接口文档

参数必填说明
app_id是应用注册后分配的数字 ID（公开标识）
app_key是token key（pk_ 开头 32 位），保密
target否all / 34 / #group，缺省 all
msg是正文，≤ 8KB
title否标题
HTTP：POST /sys/push?do=api（不需要 endpoint token）
# HTTP 调用
curl -X POST 'http://okr.kexinlai.com/sys/push?do=api' \
  -d app_id=1001 -d app_key=pk_xxx \
  -d target=34 -d msg=你有新的工单

// 服务端内部（同框架，不走 HTTP）
\Candy\Extend\Tools\Push\Target::app(1001)->toUid(34, '你有新的工单');
// app(1001) 传 app_id；也兼容 app('home') 传应用名（内部可读写法）
// 客户端 WebSocket（wss 需网关配证书，否则前端自动回退轮询）
var proto = location.protocol === 'https:' ? 'wss:' : 'ws:';
var ws = new WebSocket(proto + '//' + location.hostname + ':4020');
ws.onopen = () => ws.send(JSON.stringify({act:'login', app_id:1001, uid:34}));
// 收到 {act:'login',ok:true,uid:'home:34',flushed:N}
//      {act:'message',msg_id,title,body,payload,ts}  → 回 ack 可留痕
//      {act:'ping'}                                  → 必须回 {act:'pong'}
