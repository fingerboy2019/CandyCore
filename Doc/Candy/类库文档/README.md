# 类库 API 参考

本目录为 **`backend/Candy/`** 源码的镜像说明，供查阅类与方法签名，**不作为入门教程**。

## 结构

| 子目录 | 对应源码 |
|--------|----------|
| [Candy/Core/](Candy/Core/) | 核心：Action、View、Route、Node、Cache、Security … |
| [Candy/Class/](Candy/Class/) | 内置类：DB、Network、Attribute 注解 … |
| [Candy/Extend/](Candy/Extend/) | 与 Class 平行的扩展实现文档 |
| [Candy/Func/globalFunc.md](Candy/Func/globalFunc.md) | 全局函数汇总 |
| [语言/](语言/) | 语言系统说明（规范见 [raw/doc/LangConvention.md](../../../raw/doc/LangConvention.md)） |

## 使用说明 vs API 参考

- **怎么用**：优先看 [扩展类库/](../扩展类库/索引.md)、[框架使用/](../框架使用/README.md)
- **查 API**：在本目录按类名查找 `.md` / `.class.md`

> 已删除与「扩展类库」重复的 `Candy/Vendor/Extend/*.md`，避免双份维护。
