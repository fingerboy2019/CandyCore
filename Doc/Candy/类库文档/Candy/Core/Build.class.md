* Candy框架 应用构建类

 * 提供自动化的目录创建、文件生成、项目初始化功能
 * 
 * @package Candy\Core
 * @author 刘森 (fingerboy@qq.com)
 * @date 2019-07-27 10:00:00
 * @final 该类设计为最终类，不允许继承
 * 
 * @note 此类是框架自动初始化和应用创建的核心组件，通常不需要手动调用
 * 除非在特殊情况下需要创建新的应用或扩展
