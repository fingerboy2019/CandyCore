# Dir 类

## 概述

* Candy框架 文件夹操作类
 * 
 * Dir类提供了一套完整的目录操作API，用于管理文件系统中的目录和文件。
 * 该类支持目录的创建、删除、复制、移动，以及文件列表获取、目录状态检查等功能。
 * 同时实现了类似SPL DirectoryIterator的接口方法，便于与PHP标准库兼容使用。
 * 
 * @package Candy\Extend
 * @author 刘森 (fingerboy@qq.com)
 * @date 2020-04-12 13:45:33
 * @final 该类不允许被继承
