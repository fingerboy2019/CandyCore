# Candy Attribute 注解命名规范

`Candy/Class/Attribute` 统一存放框架注解类。权限/菜单 `#[Annotation]` 的规范实现位于 `Attribute/Annotations/Annotation.class.php`；`Candy/Class/Vendor/Annotation.class.php` 仅保留全局 `class_alias` 桥接，应用层可继续无 `use` 书写。

## 1. 目录与命名空间

| 路径 | 命名空间 |
|------|----------|
| `Attribute/Annotations/` | `Candy\Extend\Attribute\Annotations`（含 `Annotation` 权限/菜单注解） |
| `Attribute/utils/` | `Candy\Extend\Attribute\utils` |

**禁止**再使用小写 `annotations` 命名空间段。

## 2. 类名

| 类别 | 规范 | 示例 |
|------|------|------|
| 参数注解 | PascalCase 名词 | `Query`, `Param`, `Header` |
| 否定标记 | `Not` + 复数名词 | `NotQueries`, `NotParams`, `NotHeaders` |
| Markdown | 完整单词 | `Markdown`, `ResponseSuccessMarkdown` |

## 3. PHPDoc 魔法行（无 `@` 前缀）

在方法注释独立一行书写，用于 Apidoc 开关：

`NotParse`, `NotDebug`, `NotQueries`, `NotParams`, `NotHeaders`, `NotResponses`, `NotResponseSuccess`, `NotResponseError`, `NotDefaultAuthor`, `NotEvent`

## 4. 属性与构造参数

| 字段 | 规范 |
|------|------|
| 是否必填 | `required`（**不是** `require`） |
| 子字段 | `childrenField`, `childrenType`, `withoutField` |
| 描述 | `desc`, `default`, `mock`, `ref` |

`@Query("page", "int", false, "页码")` 第三参数仍按位置映射到构造函数的 `required` 参数。

## 5. Node 扫描输出键（冻结）

`Tool::parseMethodAnnotation()` 产出：`Title`, `Auth`, `Menu`, `Log`, `Desc`, `Group` — 勿改。

控制器类常量 `classGroup` 冻结。
