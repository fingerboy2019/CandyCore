# Mcrypt 类

## 概述

*
 * Candy框架 字符串加解密类库
 * 
 * 该类提供了多种字符串加密和解密方法，支持不同安全级别的数据加密需求。
 * 主要功能：
 * - 高性能的字符加密解密方法，支持设置过期时间
 * - 简单对称加密算法，适用于非敏感数据的快速加解密
 * - DES/AES加密解密，提供更高级别的安全性
 * - 支持自定义密钥和默认密钥机制
 * 
 * 使用场景：
 * - 用户密码的安全存储和验证
 * - API密钥、Token的安全传输
 * - 敏感数据的临时加密存储
 * - URL参数或Cookie中敏感信息的保护
 * 
 * @package Candy\Extend
 * @author 刘森 (fingerboy@qq.com)
 * @date 2019-08-05 23:39:50
 * @final 该类为最终类，不允许继承
 * @example 
 * ```
 * // 使用默认密钥进行加密
 * $encrypted = \Candy\Extend\Mcrypt::code('敏感数据');
 * 
 * // 使用自定义密钥进行加密
 *
