# Unknown 类

## 概述

* Client 客户端信息获取类
 * 
 * 功能描述：提供全面的客户端信息获取功能，包括IP地址、浏览器、操作系统、地理位置等信息的采集和处理。
 * 
 * 主要功能：
 * - IP地址获取（支持高级模式，可获取代理IP后的真实地址）
 * - 客户端地理位置查询（支持太平洋IP查询接口和自定义API）
 * - 浏览器类型和版本识别
 * - 操作系统类型检测
 * - 用户语言偏好获取
 * - 访问来源URL获取
 * - 用户代理字符串获取
 * 
 * @package Candy\Extend\Network
 * @author 刘森 (fingerboy@qq.com)
 * @date 2019-08-05 10:00:00
 * @final 此类不可被继承
