## 使用示例

```php
// 基本使用
echo L('pageTitle');  // 输出：团云管理平台登录

// 带默认值
echo L('nonexistent', '默认值');

// 在控制器中
$this->error(L('usernameOrPasswordError'));
$this->success(L('loginSuccess'));
```

---

## 添加新语言键

1. 在对应的语言文件中添加键值对：

```php
// zh-cn/Index.lang.php
$LANG['newKey'] = '新的语言值';

// en-us/Index.lang.php
$LANG['newKey'] = 'New language value';
```

2. 在代码中使用：

```php
echo L('newKey');
```
