## 增强特性

### ✅ L() 函数增强

框架原有的 `L()` 函数已直接增强，现在支持：

| 功能 | 说明 | 示例 |
|------|------|------|
| **多维键** | 支持点分键访问 | `L('user.profile.name')` |
| **默认值** | 键不存在时返回默认值 | `L('key', '默认值')` |
| **懒加载** | 自动加载对应的语言文件 | 首次访问时加载 |
| **缺失检测** | 自动记录缺失的键到日志 | 调试模式生效 |
| **向后兼容** | 完全兼容原有调用方式 | `L('key')` 仍可用 |

## 快速开始

### 1. 初始化语言系统

在应用启动时调用：

```php
<?php
namespace APP\Control\Admin;

Class Common extends Base {
    function init(){
        // 初始化语言系统
        langInit();  // 默认使用 zh-cn
    }
}
```

### 2. 使用增强版 L() 函数

```php
// 基本使用
echo L('pageTitle');

// 带默认值
echo L('nonexistent', '默认值');

// 多维键
echo L('user.profile.name');
echo L('user.login.success');
```

## 基本使用

### 在控制器中使用

```php
<?php
namespace APP\Control\Admin;

Class User extends Common {
    function add(){
        if(empty($_POST['username'])){
            $this->error(L('usernameRequired'));
        }
        
        // 带默认值
        $msg = L('addSuccess', '添加成功');
        $this->success([], $msg);
    }
}
```

### 在模板中使用

```html
<!DOCTYPE html>
<html>
<head>
    <title><?php echo L('pageTitle'); ?></title>
</head>
<body>
    <h1><?php echo L('welcomeMessage'); ?></h1>
    
    <form>
        <input type="text" placeholder="<?php echo L('username'); ?>">
        <input type="password" placeholder="<?php echo L('password'); ?>">
        <button><?php echo L('login'); ?></button>
    </form>
</body>
</html>
```

### 多维键使用

```php
// 设置多维语言数据
Lang::setMany([
    'user' => [
        'profile' => [
            'name' => '用户名',
            'email' => '邮箱',
        ],
        'login' => [
            'success' => '登录成功',
            'failed' => '登录失败',
        ],
    ],
]);

// 获取多维值
echo L('user.profile.name');      // 输出：用户名
echo L('user.login.success');     // 输出：登录成功
```

## 高级功能

### 1. 动态切换语言

```php
// 切换到英文
langSwitch('en-us');

// 切换到繁体中文
langSwitch('zh-tw');

// 获取当前语言
echo langLocale();  // 输出：en-us
```

### 2. 前端语言切换链接

```html
<div class="lang-switcher">
    <a href="?lang=zh-cn">简体中文</a>
    <a href="?lang=zh-tw">繁體中文</a>
    <a href="?lang=en-us">English</a>
</div>

<?php
// 处理语言切换
if(isset($_GET['lang'])){
    langSwitch($_GET['lang']);
    header('Location: ' . $_SERVER['HTTP_REFERER']);
    exit;
}
?>
```

### 3. 输出 JavaScript 语言包

```html
<head>
    <?php langJs(); ?>
</head>

<script>
// 前端使用
document.getElementById('title').textContent = t('pageTitle');
document.getElementById('msg').textContent = t('loginSuccess', '登录成功');
</script>
```

## 语言切换

### Cookie 记忆

增强版会自动将用户选择的语言保存到 Cookie（1 年有效期）：

```php
// 用户首次选择英文
langSwitch('en-us');

// 下次访问时自动从 Cookie 读取
langInit();  // 自动使用 en-us
```

## 调试工具

### 查看缺失的语言键

```php
// 获取所有缺失的语言键
$missing = langMissing();
print_r($missing);
```

### 查看语言日志

缺失的语言键会自动记录到日志文件：

```
Runtime/Logs/lang-missing-2026-04-08.log

Missing language key: usernameRequired
Missing language key: emailRequired
```

### 清空语言缓存

```php
// 清空当前语言缓存
Lang::clearCache();

// 清空指定语言缓存
Lang::clearCache('en-us');
```

## 性能优化

### 1. 启用语言包缓存

```php
// Source/Inc/Lang.inc.php
return [
    'enable_cache' => true,    // 启用缓存
    'cache_ttl' => 86400,      // 24 小时过期
];
```

启用后，语言包会缓存到 Redis/Memcached，大幅降低 IO 开销。

### 2. 懒加载

增强版会自动懒加载语言文件：

```php
// 只加载 Common.lang.php
Lang::init();

// 访问 Login 控制器时，自动加载 Login.lang.php
Lang::load('Login');
```

## 配置说明

### Source/Inc/Lang.inc.php

```php
<?php
return [
    // 支持的语言列表
    'locales' => [
        'zh-cn' => '简体中文',
        'zh-tw' => '繁體中文',
        'en-us' => 'English',
        'ja' => '日本語',
    ],
    
    // 默认语言
    'default' => 'zh-cn',
    
    // 启用缓存
    'enable_cache' => true,
    
    // 缓存过期时间（秒）
    'cache_ttl' => 86400,
    
    // 记录缺失的语言键
    'log_missing' => true,
    
    // 语言检测方式：cookie / browser / config
    'detect' => 'cookie',
];
```

## 函数列表

| 函数 | 说明 |
|------|------|
| `L($key, $default)` | 获取语言值（已增强） |
| `langInit($locale)` | 初始化语言系统 |
| `langSwitch($locale)` | 切换语言 |
| `langLocale()` | 获取当前语言 |
| `langJs($namespace)` | 输出 JS 语言包 |
| `langHas($key)` | 检查语言键是否存在 |
| `langMissing()` | 获取缺失的语言键 |

## 最佳实践

```php
// ✅ 推荐
echo L('pageTitle');
```
