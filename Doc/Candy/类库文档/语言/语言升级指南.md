# Candy 框架多语言系统升级文档

## 📋 升级概述

### 升级内容

| 项目 | 旧版 | 新版 | 说明 |
|------|------|------|------|
| 类路径 | `\APP\Extend\Lang` | `\Candy\Core\Lang` | 纳入框架核心 |
| 命名空间 | `APP\Extend` | `Candy\Core` | 框架核心命名空间 |
| L() 函数 | 调用 `\APP\Extend\Lang` | 调用 `\Candy\Core\Lang` | 自动适配 |
| 文件位置 | `Source/Class/Lang.class.php` | `Candy/Core/Lang.class.php` | 框架核心目录 |

### 升级原因

1. **统一标准**：语言系统是框架核心功能，应放在核心目录
2. **便于维护**：核心类统一在 `Candy/Core/` 管理
3. **向后兼容**：L() 函数自动适配新旧版本

## 🎯 核心类

### Candy\Core\Lang

文件：`Candy/Core/Lang.class.php`

**主要方法：**

| 方法 | 说明 | 示例 |
|------|------|------|
| `init($locale)` | 初始化语言系统 | `Lang::init('zh-cn')` |
| `get($key, $default)` | 获取语言值 | `Lang::get('pageTitle')` |
| `getNested($key, $default)` | 获取多维语言值 | `Lang::get('user.profile.name')` |
| `set($key, $value)` | 设置语言值 | `Lang::set('key', '值')` |
| `setMany($data)` | 批量设置语言值 | `Lang::setMany([...])` |
| `load($controller, $locale)` | 加载语言文件 | `Lang::load('Login')` |
| `switchLocale($locale)` | 切换语言 | `Lang::switchLocale('en-us')` |
| `getLocale()` | 获取当前语言 | `Lang::getLocale()` |
| `getLocales()` | 获取支持的语言列表 | `Lang::getLocales()` |
| `getMissingKeys()` | 获取缺失的语言键 | `Lang::getMissingKeys()` |
| `clearCache($locale)` | 清空语言缓存 | `Lang::clearCache()` |
| `toJs($namespace)` | 生成 JavaScript 语言包 | `Lang::toJs()` |
| `guessController($key)` | 根据键猜测控制器 | `Lang::guessController('login.title')` |

## 📝 L() 函数

### 函数签名

```php
function L($key = null, string $default = ''): mixed
```

### 功能

| 功能 | 示例 | 说明 |
|------|------|------|
| 获取单个值 | `L('pageTitle')` | 返回语言值 |
| 带默认值 | `L('key', '默认值')` | 键不存在时返回默认值 |
| 多维键 | `L('user.profile.name')` | 支持点分多维键 |
| 返回全部 | `L()` | 返回所有语言配置 |

### 自动适配

L() 函数会自动检测：
1. 优先使用 `\Candy\Core\Lang`（框架核心）
2. 如果核心类未加载，使用原有逻辑（兼容旧版）

## 🚀 使用方式

### 1. 初始化语言系统

**无需手动初始化！**

框架已在 `Candy\Core\Action::working()` 中自动初始化语言系统，所有控制器自动生效。

```php
// ❌ 不再需要手动调用
// \Candy\Core\Lang::init();

// ✅ 直接使用 L() 函数
echo L('pageTitle');
```

如果需要在特殊场景（如命令行、独立脚本）中初始化：

```php
\Candy\Core\Lang::init();  // 默认使用 zh-cn
\Candy\Core\Lang::init('en-us');  // 或指定语言
```

### 2. 获取语言值

```php
// 基本使用
echo L('pageTitle');

// 带默认值
echo L('nonexistent', '默认值');

// 多维键
echo L('user.profile.name');

// 使用核心类
echo \Candy\Core\Lang::get('pageTitle');
```

### 3. 切换语言

```php
// 切换到英文
\Candy\Core\Lang::switchLocale('en-us');

// 获取当前语言
echo \Candy\Core\Lang::getLocale();  // 输出：en-us
```

### 4. 生成 JavaScript 语言包

```html
<head>
    <?php echo \Candy\Core\Lang::toJs(); ?>
</head>

<script>
// 前端使用
document.title = t('pageTitle');
</script>
```

## 🔄 迁移指南

### 旧代码

```php
// 旧：使用 APP\Extend\Lang
\APP\Extend\Lang::init();
\APP\Extend\Lang::get('key');
\APP\Extend\Lang::switchLocale('en-us');
```

### 新代码

```php
// 新：使用 Candy\Core\Lang
\Candy\Core\Lang::init();
\Candy\Core\Lang::get('key');
\Candy\Core\Lang::switchLocale('en-us');

// 或者直接使用 L() 函数（推荐）
L('key');
```

### 自动迁移

L() 函数已自动适配，现有代码无需修改：

```php
// 以下代码无需修改
echo L('pageTitle');
echo L('user.profile.name');
$this->error(L('usernameRequired'));
```

## 💡 最佳实践

### 1. 使用 L() 函数（推荐）

```php
// ✅ 推荐：使用 L() 函数
echo L('pageTitle');
echo L('user.profile.name');
echo L('key', '默认值');

// ❌ 避免：直接使用 Lang 类
echo \Candy\Core\Lang::get('pageTitle');  // 可用，但不推荐
```

### 2. 在控制器中使用

```php
<?php
namespace APP\Control\Admin;

// 语言系统已自动初始化，直接使用 L() 函数

Class User extends Common {
    function index(){
        // 获取语言值
        $title = L('pageTitle');
        
        // 多维键
        $msg = L('user.login.success');
        
        // 带默认值
        $hint = L('nonexistent', '默认提示');
        
        $this->assign('title', $title);
        $this->display();
    }
}
```

### 3. 及时添加缺失的语言键

开发时定期检查日志文件：

```bash
cat Runtime/Logs/lang-missing-2026-04-08.log
```

然后补充到语言文件中。

## 📊 性能优化

### 1. 启用语言包缓存

```php
// Source/Inc/Lang.inc.php
return [
    'enable_cache' => true,    // 启用缓存
    'cache_ttl' => 86400,      // 24 小时过期
];
```

### 2. 懒加载

增强版会自动懒加载语言文件：

```php
// 只加载 Common.lang.php
Lang::init();

// 访问 Login 控制器时，自动加载 Login.lang.php
Lang::load('Login');
```
