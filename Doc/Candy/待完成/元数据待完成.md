# 元数据控制项目建议

## 1. 页面SEO相关
- **author**：文档作者
- **date**：文档创建日期
- **update**：文档更新日期
- **tags**：文档标签
- **category**：文档分类

## 2. 文档显示相关
- **toc**：是否显示目录（true/false）
- **toc_depth**：目录深度（1-6）
- **sidebar**：是否显示侧边栏（true/false）
- **theme**：文档主题（light/dark）

## 3. 文档功能相关
- **comments**：是否允许评论（true/false）
- **edit**：是否允许编辑（true/false）
- **download**：是否允许下载（true/false）
- **print**：是否允许打印（true/false）

## 4. 文档权限相关
- **password**：文档密码
- **role**：文档访问角色（admin/user/guest）
- **expire**：文档过期时间

## 5. 文档样式相关
- **css**：自定义CSS文件路径
- **js**：自定义JS文件路径
- **logo**：文档logo路径
- **favicon**：文档favicon路径

## 6. 文档国际化相关
- **lang**：文档语言（zh-CN/en-US/ja-JP）
- **locale**：文档区域设置

## 7. 文档性能相关
- **cache**：是否启用缓存（true/false）
- **cache_time**：缓存时间（秒）

## 8. 文档集成相关
- **google_analytics**：Google Analytics跟踪ID
- **baidu_tongji**：百度统计跟踪ID
- **disqus**：Disqus评论ID
- **giscus**：Giscus评论ID

## 9. 文档社交相关
- **og_title**：Open Graph标题
- **og_description**：Open Graph描述
- **og_image**：Open Graph图片
- **og_url**：Open Graph URL
- **twitter_card**：Twitter卡片类型

## 10. 文档自定义相关
- **custom**：自定义元数据，可以是任意键值对

## 示例
```markdown
---
title: Candy框架开发手册
keywords: Candy框架, PHP框架, 开发手册
description: Candy框架是一个轻量级的PHP开发框架，提供快速开发Web应用的能力。
author: 刘森
date: 2024-01-01
update: 2024-01-02
tags: PHP, 框架, 开发
category: 技术文档
toc: true
toc_depth: 3
sidebar: true
theme: light
comments: true
edit: true
download: true
print: true
password: 123456
role: user
expire: 2024-12-31
css: /Doc/Static/custom.css
js: /Doc/Static/custom.js
logo: /Doc/Static/logo.png
favicon: /Doc/Static/favicon.ico
lang: zh-CN
locale: zh_CN
cache: true
cache_time: 3600
google_analytics: UA-123456789-1
baidu_tongji: 123456789
disqus: candy-framework
giscus: candy-framework/giscus
og_title: Candy框架开发手册
og_description: Candy框架是一个轻量级的PHP开发框架，提供快速开发Web应用的能力。
og_image: /Doc/Static/og_image.png
og_url: https://example.com/Doc/
twitter_card: summary_large_image
custom:
  key1: value1
  key2: value2
---
```
