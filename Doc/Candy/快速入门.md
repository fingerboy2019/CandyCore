# Candy 框架快速入门

本指南将带领你通过一个简单的示例，快速掌握 Candy 框架的基本使用流程。Candy 框架提供了自动化的项目构建功能，可以快速生成完整的项目结构。

## 前提条件
确保已完成 [安装指南](安装指南.md) 中的步骤，包括环境配置、依赖安装和数据库设置。

## 项目创建方式

Candy 框架提供了两种项目创建方式：

### 方式一：自动化项目构建（推荐）

Candy 框架内置了自动化项目构建功能，可以通过 URL 参数或命令行快速生成完整的项目结构。

#### 单项目模式初始化

1. **启动项目初始化**
   在浏览器中访问以下地址：
   ``` php {.line-numbers .match-braces .copy-to-clipboard line-data="1, 5-10"}
   http://your-domain.com/?start
   ```
   或使用命令行：
   ```bash
   php index.php --start
   ```

2. **自动生成的项目结构**
   框架会自动创建以下目录结构：
   ```treeview {.no-line-numbers}
   candy/
   ├── Application/          # 应用程序目录
   │   └── Home/            # 默认项目目录
   │       ├── Controls/    # 控制器目录
   │       ├── Models/      # 模型目录
   │       ├── Views/       # 视图目录
   │       └── Languages/   # 语言包目录
   ├── Public/              # 公共资源目录
   │   ├── css/             # CSS 样式目录
   │   ├── js/              # JavaScript 目录
   │   ├── images/          # 图片资源目录
   │   └── uploads/         # 文件上传目录
   ├── Source/              # 源文件目录
   │   ├── Class/           # 通用类库
   │   ├── Event/           # 事件类库
   │   ├── Func/            # 函数库
   │   └── Vendor/          # 第三方类库
   └── Runtime/             # 运行时目录
       ├── Cache/           # 缓存目录
       ├── Comps/           # 模板组合文件
       ├── Data/            # 数据文件
       ├── Controls/        # 控制器缓存
       ├── Models/          # 模型缓存
       └── Logs/            # 日志目录
   ```

3. **自动生成的核心文件**
   - 控制器：`Application/Home/Controls/Index.class.php`
   - 视图：`Application/Home/Views/...` 或 `Template/default/...`（由 `System.inc.php` 的 `$tplpath` 决定）
   - 配置：`Source/Inc/Config.inc.php`、`Source/Inc/Route.inc.php`

#### 多项目模式初始化（ALLINONE）

1. **启用多项目模式**
   在 `index.php` 文件中定义 `ALLINONE` 常量：
```php
define('ALLINONE', true);
```

2. **创建域名对应的项目**
框架会根据访问域名自动创建项目目录：
```treeview
candy/Applies/
├── your-domain.com/     # 域名对应的项目目录
│   ├── Application/     # 应用程序目录
│   ├── Public/          # 公共资源目录
│   └── Source/          # 源文件目录
└── default/             # 默认项目目录
    ├── Application/     # 应用程序目录
    ├── Public/          # 公共资源目录
    └── Source/          # 源文件目录
```

3. **启动多项目初始化**
在浏览器中访问：
```
http://your-domain.com/?start
```

### 方式二：手动创建项目（了解原理）

如果你想了解项目结构的细节，可以手动创建项目目录和文件。

#### 步骤 1：创建项目目录
在 `Application` 目录下创建你的项目目录（例如 `Demo`）：
```bash
mkdir -p /www/wwwroot/candy/Application/Demo/Controls
```

#### 步骤 2：定义路由
打开 `Inc/Route.inc.php` 文件，添加一个简单路由：
```php
return [
    '/' => 'Demo/Index/index', // 访问根路径指向 Demo 项目的 Index 控制器的 index 方法
];
```

#### 步骤 3：编写控制器
在 `Application/Demo/Controls` 目录下创建 `Index.php` 文件：
```php
<?php
namespace Application\Demo\Controls;

use Candy\Core\Control;

class Index extends Control
{
    public function index()
    {
        // 传递数据到视图
        $this->assign('message', 'Hello, Candy Framework!');
        // 渲染视图
        $this->display('index.html');
    }
}
```

#### 步骤 4：创建视图文件
在 `Application/Demo/Views` 目录下创建 `index.html` 模板文件：
```html
<!DOCTYPE html>
<html>
<head>
    <title>Candy 快速入门</title>
</head>
<body>
    <h1>{$message}</h1>
</body>
</html>
```

## 运行测试

### 方式一：使用 PHP 内置服务器

启动 PHP 内置服务器：
```bash
php -S localhost:8000 -t public/
```

在浏览器中访问 `http://localhost:8000`，应看到页面显示 `Hello, Candy Framework!`。

### 方式二：配置 Web 服务器

根据你的 Web 服务器（Apache/Nginx）配置虚拟主机，将根目录指向 `public/` 目录。

## 项目配置

### 基本配置

主要配置文件位于 `Inc/Config.inc.php`，可以配置数据库连接、模板设置等：

```php
return [
    'CHARSET'  => 'utf-8',
    'DRIVER'   => 'pdomysql',
    'DB'       => [
        'default' => [
            'HOST'     => 'localhost',
            'PORT'     => 3306,
            'PASSWORD' => 'password',
            // ...
        ]
    ],
    // ...
];
```

### 路由配置

路由配置文件位于 `Inc/Route.inc.php`，可以配置 URL 路由规则：

```php
return [
    'URL_MODE'         => 1,          // URL 模式：0-普通模式，1-路径模式
    'URL_ROUTER_ON'    => true,       // 是否开启路由
    'URL_DEPR'         => '/',        // URL 分隔符
    'URL_HTML_SUFFIX'  => '.html',    // URL 后缀
    'URL_MAP_RULES'    => [           // URL 映射规则
        'show/index' => 'Home/Index/index',
    ],
];
```
