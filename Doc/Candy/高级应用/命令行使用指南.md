# Candy框架命令行工具使用指南

## 概述

Candy框架提供了一个功能强大的命令行工具，通过`candy`脚本可以快速执行各种开发任务。该工具类似于Symfony Console或Laravel Artisan，提供了丰富的命令集和灵活的扩展机制。

## 基本使用方法

命令行工具的入口是项目根目录下的`candy`脚本：

```bash
php candy <命令名> [参数] [选项]
```

## 核心命令

### 帮助和信息

- **查看帮助**：
```bash
  php candy help
  php candy <命令名> --help
```

- **列出所有命令**：
  ```bash
  php candy list
  ```

- **查看版本信息**：
  ```bash
  php candy version
  ```

### 构建和部署

- **构建二进制文件**：
  ```bash
  php candy build:bin
  ```

- **构建PHAR文件**：
  ```bash
  php candy build:phar
  ```

### 代码生成

- **按表生成 CRUD（推荐，默认 admin-layui）**：
  ```bash
  cd backend
  # 默认：admin-layui + model/control/view/lang
  php candy generate:crud Admin sa_article
  php candy generate:crud Admin sa_article --menu-title=文章示例 --class-group=Content -f
  php candy generate:crud Admin sa_article -l model -l control --style=admin-layui
  ```

- **创建应用骨架**：
  ```bash
  php candy generate:scaffold Admin
  php candy make:app <应用名>
  ```

- **开发脚手架：初始化数据库（DEBUG 模式）**：
  ```bash
  cd backend
  php candy scaffold:init --status   # 查看状态
  php candy scaffold:init            # 导入 raw/doc/sql/scaffold_dev_template.sql
  php candy scaffold:init -f         # 强制重新导入
  ```
  Web 引导：访问站点首页 `/Index/index.html`，初始化完成后自动跳转 Admin 登录。

- **创建控制器**：
  ```bash
  php candy make:control <控制器名>
  ```

- **创建命令**：
  ```bash
  php candy make:command <命令名>
  ```

- **创建模型**：
  ```bash
  php candy make:model <模型名>
  ```

- **创建验证器**（源码短名，Runtime 编译追加 `Validate` 后缀）：
  ```bash
  php candy make:validate Admin Group
  # → Application/Admin/Validates/Group.class.php
  # → Runtime/Validates/Admin/groupvalidate.*.php（类名 GroupValidate）
  ```

- **创建响应 Schema**（源码短名，Runtime 编译追加 `Schema` 后缀）：
  ```bash
  php candy make:schema Admin Group
  # → Application/Admin/Schemas/Group.class.php
  # → Runtime/Schemas/Admin/groupschema.*.php（类名 GroupSchema）
  ```

生成后请清理 Runtime（保留 `init.lock`）并执行 `php candy clear --node`，再在角色管理中授权新节点。Web 端：**编码工具 → 代码生成**（仅 DEBUG）。详见 `raw/doc/ArticleExampleModule.md`、`AGENTS.md` 代码生成章节。

### 服务器管理

- **运行内置服务器**：
  ```bash
  php candy run
  ```

- **运行Worker进程**：
  ```bash
  php candy worker
  ```

- **运行独立进程**：
  ```bash
  php candy process
  ```

- **运行Swoole服务器**：
  ```bash
  php candy swoole
  ```

- **运行WebDAV服务器**：
  ```bash
  php candy webdav
  ```

- **运行WebSocket服务器**：
  ```bash
  php candy ws
  ```

- **运行FTP服务器**：
  ```bash
  php candy ftp
  ```

### 其他工具

- **清除缓存**：
  ```bash
  php candy clear
  ```

- **发布vendor资源**：
  ```bash
  php candy vendor:publish
  ```

- **执行Composer命令**：
  ```bash
  php candy composer <composer命令>
  ```

## 常用选项

所有命令都支持以下通用选项：

- `--help, -h`: 显示帮助信息
- `--version, -V`: 显示版本信息
- `--quiet, -q`: 不输出任何消息
- `--verbose, -v|vv|vvv`: 增加消息详细程度（1-3级）
- `--ansi`: 强制ANSI输出
- `--no-ansi`: 禁用ANSI输出
- `--no-interaction, -n`: 不询问任何交互式问题

## 扩展命令

除了默认命令外，还可以通过配置文件扩展自定义命令：

1. 在配置文件中定义命令：
   ```php
   // 配置文件示例
   return [
       'mycommand' => MyCommand::class,
       'my:subcommand' => MySubCommand::class,
   ];
   ```

2. 或者通过代码动态添加命令：
   ```php
   $console->addCommand(MyCommand::class, 'mycommand');
   ```

## 非标准命令

Candy命令行工具还支持非标准命令，包括：

1. **函数调用**：
   ```php
   // 配置示例
   return [
       'myfunc' => 'my_function_name',
   ];
   ```

2. **类方法调用**：
   ```php
   // 配置示例
   return [
       'myclass:method' => 'MyClass::myMethod',
   ];
   ```

3. **闭包调用**：
   ```php
   // 配置示例
   return [
       'myclosure' => function($arg1, $arg2) {
           // 命令逻辑
       },
   ];
   ```

## 示例

- **查看所有命令**：
  ```bash
  php candy list
  ```

- **创建一个新的用户控制器**：
  ```bash
  php candy make:control User
  ```

- **运行内置服务器并显示详细信息**：
  ```bash
  php candy run -v
  ```

- **执行Composer更新**：
  ```bash
  php candy composer update
  ```

## 注意事项

1. 命令行工具需要PHP CLI环境支持
2. 某些命令可能需要特定的扩展（如Swoole命令需要Swoole扩展）
3. 自定义命令需要遵循Command类的接口规范
4. 复杂命令建议使用标准命令类实现，以便更好地管理和维护
