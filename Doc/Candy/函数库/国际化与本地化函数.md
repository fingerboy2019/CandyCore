# 国际化与本地化函数

本文件包含Candy框架中用于支持国际化(i18n)和本地化(l10n)的函数，帮助开发者创建多语言应用程序。

## 1. importLang()

```php
function importLang(array $path = []): void
```

**功能描述**：导入语言文件到系统配置中，用于动态加载不同模块或应用的语言包。

**参数**：
- `$path`：语言文件路径数组，每个路径格式为`应用名称/语言文件名称`

**返回值**：无返回值

**使用示例**：
```php
// 导入单个语言文件
importLang(['Home/Common']);

// 导入多个语言文件
importLang([
    'Home/Common',
    'Home/User',
    'Admin/Menu'
]);
```

**注意事项**：
- 语言文件路径格式为：`CANDYROOT . 'Application/' . $appName . '/Languages/' . G('LANG') . '/' . $action . '.lang.php'`
- 引入完成后，会更新`LANGINFO`配置，使导入的语言项可通过`L()`函数访问

## 2. L()

```php
function L($key=null):array|null|string
```

**功能描述**：获取系统配置中的语言项，是访问语言资源的统一接口。

**参数**：
- `$key`：语言项键名，为null时返回完整的语言配置数组

**返回值**：
- 当`$key`为null时，返回完整的语言配置数组
- 当`$key`不为null时，返回对应的语言项值，如果语言项不存在则返回空字符串

**使用示例**：
```php
// 获取单个语言项
$welcome = L('welcome_message');
echo $welcome; // 输出：欢迎使用Candy框架

// 获取多个语言项
$title = L('page_title');
$subtitle = L('page_subtitle');

// 返回完整的语言配置数组
$allLang = L();
print_r($allLang);
```

## 国际化与本地化使用指南

### 1. 语言文件结构

Candy框架的语言文件通常存放在`Application/应用名称/Languages/语言代码/`目录下，文件格式为：

```php
// Application/Home/Languages/zh-cn/Common.lang.php
$LANG = [
    'welcome_message' => '欢迎使用Candy框架',
    'page_title' => '首页',
    'page_subtitle' => '这是网站的首页',
    'login' => '登录',
    'logout' => '退出',
    'register' => '注册'
];
```

### 2. 语言切换

Candy框架通过全局配置项`LANG`控制当前使用的语言，可以通过以下方式切换语言：

```php
// 设置当前语言为中文
G('LANG', 'zh-cn');

// 设置当前语言为英文
G('LANG', 'en-us');
```

### 3. 多语言应用开发流程

1. **创建语言文件**：
   ```
   Application/
   ├── Home/
   │   └── Languages/
   │       ├── zh-cn/
   │       │   ├── Common.lang.php
   │       │   └── Index.lang.php
   │       └── en-us/
   │           ├── Common.lang.php
   │           └── Index.lang.php
   ```

2. **加载语言文件**：
   ```php
   // 在控制器中加载语言文件
   importLang(['Home/Common', 'Home/Index']);
   ```

3. **使用语言项**：
```html
   // 在视图中使用语言项
   <h1><?php echo L('page_title'); ?></h1>
   <p><?php echo L('welcome_message'); ?></p>
   <a href="#login"><?php echo L('login'); ?></a>
   ```

### 4. 语言项使用技巧

1. **动态语言项**：
   ```php
   // 语言文件中定义带占位符的语言项
   $LANG = [
       'welcome_user' => '欢迎你，%s！'
   ];
   
   // 在代码中使用sprintf格式化
   $username = '张三';
   $welcome = sprintf(L('welcome_user'), $username);
   echo $welcome; // 输出：欢迎你，张三！
   ```

2. **条件语言项**：
   ```php
   // 根据用户类型显示不同的欢迎信息
   $userType = 'admin';
   if ($userType === 'admin') {
       $welcome = L('welcome_admin');
   } else {
       $welcome = L('welcome_user');
   }
   ```

3. **语言项分组**：
   ```php
   // 语言文件中使用分组结构
   $LANG = [
       'user' => [
           'login' => '登录',
           'register' => '注册',
           'profile' => '个人资料'
       ],
       'system' => [
           'save' => '保存',
           'delete' => '删除',
           'update' => '更新'
       ]
   ];
   
   // 访问分组语言项
   echo L('user.login'); // 注意：此方式需要额外处理，Candy框架的L()函数默认不支持嵌套键
   ```

### 5. 扩展国际化功能

如果需要更复杂的国际化功能，可以扩展Candy框架的语言处理机制：

1. **添加语言切换控制器**：
   ```php
   // 在Home控制器中添加语言切换方法
   public function changeLang() {
       $lang = $_GET['lang'] ?? 'zh-cn';
       // 验证语言是否存在
       if (in_array($lang, ['zh-cn', 'en-us', 'ja-jp'])) {
           G('LANG', $lang);
           cookie('lang', $lang, 3600*24*30); // 保存语言偏好到Cookie
       }
       // 重定向回原页面
       header('Location: ' . $_SERVER['HTTP_REFERER']);
   }
   ```

2. **自动检测用户语言**：
   ```php
   // 在应用入口处添加语言检测
   if (!G('LANG')) {
       // 从Cookie获取语言偏好
       $lang = cookie('lang');
       if (!$lang) {
           // 从浏览器HTTP头获取语言
           $acceptLang = $_SERVER['HTTP_ACCEPT_LANGUAGE'];
           $lang = substr($acceptLang, 0, 2);
           // 映射浏览器语言到系统语言代码
           $langMap = ['zh' => 'zh-cn', 'en' => 'en-us'];
           $lang = $langMap[$lang] ?? 'zh-cn';
       }
       G('LANG', $lang);
   }
   ```

通过以上函数和指南，开发者可以方便地在Candy框架中实现多语言应用，满足不同地区用户的语言需求。
