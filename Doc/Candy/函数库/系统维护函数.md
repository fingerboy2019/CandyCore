# 系统维护函数

## 功能说明
系统维护函数用于执行系统级别的维护操作，包括清除缓存、加载缓存、内存使用统计等，是系统管理和维护的重要工具。

## 主要函数

### cleanRuntime() - 清除运行时缓存

```php
/**
 * 清除系统运行时产生的所有缓存和临时文件
 *
 * 该函数用于清理系统运行过程中产生的各类缓存文件、编译文件和日志文件，
 * 可以有效释放磁盘空间并确保系统使用最新的代码和配置。
 * 当系统遇到缓存相关问题或进行版本更新后，通常需要调用此函数清理缓存。
 *
 * 清理内容包括：
 * - 缓存文件 (Cache目录)
 * - 模板编译文件 (Comps目录)
 * - 控制器编译文件 (Controls目录)
 * - 数据编译文件 (Data目录)
 * - 日志文件 (Logs目录)
 * - 模型编译文件 (Models目录)
 *
 * @return void 无返回值
 */
function cleanRuntime(): void
```

**功能说明**：
- 用于清理系统运行时产生的所有临时文件和缓存
- 支持清理多种类型的缓存文件：
  - 页面缓存文件
  - 模板编译文件
  - 控制器编译文件
  - 数据编译文件
  - 日志文件
  - 模型编译文件

**使用示例**：
```php
// 清理所有运行时缓存
cleanRuntime();
```

### cacheLoading() - 缓存加载初始化

```php
/**
 * 缓存加载函数
 *
 * 该函数用于初始化系统缓存，包括设置缓存引擎、检查缓存状态等，
 * 并返回缓存实例。支持页面静态化缓存配置。
 *
 * @param int $cstart 是否开启页面静态化缓存，1表示开启，0表示不开启，默认为0
 * @return \Candy\Core\Cache|false 返回缓存实例，失败时返回false
 */
function cacheLoading(int $cstart = 0)
```

**功能说明**：
- 初始化系统缓存引擎
- 检查缓存状态并生成调试信息
- 支持页面静态化缓存功能
- 根据运行环境提供不同的缓存策略

**参数说明**：
- `$cstart`：是否开启页面静态化缓存（1=开启，0=关闭），默认值为0

**返回值**：
- 成功：返回缓存实例对象
- 失败：返回false

**使用示例**：
```php
// 初始化默认缓存
$cache = cacheLoading();

// 开启页面静态化缓存
$cache = cacheLoading(1);
```

### usageMemory() - 内存使用统计

```php
/**
 * 统计内存使用情况
 *
 * 该函数用于获取当前脚本的内存使用情况，并以人类可读的格式返回。
 * 主要用于性能调优和内存管理场景。
 *
 * @param int $startMemory 起始内存使用量，默认为0
 * @return string 格式化后的内存使用信息字符串
 */
function usageMemory(int $startMemory = 0): string
```

**功能说明**：
- 统计当前脚本的内存使用情况
- 计算内存使用增量（如果提供了起始内存值）
- 返回格式化后的内存使用信息（带单位）

**参数说明**：
- `$startMemory`：起始内存使用量，用于计算内存使用增量

**返回值**：
- 返回格式化后的内存使用信息字符串（如："1.2 MB"）

**使用示例**：
```php
// 获取当前内存使用
$memory = usageMemory();

// 计算内存使用增量
$start = memory_get_usage();
// 执行一些内存密集型操作
$delta = usageMemory($start);
```

### stripWhitespace() - 代码压缩

```php
/**
 * 去除PHP代码中的空白字符
 *
 * 该函数用于压缩PHP代码，去除注释和空白字符，提高代码加载效率。
 * 主要用于代码优化和性能提升场景。
 *
 * @param string $content PHP代码内容
 * @return string 压缩后的PHP代码
 */
function stripWhitespace(string $content): string
```

**功能说明**：
- 去除PHP代码中的注释（包括单行注释和多行注释）
- 去除多余的空白字符（空格、制表符、换行符等）
- 保留字符串中的空白字符，确保代码功能不受影响

**参数说明**：
- `$content`：要压缩的PHP代码内容

**返回值**：
- 返回压缩后的PHP代码

**使用示例**：
```php
// 读取PHP文件内容
$content = file_get_contents('file.php');
// 压缩代码
$compressed = stripWhitespace($content);
// 保存压缩后的代码
file_put_contents('file.min.php', $compressed);
```
