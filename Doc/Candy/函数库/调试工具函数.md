# 调试工具函数

本文件包含Candy框架中用于调试和系统信息查看的工具函数，帮助开发者在开发过程中进行代码调试、变量查看和日志分析。

## 1. debug()

```php
function debug(int $falg = 0): void
```

**功能描述**：设置全局调试模式的开关。

**参数**：
- `$falg`：调试模式开关，0表示关闭调试，非0表示开启调试

**返回值**：无返回值

**使用示例**：
```php
// 开启调试模式
debug(1);

// 关闭调试模式
debug(0);
```

## 2. halt()

```php
function halt(...$args): void
```

**功能描述**：打印变量并停止程序执行，是调试过程中的紧急停止函数。

**参数**：
- `$args`：可变参数，要打印的变量列表

**返回值**：无返回值

**使用示例**：
```php
// 打印变量并停止执行
$user = ['id' => 1, 'name' => '张三'];
halt($user);

// 打印多个变量并停止执行
halt($user, $order, $product);
```

## 3. P()

```php
function P(...$args): void
```

**功能描述**：格式化打印变量，提供美观的语法高亮显示，适用于调试过程中的变量查看。

**参数**：
- `$args`：可变参数，要打印的变量列表

**返回值**：无返回值

**使用示例**：
```php
// 打印单个变量
$user = ['id' => 1, 'name' => '张三'];
P($user);

// 打印多个变量
$order = ['id' => 1001, 'status' => 'pending'];
$product = ['id' => 5001, 'name' => '商品名称'];
P($user, $order, $product);

// 打印对象
$db = D('user');
P($db);
```

**输出特点**：
- 对数组和对象进行格式化展示
- 对字符串变量进行红色高亮
- 对变量名进行蓝色高亮
- 对语法元素（括号、箭头）进行特殊颜色标记

## 4. stop()

```php
function stop(string $msg = ' ')
```

**功能描述**：停止程序执行，可选择输出停止信息。

**参数**：
- `$msg`：停止时输出的信息，默认为空字符串

**返回值**：无返回值

**使用示例**：
```php
// 简单停止程序
top();

// 输出停止信息并停止程序
stop('程序执行到此处停止');
```

**执行特点**：
- 在Web环境下，函数会返回而不终止整个PHP进程
- 在CLI环境下，函数会调用exit()终止程序执行
- 函数内部会触发'app_stop'事件，可用于资源清理等操作

## 5. readLog()

```php
function readLog(?string $path = null, bool $display=false):string
```

**功能描述**：读取系统日志文件内容。

**参数**：
- `$path`：日志文件路径，为null时使用默认日志路径
- `$display`：是否直接输出日志内容，true表示直接输出，false表示返回日志内容

**返回值**：日志文件内容字符串

**使用示例**：
```php
// 读取默认日志并返回内容
$logContent = readLog();
echo $logContent;

// 读取指定日志并直接输出
readLog('/path/to/log.txt', true);

// 读取默认日志并直接输出
readLog(null, true);
```

## 调试函数使用技巧

1. **调试流程**：
   ```php
   // 开启调试模式
   debug(1);
   
   // 打印变量进行调试
   $data = ['key' => 'value'];
   P($data);
   
   // 遇到问题时紧急停止
   if ($error) {
       halt('错误发生在第'.__LINE__.'行');
   }
   
   // 读取日志进行分析
   readLog(null, true);
   ```

2. **变量比较**：
   ```php
   // 比较两个变量的差异
   $oldData = ['name' => '张三', 'age' => 20];
   $newData = ['name' => '李四', 'age' => 20];
   P('旧数据:', $oldData, '新数据:', $newData);
   ```

3. **执行追踪**：
   ```php
   // 在关键执行点添加调试信息
   P('开始执行函数A');
   functionA();
   P('函数A执行完毕，开始执行函数B');
   functionB();
   P('函数B执行完毕');
   ```

4. **性能调试**：
   ```php
   // 记录执行时间
   $start = microtime(true);
   
   // 执行耗时操作
   heavyOperation();
   
   // 计算并输出执行时间
   $end = microtime(true);
   halt('执行时间：'.($end - $start).'秒');
   ```

这些调试工具函数为开发者提供了便捷的调试手段，帮助快速定位和解决开发过程中的问题。
