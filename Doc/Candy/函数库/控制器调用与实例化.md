# 控制器调用与实例化

## A() - 异步调用控制器类

```php
/**
 * 异步调用控制器类
 *
 * 该函数用于异步实例化并调用控制器类，支持跨应用调用、插件调用，
 * 可在不同应用间或插件间进行无缝切换和调用。
 *
 * @param string|null $className 类名或调用路径，格式可为：控制器/方法 或 应用://控制器/方法
 * @return void
 * @throws Exception 当类不存在或参数无效时可能抛出异常
 */
function A(?string $className = null):void
```

**使用示例**：
- 同应用调用: `A('index/index')` - 调用当前应用的index控制器的index方法
- 跨应用调用: `A('admin://user/login')` - 调用admin应用的user控制器的login方法
- 插件调用: `A('Addon://plugin/action')` - 调用插件的action方法

## M() - 模型实例化函数

```php
/**
 * 模型实例化函数
 *
 * 该函数用于实例化模型类，支持跨应用调用和自定义配置。
 * 可以根据类名自动加载对应的模型文件并初始化实例。
 *
 * @param string $className 类名，支持跨项目格式'项目://类名'
 * @param string|array|null $config 配置信息，支持字符串或数组形式
 * @return object 模型实例
 */
function M(string $className = '',string|array|null $config = []):object
```

**使用示例**：
- 基本使用: `M('User')` - 实例化User模型
- 跨应用调用: `M('Admin://User')` - 实例化Admin应用的User模型
- 自定义配置: `M('User', ['host' => 'localhost'])` - 使用自定义配置实例化模型

## N() - 类实例化

```php
/**
 * 类实例化函数
 *
 * 该函数用于通过容器实例化类，支持自动补全命名空间、依赖注入和单例模式控制，
 * 是框架中创建对象的标准方式。
 *
 * @param string $className 类名
 * @param array $vars 构造函数参数数组
 * @param bool $newInstance 是否创建新实例，默认为false（使用容器中的实例）
 * @param array $invokeFunction 调用方法参数，用于创建实例后立即调用方法
 * @return object|string 返回实例化的对象或类名
 */
function N(string $className = '',array $vars = [],bool $newInstance = false,array $invokeFunction = []): object|string
```

**使用示例**：
- 基本实例化: `N('Util.Helper')` - 实例化Util\Helper类
- 带参数实例化: `N('User', ['name' => 'admin'])` - 带构造参数实例化User类
- 强制创建新实例: `N('Cache', [], true)` - 强制创建新的Cache实例
- 实例化并调用方法: `N('Model.User', [], false, ['find', ['id' => 1]])` - 实例化并调用find方法

## debug() - 切换调试模式

```php
/**
 * 切换调试模式
 *
 * 该函数用于开启或关闭框架的调试模式，控制是否显示详细的调试信息。
 * 调试模式开启时会显示错误详情、SQL执行语句、性能分析等信息，
 * 调试模式关闭时只显示简单的错误提示。
 *
 * @param int $flag 调试模式开关，0表示关闭调试模式，1表示开启调试模式，默认为0
 * @return void 无返回值
 */
function debug(int $flag = 0): void
```

**使用示例**：
- 关闭调试模式: `debug(0)` - 生产环境推荐使用
- 开启调试模式: `debug(1)` - 开发环境推荐使用
- 默认关闭调试: `debug()` - 等价于debug(0)
