# 应用结构与文件引入函数

## 功能说明
应用结构与文件引入函数用于获取应用路径、引入外部文件、查询函数定义等操作，是框架应用结构管理的核心工具。这些函数提供了便捷的应用路径管理和文件引入机制，支持模块化开发和插件扩展。

## 主要函数

### getAppPath() - 应用路径获取

```php
/**
 * 获取应用路径
 * 
 * 该函数用于获取指定应用的路径，支持普通应用和插件应用，
 * 当应用名称为空时返回当前活动应用的路径。
 * 
 * @param string $appName 应用名称，为空时返回当前活动应用的路径
 * @param string|null $type 应用类型，'addon'表示插件应用
 * @return string|bool 应用路径（末尾包含目录分隔符），不存在时返回false
 */
function getAppPath(string $appName = '',?string $type = null):string|bool
```

**功能说明**：
- 获取指定应用的绝对路径
- 支持普通应用和插件应用
- 自动检测应用类型和存在性
- 应用路径末尾包含目录分隔符

**参数说明**：
- `$appName`：应用名称，为空时返回当前活动应用的路径
- `$type`：应用类型，'addon'表示插件应用，默认值为null

**返回值**：
- 成功：返回应用的绝对路径（末尾包含目录分隔符）
- 失败：返回false

**使用示例**：
```php
// 获取当前活动应用的路径
$currentPath = getAppPath();

// 获取指定普通应用的路径
$adminPath = getAppPath('Admin');

// 获取指定插件应用的路径
$pluginPath = getAppPath('MyPlugin', 'addon');
```

### import() - 文件引入

```php
/**
 * 文件引入函数
 *
 * 该函数用于引入外部文件，支持点号分隔的路径格式和特殊路径标识。
 * 主要用于引入框架核心类库、第三方库和自定义组件。
 *
 * @param string $path 文件路径，支持点号分隔的路径格式，@开头表示特殊路径
 * @param string $startpath 起始路径，默认为SOURCEPATH/Vendor/
 * @param string $suffix 文件后缀，默认为.php
 * @return bool 引入成功返回true，失败返回false
 */
function import(string $path,string $startpath = '',string $suffix = '.php'): bool
```

**功能说明**：
- 引入外部PHP文件
- 支持点号分隔的路径格式（如：`Library.Class`）
- 支持特殊路径标识（@开头表示本项目调用）
- 支持自定义起始路径和文件后缀

**参数说明**：
- `$path`：文件路径，支持点号分隔和特殊路径标识
- `$startpath`：起始路径，默认值为`SOURCEPATH/Vendor/`
- `$suffix`：文件后缀，默认值为`.php`

**返回值**：
- 成功：返回true
- 失败：返回false

**使用示例**：
```php
// 引入第三方库
import('PHPMailer.PHPMailer');

// 引入控制器类
import('@.Index');

// 引入模型类
import('@.User');

// 自定义起始路径
import('Custom.Library', '/path/to/libs/', '.class.php');
```

### functionDump() - 函数定义查询

```php
/**
 * 查询函数定义位置
 *
 * 该函数用于查询函数或类方法的定义位置，返回函数名、文件名和行号范围。
 * 主要用于调试和开发环境，帮助开发者定位函数定义。
 *
 * @param string|array $funcname 函数名或类方法数组，格式为[类名, 方法名]
 * @return string 格式化的函数定义位置信息字符串
 */
function functionDump($funcname): string
```

**功能说明**：
- 查询函数或类方法的定义位置
- 返回格式化的函数定义信息
- 支持普通函数和类方法查询
- 包含函数名、文件名和行号范围

**参数说明**：
- `$funcname`：函数名或类方法数组，格式为[类名, 方法名]

**返回值**：
- 返回格式化的函数定义位置信息字符串

**使用示例**：
```php
// 查询普通函数位置
$info = functionDump('session');
// 返回类似: "function session defined by /path/to/global.func.php(3637 - 3717)"

// 查询类方法位置
$info = functionDump(['\Candy\Core\Controller', 'init']);
// 返回类似: "function init defined by /path/to/Controller.php(50 - 75)"
```
