# 安全处理

## takeToken() - CSRF令牌生成

```php
/**
 * 生成并输出CSRF令牌函数
 *
 * 该函数用于生成CSRF（跨站请求伪造）保护令牌，并可选择直接输出为隐藏表单字段
 * 或仅输出生成的令牌值，适用于Web表单提交安全保护。
 *
 * @param bool $input 是否以隐藏表单字段形式输出
 * @param string $name token字段的名称
 * @return void 无返回值
 */
function takeToken(bool $input = true,string $name = 'token'): void
```

**使用示例**：
- 生成隐藏表单字段: `takeToken()` - 输出隐藏token表单字段
- 仅获取token值: `takeToken(false)` - 仅输出生成的token值（用于AJAX）
- 自定义字段名: `takeToken(true, 'csrf_token')` - 使用自定义字段名

## id_encode() - ID加密

```php
/**
 * ID加密函数
 *
 * 该函数用于加密ID值，生成一个看起来像随机字符串的编码，
 * 适用于URL参数加密、防止ID遍历等场景。
 *
 * @param int $string 原始ID值
 * @return string 加密后的ID字符串
 */
function id_encode(int $string): string
```

**使用示例**：
- 加密URL参数: `$url = '/user/edit?id=' . id_encode(123)` - 加密ID后生成URL

## id_decode() - ID解密

```php
/**
 * ID解密函数
 *
 * 该函数用于解密由id_encode()加密的ID值，适用于URL参数加密、
 * 敏感ID保护等场景。
 *
 * @param string $string 加密的ID字符串
 * @return int 解密后的ID值
 */
function id_decode(string $string): int
```

**使用示例**：
- 解密URL参数: `$realId = id_decode($_GET['id'])` - 解密URL中的ID参数

## safeReplace() - 安全替换

```php
/**
 * 安全字符串替换函数
 *
 * 该函数用于安全地替换字符串中的特定内容，支持HTML实体转换，
 * 适用于防止XSS攻击和安全内容处理。
 *
 * @param string $string 原始字符串
 * @param array|string $search 要查找的内容
 * @param array|string $replace 替换的内容
 * @param int $flags 替换标志
 * @return string 替换后的字符串
 */
function safeReplace(string $string,array|string $search,array|string $replace,int $flags = 0): string
```

**使用示例**：
- 安全替换: `$safeHtml = safeReplace($html, ['<script', '</script>'], ['&lt;script', '&lt;/script&gt;'])` - 移除脚本标签

## IP地址管理

### addIPList() - 添加IP到名单

```php
/**
 * 添加IP到黑名单或白名单
 *
 * 该函数用于将IP地址添加到系统的黑名单或白名单中，支持单个IP和IP数组，
 * 可设置过期时间。主要用于IP访问控制和安全过滤场景。
 *
 * @param string $type 名单类型，'b'表示黑名单，'w'表示白名单，默认为'b'
 * @param string|array $ip 要添加的IP地址，支持单个IP和IP数组
 * @param int $exp_time 过期时间（秒），0表示永不过期，默认为0
 * @return bool 添加成功返回true，失败返回false
 */
function addIPList(string $type = 'b', string|array $ip = '',int $exp_time = 0):bool
```

**使用示例**：
- 添加单个IP到黑名单: `addIPList('b', '192.168.1.100')` - 阻止指定IP访问
- 添加多个IP到白名单: `addIPList('w', ['10.0.0.1', '10.0.0.2'], 86400)` - 允许指定IP访问1天

### checkIP() - IP地址检查

```php
/**
 * 检查IP是否在指定的黑名单或白名单中
 *
 * 该函数用于验证IP地址是否存在于系统的黑名单或白名单中，
 * 可用于IP访问控制和安全过滤。
 *
 * @param string $type 名单类型，'b'表示黑名单，'w'表示白名单，默认为'b'
 * @param string $ip 要检查的IP地址，默认为空字符串（将使用当前访问者IP）
 * @return bool 如果IP在指定名单中返回true，否则返回false
 */
function checkIP(string $type = 'b',string $ip = ''): bool
```

**使用示例**：
- 检查IP是否在黑名单: `checkIP('b', '192.168.1.100')` - 检查指定IP是否被禁止
- 检查当前访问者IP: `checkIP('w')` - 检查当前用户IP是否在白名单中

### cleanIPList() - 清除IP名单

```php
/**
 * 清除IP名单表中的记录
 *
 * 该函数用于清理系统中的IP黑名单或白名单记录，
 * 可选择性地清除特定类型的名单或全部名单。
 *
 * @param string $type 名单类型，'b'表示黑名单，'w'表示白名单，空字符串表示所有类型，默认为空
 * @param bool $reset 是否重置标识，true表示重置（完全清除），false表示常规清除，默认为false
 * @return void 无返回值
 */
function cleanIPList(string $type = '',bool $reset = false): void
```

**使用示例**：
- 清除所有黑名单: `cleanIPList('b')` - 清除所有黑名单记录
- 清除所有白名单: `cleanIPList('w')` - 清除所有白名单记录
- 清除所有IP名单: `cleanIPList()` - 清除所有IP名单记录
- 重置并清除黑名单: `cleanIPList('b', true)` - 完全重置并清除黑名单

### delIPList() - 删除IP名单记录

```php
/**
 * 删除IP名单表中的记录
 *
 * 该函数用于从系统的黑名单或白名单中删除指定的IP地址记录，
 * 支持单个IP和IP数组，并可设置过期时间条件。
 *
 * @param string $type 名单类型，'b'表示黑名单，'w'表示白名单，默认为'b'
 * @param string $ip 要删除的IP地址，支持单个IP和IP数组
 * @param int $exp_time 过期时间条件，0表示删除所有匹配IP，默认为0
 * @return bool 删除成功返回true，失败返回false
 */
function delIPList(string $type = 'b', string $ip = '', int $exp_time = 0):bool
```

**使用示例**：
- 从黑名单删除单个IP: `delIPList('b', '192.168.1.100')` - 允许指定IP重新访问
- 从白名单删除多个IP: `delIPList('w', ['10.0.0.1', '10.0.0.2'])` - 禁止指定IP访问

### getIPList() - 获取IP名单

```php
/**
 * 获取IP名单表中的记录
 *
 * 该函数用于获取系统的黑名单或白名单记录，
 * 支持获取指定类型的名单或全部名单。
 *
 * @param string $type 名单类型，'b'表示黑名单，'w'表示白名单，默认为'b'
 * @return array IP名单记录数组
 */
function getIPList(string $type = 'b'):array
```

**使用示例**：
- 获取所有黑名单: `$blacklist = getIPList('b')` - 获取所有黑名单IP
- 获取所有白名单: `$whitelist = getIPList('w')` - 获取所有白名单IP
