## G() - 全局变量操作函数

全局变量操作函数，用于获取和设置系统全局变量，可用于访问系统配置和状态信息。

### 函数签名

```php
function G(mixed $name = null, mixed $value = '', mixed $default = null)
```

### 参数说明

- `$name`: 变量名或变量路径，支持点号分隔的嵌套路径，为空时返回所有全局变量
- `$value`: 要设置的变量值，为空字符串时表示获取变量
- `$default`: 获取变量时的默认值，当变量不存在时返回

### 返回值

- 获取变量时返回变量值或默认值
- 设置变量时返回设置的值

### 使用示例

```php
// 获取单个全局变量
$appName = G('appName');

// 获取嵌套路径的变量
$dbHost = G('cfgs.db.host');

// 设置全局变量
G('appEnv', 'production');

// 设置嵌套路径的变量
G('cfgs.debug', true);

// 获取所有全局变量
$allGlobals = G();
```

## getLocalIP() - 获取服务器IP地址

获取当前服务器的IP地址，优先从`$_SERVER`数组中获取，如果不存在则通过`gethostbyname`和`gethostname`函数获取。

### 函数签名

```php
function getLocalIP(string $host = ''): string
```

### 参数说明

- `$host`: 可选的主机名参数，默认为空

### 返回值

返回服务器的IP地址字符串

### 使用示例

```php
// 获取默认服务器IP
$serverIP = getLocalIP();

// 获取指定主机名的IP
$exampleIP = getLocalIP('example.com');
```

## isWebServer() - Web服务器环境检测

检测当前是否处于Web服务器环境，通过检查CLIWORKING常量和GATEWAY_CLIENT_ID服务器变量进行判断。

### 函数签名

```php
function isWebServer()
```

### 返回值

如果是Web服务器环境返回`true`，否则返回`false`

### 使用示例

```php
// 根据运行环境执行不同逻辑
if (isWebServer()) {
    // Web环境下的操作
    echo 'This is running in a web server environment';
} else {
    // CLI环境下的操作
    echo 'This is running in a command-line environment';
}
```

## isMobile() - 移动设备检测

检测当前访问的设备是否为移动设备，通过多重方式进行判断，包括HTTP头信息、User-Agent字符串分析等。

### 函数签名

```php
function isMobile(): bool
```

### 返回值

如果是移动设备返回`true`，否则返回`false`

### 使用示例

```php
// 根据设备类型显示不同内容
if (isMobile()) {
    // 显示移动端内容或模板
    $template = 'mobile/index.html';
} else {
    // 显示PC端内容或模板
    $template = 'pc/index.html';
}

// 在模板路径初始化时使用
$templatePath = isMobile() ? 'views/mobile/' : 'views/pc/';
```

## isSsl() - SSL协议检测

检测当前请求是否通过HTTPS/SSL协议进行访问，支持多种判断方式，包括检查SERVER变量和系统配置。

### 函数签名

```php
function isSsl(): bool
```

### 返回值

如果使用SSL协议返回`true`，否则返回`false`

### 使用示例

```php
// 根据协议生成不同的URL
$protocol = isSsl() ? 'https://' : 'http://';
$fullUrl = $protocol . $_SERVER['HTTP_HOST'] . $_SERVER['REQUEST_URI'];

// 在URL生成函数中使用
function generateSecureUrl($path) {
    $base = isSsl() ? 'https://' : 'http://';
    return $base . $_SERVER['HTTP_HOST'] . $path;
}
```

## isWinOS() - Windows操作系统检测

检测当前服务器运行的操作系统是否为Windows系列，通过检查PHP_OS常量进行判断，忽略大小写差异。

### 函数签名

```php
function isWinOS(): bool
```

### 返回值

如果是Windows操作系统返回`true`，否则返回`false`

### 使用示例

```php
// 根据操作系统执行不同的文件操作
if (isWinOS()) {
    // Windows路径分隔符处理
    $path = str_replace('/', '\\', $path);
} else {
    // 类Unix系统路径处理
    $path = str_replace('\\', '/', $path);
}

// 操作系统特定配置
$config = [
    'temp_dir' => isWinOS() ? 'C:/tmp/' : '/tmp/',
    'line_ending' => isWinOS() ? "\r\n" : "\n"
];
```
