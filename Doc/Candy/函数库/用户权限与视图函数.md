# 用户权限与视图函数

## applyUserAuth

```php
/**
 * 应用用户权限到节点
 *
 * 该函数用于将用户权限应用到节点系统中，通常在用户登录或权限变更时调用，
 * 用于更新用户的访问权限缓存。该函数是Node类的静态方法applyUserAuth的封装。
 *
 * 使用示例：
 * - 应用用户权限: applyUserAuth(['user_view', 'user_edit'])
 * - 强制刷新权限: applyUserAuth(['user_view', 'user_edit'], true)
 *
 * @param array $auths 权限节点数组，包含用户拥有的权限标识
 * @param bool $force 是否强制刷新权限缓存，默认为false
 * @return array 返回处理后的权限节点数组
 */
function applyUserAuth(array $auths = [], bool $force = false): array
```

## assign

```php
/**
 * 将变量数组分配到视图变量中
 *
 * 该函数用于将一组变量分配到视图变量数组中，
 * 支持变量提取并特殊处理函数名形式的变量。
 * 主要用于视图渲染前的数据准备阶段。
 *
 * 使用示例：
 * - 分配普通变量: assign(['var' => 'title', 'value' => '首页'], $viewVars)
 * - 调用数据函数: assign(['var' => 'articles', 'value' => 'cmsData', 'source' => 'article'], $viewVars)
 *
 * @param array $params 模板 assign 参数，必须包含 var 和 value
 * @param array $viewVars 视图变量数组的引用，分配的变量将存储在这里
 * @return void 无返回值
 * @note value 为已注册函数名时，移除 var/value 后将其余标签参数传给该函数
 */
function assign(array $params, &$viewVars): void
```
