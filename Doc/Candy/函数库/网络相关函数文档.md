# 网络相关函数文档

## 1. URL 处理函数

### U - URL 组装函数

```php
function U(...$params): string
```

**功能说明**：
该函数是框架的核心 URL 生成器，用于根据 URL 表达式和参数组装生成各种格式的 URL。支持 PATHINFO、REWRITE、GET 等多种 URL 模式，并兼容各种特殊格式的 URL 构建需求。

**参数说明**：
- `$params`：可变参数列表，支持多种传参方式：
  - 单参数模式: `U('Index/index')`
  - 双参数模式: `U('Index/index', ['id' => 1])`
  - 数组模式: `U(['Index/index', ['id' => 1], 'html', true])`

**返回值**：
- `string`：组装好的 URL 字符串

**使用示例**：
```php
// 返回当前 URL
$currentUrl = U();

// 基本 URL 生成
$basicUrl = U('Index/index');

// 带参数的 URL
$paramUrl = U('User/detail', ['id' => 1]);

// 带锚点和域名的 URL
$anchorUrl = U('Article/read#section1@blog.example.com');

// 跨应用的 URL
$crossAppUrl = U('Admin://User/index');

// 二维数组参数方式
$arrayUrl = U(['Index/index', ['id' => 1], 'html', true]);
```

**Api 统一前缀（`API_URL`）**

当处于 Api 模式且 `Source/Inc/Route.inc.php` 中配置了 `API_URL.prefix` 时，`U()` 会在 PATHINFO 路径上自动追加前缀（已含前缀则不重复）。强制生成绝对地址时，若配置了 `API_URL.domain` 且未写显式 `@域名`，则优先使用 Api 专用域名。

```php
// 配置见 Route.inc.php → API_URL / URL_ROUTE_RULES 入站剥前缀
// 入站 /api/v1/... 会自动 API_URL_MODE；也可手动：
C('API_URL_MODE', true);
$url = U('Crm/User/list.json');           // → /api/v1/Crm/User/list.json
$abs = U('/Crm/User/list.json');          // → https://{API_URL.domain}/api/v1/Crm/...
$fix = U('Crm/User/list.json@other.com'); // 显式域名优先，仍可带前缀
```

完整说明见 [路由使用 · Api 统一前缀](../框架使用/路由使用.md#43-api-统一前缀api_url)。

## 2. HTTP 响应处理函数

### apiDate - 设置 API 响应数据

```php
function apiDate(array $data): array
```

**功能说明**：
该函数用于设置 API 响应数据到系统全局变量中，并同时返回传入的数据数组，方便链式调用。主要用于 API 接口开发场景，确保响应数据被正确记录和处理。

**参数说明**：
- `$data`：API 响应数据数组，通常包含 code、message 和 data 等字段

**返回值**：
- `array`：返回传入的数据数组，便于链式调用

**使用示例**：
```php
// 设置 API 响应数据
apiDate(['code' => 200, 'message' => 'success', 'data' => $result]);

// 链式调用
return apiDate(['code' => 200, 'message' => 'success']);

// 错误响应
return apiDate(['code' => 400, 'message' => '参数错误']);
```

### headerLoading - HTTP 头信息处理

```php
function headerLoading(string $info, int $code = 0, string $body = ''): void
```

**功能说明**：
用于设置 HTTP 头信息、状态码和响应体内容，支持页面跳转、内容类型设置等功能。自动适配 Web 服务器环境和 CLI 环境。

**参数说明**：
- `$info`：头信息内容，如 'Content-Type: application/json' 或 'location: /new/page'
- `$code`：HTTP 状态码，如 200、404、302 等，默认为 0
- `$body`：响应体内容，默认为空

**返回值**：
- `void`：无返回值

**使用示例**：
```php
// 设置内容类型
headerLoading('Content-Type: application/json');

// 执行页面跳转
headerLoading('location: /new/page');

// 设置状态码
headerLoading('Not Found', 404);

// 在 Web 环境下设置状态码和响应体
headerLoading('', 200, 'Success message');
```

## 3. 数据格式转换函数

### json - JSON 编码与解码

```php
function json(mixed $data, string $type = 'en'): mixed
```

**功能说明**：
提供 JSON 数据的编码和解码功能，支持中文编码，兼容各种数据类型。

**参数说明**：
- `$data`：要处理的数据，编码时可以是任意类型，解码时应为 JSON 字符串
- `$type`：操作类型，'en' 表示编码（默认），非 'en' 表示解码

**返回值**：
- `mixed`：编码时返回 JSON 字符串，解码时返回 PHP 数组

**使用示例**：
```php
// JSON 编码
$jsonString = json(['name' => '张三', 'age' => 25]);
// 输出: {"name":"张三","age":25}

// JSON 解码
$array = json($jsonString, 'de');
// 输出: ['name' => '张三', 'age' => 25]

// 编码特殊值
json(null);  // 返回: "null"
json(true);  // 返回: "true"
json(false); // 返回: "false"
```

## 4. 远程通信函数

### rpc - 框架 Rpc 客户端

```php
function rpc(string $serverName, array $config = []): object
```

**功能说明**：
初始化并返回指定服务名的 Rpc 客户端代理。协议由 `Source/Inc/Rpc.inc.php` 的 `protocol`（`auto|json|bin`）决定；`auto` 时 DEBUG 用 JSON 帧、生产用 Binary 帧。服务端按帧自动识别。

**参数说明**：
- `$serverName`：服务名（对应 `Application/{App}/Rpc` 或 `Rpc.inc.php` 白名单）
- `$config`：地址列表 `['tcp://127.0.0.1:2020']`，或选项数组（`address`/`protocol`/`name`/`version`）

**返回值**：
- `object`：`Candy\Extend\Rpc\Client` 代理，可魔术调用远程方法

**使用示例**：
```php
$client = rpc('Ping', ['tcp://127.0.0.1:2020', 'protocol' => 'json']);
$ret = $client->echo('hello');
$sum = $client->add(1, 2);
```

## 5. 网络请求辅助函数

### get_client_ip - 获取客户端 IP 地址

```php
function get_client_ip(): string
```

**功能说明**：
获取当前请求的客户端 IP 地址，支持多种代理环境。

**返回值**：
- `string`：客户端 IP 地址字符串

**使用示例**：
```php
// 获取客户端 IP 地址
$clientIp = get_client_ip();
```

### objToArray - 对象转数组函数

```php
function objToArray($obj): array
```

**功能说明**：
递归将对象转换为数组，支持多层嵌套结构。

**参数说明**：
- `$obj`：要转换的对象或数组

**返回值**：
- `array`：转换后的数组

**使用示例**：
```php
// 转换单个对象
$object = new stdClass();
$object->name = '张三';
$object->age = 25;
$array = objToArray($object);
// 结果: ['name' => '张三', 'age' => 25]

// 转换嵌套对象
$nestedObj = new stdClass();
$nestedObj->user = $object;
$nestedObj->status = 'active';
$nestedArray = objToArray($nestedObj);
// 结果: ['user' => ['name' => '张三', 'age' => 25], 'status' => 'active']

// 转换数组中的对象
$mixedArray = ['user' => $object, 'id' => 1];
$convertedArray = objToArray($mixedArray);
// 结果: ['user' => ['name' => '张三', 'age' => 25], 'id' => 1]
```

## 6. 网页镜像功能函数

### getMirContents - 获取镜像内容

```php
function getMirContents(string $url, array $config): array
```

**功能说明**：
获取指定 URL 的网页镜像内容，支持多种缓存配置和客户端类型（PC/移动）。

**参数说明**：
- `$url`：要获取镜像的目标 URL
- `$config`：配置数组，支持以下选项：
  - `dir`：保存目录，默认为主机名或 MD5 后的主机名
  - `suffix`：文件后缀，默认为 '.php'
  - `exp_time`：过期时间，默认为 3600 秒
  - `site_mode`：站点模式，'pc'、'mobile' 或 'auto'（自动检测）

**返回值**：
- `array`：包含状态（'expired' 或 'hit'）和内容的数组

**使用示例**：
```php
// 获取网页镜像内容
$mirrorConfig = [
    'dir' => 'example_com',
    'exp_time' => 7200,
    'site_mode' => 'auto'
];
$mirrorContents = getMirContents('https://www.example.com/page', $mirrorConfig);

// 处理结果
if ($mirrorContents['status'] === 'expired') {
    // 内容已过期，需要重新获取
} else {
    // 使用缓存的镜像内容
    $content = $mirrorContents['content'];
}
```

### makeMirForSave - 保存网页镜像

```php
function makeMirForSave($url, $config = []): void
```

**功能说明**：
将指定 URL 的网页内容保存为镜像，支持自动替换链接和适应不同客户端类型。

**参数说明**：
- `$url`：要保存镜像的目标 URL
- `$config`：配置数组，与 getMirContents 函数相同

**返回值**：
- `void`：无返回值

**使用示例**：
```php
// 保存网页镜像
$mirrorConfig = [
    'dir' => 'example_com',
    'exp_time' => 7200
];
makeMirForSave('https://www.example.com/page', $mirrorConfig);

// 保存移动版本镜像
$mobileConfig = [
    'dir' => 'example_com_mobile',
    'site_mode' => 'mobile'
];
makeMirForSave('https://www.example.com/mobile/page', $mobileConfig);
```

### get_user_agent - 获取用户代理信息

**功能说明**：
获取当前请求的用户代理（User-Agent）信息，用于识别客户端浏览器和设备类型。

**使用示例**：
```php
// 获取用户代理信息
$userAgent = get_user_agent();

// 判断是否为移动设备
if (strpos($userAgent, 'Mobile') !== false) {
    // 移动设备处理逻辑
}
```

## 6. 网络安全相关函数

### http_status - HTTP 状态码处理

**功能说明**：
