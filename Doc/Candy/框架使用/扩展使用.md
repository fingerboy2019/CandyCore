# Candy框架扩展使用指南

## 1. 扩展概述

Candy框架的扩展系统允许开发者在不修改框架核心代码的情况下，添加新的功能模块。扩展可以是独立的功能单元，如插件、组件或模块，它们可以被应用程序灵活地加载和使用。

## 2. 扩展目录结构

扩展通常位于`ADDONPATH`目录下，默认情况下为项目根目录下的`Addon`文件夹。每个扩展都有自己独立的目录，其基本结构如下：

```
Addon/
└── [扩展名称]/
    ├── conf.php          # 扩展配置文件
    ├── Controls/         # 控制器目录
    │   ├── Common.class.php  # 公共控制器
    │   └── Index.class.php   # 主控制器
    ├── Models/           # 模型目录
    ├── Views/            # 视图目录
    └── Statics/          # 静态资源目录
```

## 3. 扩展配置文件

每个扩展必须包含一个`conf.php`配置文件，用于定义扩展的基本信息和设置：

```php

return [
    'name'        => '扩展名称',
    'title'       => '扩展标题',
    'description' => '扩展描述',
    'author'      => '开发者名称',
    'version'     => '1.0.0',
    'enable'      => 1,      // 是否启用扩展
    'auth'        => [],     // 权限配置
];
```

## 4. 扩展的创建

### 4.1 使用Build类创建扩展

Candy框架提供了`Build`类来帮助开发者快速创建扩展结构：

```php
// 创建一个名为Demo的扩展
Build::addon('Demo');
```

### 4.2 手动创建扩展

1. 在`ADDONPATH`目录下创建扩展目录
2. 创建`conf.php`配置文件
3. 创建必要的控制器、模型和视图目录
4. 实现扩展的核心功能

## 5. 扩展的控制器

扩展的控制器位于`Controls`目录下，需要继承自`Base`类：

```php
namespace APP\Addon\[扩展名称];

defined('CANDY') OR die('You Are A Bad Guy. o_O???');

// 公共控制器
Class Common extends Base {
    function init() {
        // 初始化操作
    }
}

// 主控制器
Class Index extends Common {
    function index() {
        // 扩展的默认方法
    }
}
```

## 6. 扩展的使用

### 6.1 检查扩展是否存在

使用`Addon`类的`checkAddon`方法检查扩展是否存在：

```php
// 检查Demo扩展是否存在
if (Addon::checkAddon('Demo')) {
    // 扩展存在，可以使用
}
```

### 6.2 获取启用的扩展列表

使用`Addon`类的`getEnableAddons`方法获取所有启用的扩展：

```php
// 获取所有启用的扩展
$addons = Addon::getEnableAddons();
foreach ($addons as $addon) {
    echo $addon['name'] . ' - ' . $addon['title'] . '<br>';
}
```

### 6.3 调用扩展的方法

通过URL访问扩展的控制器和方法：

```
http://example.com/[入口文件]/Addon/[扩展名称]/[控制器]/[方法]
```

例如：
```
http://example.com/index.php/Addon/Demo/Index/index
```

### 6.4 在应用中嵌入扩展

在应用的视图中嵌入扩展的内容：

```php
// 在模板中嵌入Demo扩展的内容
$this->addon('Demo', 'Index', 'index');
```

## 7. 扩展的权限管理

### 7.1 定义扩展权限

在扩展的`conf.php`配置文件中定义权限：

```php

return [
    // ...
    'auth' => [
        'view' => ['title' => '查看权限', 'description' => '允许查看扩展内容'],
        'edit' => ['title' => '编辑权限', 'description' => '允许编辑扩展内容'],
    ],
];
```

### 7.2 检查扩展权限

使用`Addon`类的`getAddonAuth`方法检查当前用户是否有扩展的权限：

```php
// 检查当前用户是否有Demo扩展的view权限
if (Addon::getAddonAuth('Demo', 'view')) {
    // 用户有查看权限
} else {
    // 用户没有查看权限
}
```

## 8. 扩展的启用与禁用

### 8.1 启用扩展

修改扩展的`conf.php`配置文件，将`enable`设置为1：

```php

return [
    // ...
    'enable' => 1,
    // ...
];
```

### 8.2 禁用扩展

修改扩展的`conf.php`配置文件，将`enable`设置为0：

```php

return [
    // ...
    'enable' => 0,
    // ...
];
```

## 9. 扩展开发最佳实践

1. **保持独立性**：扩展应该尽量独立，减少对其他扩展或核心框架的依赖
2. **命名规范**：遵循Candy框架的命名规范，使用驼峰命名法
3. **权限控制**：为扩展添加适当的权限控制，确保安全
4. **文档完善**：为扩展编写详细的文档，方便其他开发者使用
5. **版本控制**：使用版本控制管理扩展的代码，方便升级和维护

## 10. 扩展示例

以下是一个简单的Demo扩展示例：

### 10.1 配置文件

`Addon/Demo/conf.php`：

```php

return [
    'name'        => 'Demo',
    'title'       => '示例扩展',
    'description' => '这是一个Candy框架的示例扩展',
    'author'      => 'Candy Team',
    'version'     => '1.0.0',
    'enable'      => 1,
    'auth'        => [
        'view' => ['title' => '查看权限', 'description' => '允许查看示例内容'],
    ],
];
```

### 10.2 控制器

`Addon/Demo/Controls/Common.class.php`：

```php

namespace APP\Addon\Demo;

defined('CANDY') OR die('You Are A Bad Guy. o_O???');

Class Common extends Base {
    function init() {
        // 初始化操作
    }
}
```

`Addon/Demo/Controls/Index.class.php`：

```php

namespace APP\Addon\Demo;

defined('CANDY') OR die('You Are A Bad Guy. o_O???');

Class Index extends Common {
    function index() {
        $this->assign('message', 'Hello from Demo Addon!');
        $this->display('index');
    }
}
```

### 10.3 视图

`Addon/Demo/Views/index.html`：

```html
<!DOCTYPE html>
<html>
<head>
    <title>Demo Addon</title>
</head>
<body>
    <h1>示例扩展</h1>
    <p>{$message}</p>
</body>
</html>
```

## 11. 扩展的生命周期

1. **加载配置**：框架加载扩展的配置文件
2. **初始化**：调用扩展的`init`方法进行初始化
3. **执行操作**：根据URL请求执行相应的控制器和方法
4. **渲染视图**：渲染扩展的视图并输出结果

## 12. 扩展的调试与维护

### 12.1 调试扩展

1. 确保扩展的`enable`配置为1
2. 检查扩展的目录结构和文件权限
3. 查看框架的错误日志，定位问题

### 12.2 维护扩展

1. 定期更新扩展的版本
2. 修复扩展的bug和安全漏洞
3. 优化扩展的性能
4. 更新扩展的文档

## 13. 扩展的卸载

要卸载扩展，只需删除扩展的目录即可：

```bash
rm -rf ADDONPATH/[扩展名称]
```

## 14. 总结

Candy框架的扩展系统提供了一种灵活的方式来扩展框架的功能。通过本文档，您应该了解了扩展的创建、配置、使用和维护方法。在实际开发中，您可以根据需要创建各种扩展，以满足不同的业务需求。
