## 控制器基础

### 目录结构

控制器文件需存放在项目目录的 `Controller` 子目录下：

```
Application/
└── Controller/
    ├── Index.class.php      # 默认控制器（首页）
    ├── User.class.php       # 用户控制器
    └── Article.class.php   # 文章控制器
```

### 命名规范

- **文件名**：使用大驼峰命名法（PascalCase）
  - `Index.class.php`
  - `User.class.php`
  - `ArticleManager.class.php`

- **类名**：与文件名保持一致
- **方法名**：使用小写字母和下划线

### 类定义

控制器类需继承 `Candy\Core\Action` 基类，并包含公共方法作为请求处理入口：

```php
<?php
namespace App\Controller;

use Candy\Core\Action;

class Index extends Action
{
    /**
     * 处理 / 请求
     * 对应 URL: http://domain.com/
     */
    public function index()
    {
        $this->assign('message', '欢迎使用 Candy 框架');
        $this->display();
    }

    /**
     * 处理 /demo 请求
     * 对应 URL: http://domain.com/demo
     */
    public function demo()
    {
        $this->assign('title', 'Demo 页面');
        $this->display();
    }
}
```

## 请求处理

### 获取请求参数

通过 `$this->request` 对象获取请求参数：

```php
// 获取 GET 参数
$id = $this->request->get('id', 0);           // 默认值
$name = $this->request->get('name');           // 无默认值

// 获取 POST 参数
$username = $this->request->post('username', '');
$email = $this->request->post('email');

// 获取所有请求参数（合并 GET/POST）
$params = $this->request->all();

// 获取 Cookie
$theme = $this->request->cookie('theme', 'default');

// 获取服务器变量
$ip = $this->request->server('REMOTE_ADDR');
$user_agent = $this->request->server('HTTP_USER_AGENT');
```

### 请求验证

使用 `$this->request` 验证请求数据：

```php
// 验证必填字段
if (!$this->request->has('username')) {
    $this->error('用户名不能为空');
}

// 验证邮箱格式
$email = $this->request->post('email');
if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
    $this->error('邮箱格式不正确');
}

// 验证整数
$age = $this->request->post('age');
if (!is_numeric($age) || $age < 0) {
    $this->error('年龄必须是非负整数');
}

// 验证数组
$tags = $this->request->post('tags');
if (!is_array($tags)) {
    $this->error('标签必须是数组');
}
```

### 数据过滤

使用 `$this->filter` 对数据进行过滤：

```php
// 过滤字符串
$name = $this->filter->text($_POST['name']);

// 过滤 HTML 标签
$content = $this->filter->xss($_POST['content']);

// 过滤数组
$tags = $this->filter->array($_POST['tags']);

// 过滤整数
$age = $this->filter->integer($_POST['age']);

// 过滤浮点数
$price = $this->filter->float($_POST['price']);
```

## 视图渲染

### 分配数据

通过 `assign` 方法将数据传递给视图模板：

```php
// 单个变量
$this->assign('user', [
    'name' => '张三',
    'age' => 25
]);

// 批量分配
$this->assign([
    'title' => '用户信息',
    'list' => [1, 2, 3],
    'page' => 1
]);

// 直接输出
echo $this->assign('message', 'Hello World');
```

### 渲染模板

默认从 `Views` 目录加载模板文件，支持指定模板路径：

```php
// 渲染当前控制器对应的模板（如 Index/index.html）
$this->display();

// 渲染指定模板
$this->display('user/detail.html');

// 渲染其他控制器的模板
$this->display('User/list.html');

// 渲染其他项目的模板
$this->display('Admin/User/index.html');
```

### 模板继承

使用模板继承实现代码复用：

```php
// base.html
{extends name="base"}
{block name="content"}
    <h1>子页面内容</h1>
{/block}

// index.html
{extends name="base"}
{block name="content"}
    <h1>首页内容</h1>
    {foreach $items as $item}
        {$item.name}
    {/foreach}
{/block}
```

## 响应处理

### 重定向

使用 `redirect` 方法跳转页面：

```php
// 跳转到当前项目的其他控制器方法
$this->redirect('User/profile');

// 跳转到指定参数
$this->redirect('User/profile', ['id' => 1]);

// 跳转到绝对 URL
$this->redirect('https://example.com');

// 带参数跳转
$this->redirect('https://example.com', ['token' => $token]);
```

### 输出 JSON

需要返回 API 接口时，使用 `json` 方法：

```php
// 简单响应
$this->json(['code' => 200, 'msg' => '成功']);

// 带数据
$this->json([
    'code' => 200,
    'msg' => '获取成功',
    'data' => [
        'id' => 1,
        'name' => '张三'
    ]
]);

// 错误响应
$this->json([
    'code' => 400,
    'msg' => '参数错误'
], 400);
```

### 退出程序

使用 `exit` 方法终止程序执行：

```php
// 正常退出
$this->exit();

// 退出并跳转
$this->exit('User/profile');

// 退出并显示错误
$this->exit('操作失败', 400);
```

## 常见场景

### 列表页面

```php
<?php
namespace App\Controller;

use Candy\Core\Action;

class Article extends Action
{
    /**
     * 文章列表
     */
    public function index()
    {
        // 获取分页参数
        $page = I('get.page', 1);
        $pageSize = I('get.pageSize', 20);

        // 获取查询条件
        $where = [];
        if (!empty(I('get.title'))) {
            $where['title'] = '%' . I('get.title') . '%';
        }

        // 查询数据
        $articles = D('Article')->where($where)
            ->page($page, $pageSize)
            ->select();

        // 获取总数
        $total = D('Article')->where($where)->count();

        // 分配数据
        $this->assign('articles', $articles);
        $this->assign('total', $total);
        $this->assign('page', $page);

        // 渲染列表模板
        $this->display('list');
    }
}
```

### 详情页

```php
<?php
namespace App\Controller;

use Candy\Core\Action;

class Article extends Action
{
    /**
     * 文章详情
     */
    public function detail()
    {
        // 获取文章 ID
        $id = I('get.id');

        // 参数验证
        if (!$id) {
            $this->error('文章 ID 不能为空');
        }

        // 查询文章
        $article = D('Article')->find($id);

        // 检查是否存在
        if (!$article) {
            $this->error('文章不存在');
        }

        // 分配数据
        $this->assign('article', $article);

        // 渲染详情页
        $this->display('detail');
    }
}
```

### 表单提交

```php
<?php
namespace App\Controller;

use Candy\Core\Action;

class Article extends Action
{
    /**
     * 添加文章（GET 请求显示表单）
     */
    public function add()
    {
        if ($_SERVER['REQUEST_METHOD'] === 'GET') {
            $this->display();
            return;
        }

        // 获取提交数据
        $post = I('post.');

        // 数据验证
        if (empty($post['title'])) {
            $this->error('标题不能为空');
        }

        if (empty($post['content'])) {
            $this->error('内容不能为空');
        }

        // 保存数据
        D('Article')->add($post);

        // 成功跳转
        $this->success('添加成功', 'index');
    }
}
```

### API 接口

```php
<?php
namespace App\Controller;

use Candy\Core\Action;

class Api extends Action
{
    /**
     * 用户登录接口
     */
    public function login()
    {
        // 获取登录信息
        $username = I('post.username');
        $password = I('post.password');

        // 验证参数
        if (empty($username) || empty($password)) {
            $this->json(['code' => 400, 'msg' => '参数错误'], 400);
        }

        // 验证用户
        $user = D('User')->authenticate($username, $password);

        if (!$user) {
            $this->json(['code' => 401, 'msg' => '用户名或密码错误'], 401);
        }

        // 生成 Token
        $token = md5($user['uid'] . time());

        // 返回 Token
        $this->json([
            'code' => 200,
            'msg' => '登录成功',
            'data' => [
                'token' => $token,
                'user' => $user
            ]
        ]);
    }

    /**
     * 获取用户信息
     */
    public function info()
    {
        // 获取 Token
        $token = I('get.token');

        // 验证 Token
        if (empty($token)) {
            $this->json(['code' => 401, 'msg' => 'Token 不能为空'], 401);
        }

        // 获取用户信息
        $user = D('User')->getTokenUser($token);

        if (!$user) {
            $this->json(['code' => 401, 'msg' => 'Token 无效'], 401);
        }

        // 返回用户信息
        $this->json([
            'code' => 200,
            'data' => $user
        ]);
    }
}
```

## 最佳实践

### 1. 单一职责原则

每个控制器方法应只处理一个业务功能：

```php
// ❌ 不好：一个方法处理多个功能
public function index()
{
    // 处理列表
    if (!I('get.action')) {
        $this->list();
        return;
    }
    // 处理详情
    $this->detail();
}

// ✅ 好：分离方法
public function list()
{
    // 处理列表逻辑
}

public function detail()
{
    // 处理详情逻辑
}
```

### 2. 数据验证前置

在业务逻辑之前进行数据验证：

```php
public function update()
{
    // 1. 验证参数
    if (empty(I('post.id'))) {
        $this->error('ID 不能为空');
    }

    // 2. 获取数据
    $id = I('post.id');
    $user = D('User')->find($id);

    if (!$user) {
        $this->error('用户不存在');
    }

    // 3. 更新数据
    D('User')->update($id, I('post.'));

    // 4. 返回结果
    $this->success('更新成功');
}
```

### 3. 异常处理

使用 try-catch 捕获异常：

```php
public function export()
{
    try {
        // 导出数据
        $data = D('User')->select();
        $file = $this->exportToExcel($data);

        $this->success('导出成功', $file);
    } catch (\Exception $e) {
        $this->error('导出失败：' . $e->getMessage());
    }
}
```

### 4. 使用助手方法

框架提供多个助手方法简化操作：

```php
// 获取当前请求
$request = I();

// 获取参数
$id = I('get.id');

// 获取 POST 数据
$name = I('post.name');

// 获取 Cookie
$theme = I('cookie.theme');

// 获取服务器变量
$ip = I('server.remote_addr');
```
