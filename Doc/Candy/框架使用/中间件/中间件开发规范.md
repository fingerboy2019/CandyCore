# Candy 框架中间件开发规范

## 目录结构

所有中间件统一存放在 `/www/wwwroot/candy/Source/Middleware/` 目录下，便于统一管理。

```
Source/
├── Middleware/
│   ├── JwtAuthMiddleware.class.php      # JWT 认证中间件
│   ├── LogMiddleware.class.php          # 日志中间件（示例）
│   └── ContentFilterMiddleware.class.php # 内容过滤中间件（示例）
└── Inc/
    └── Middleware.inc.php               # 中间件配置文件
```

---

## 中间件规范

### 1. 命名规范

- 文件名：`{功能名}Middleware.class.php`
- 类名：`{功能名}Middleware`
- 命名空间：`APP\Middleware`

**示例**：
```
文件名：JwtAuthMiddleware.class.php
类名：JwtAuthMiddleware
命名空间：APP\Middleware
```

### 2. 基本要求

- 必须继承 `Candy\Core\Security` 类
- 必须实现 `handle(string $content = '')` 方法
- 文件必须包含 `defined('CANDY') OR die()` 安全声明
- 类文件必须使用 `declare(strict_types=1)` 严格类型

### 3. 标准模板

```php
<?php
/**
 * {中间件名称}
 *
 * {功能描述}
 *
 * @package APP\Middleware
 * @author {作者}
 * @date {日期}
 */

declare(strict_types=1);
namespace APP\Middleware;

use Candy\Core\Security;

defined('CANDY') OR die('You Are A Bad Guy. o_O???');

class {MiddlewareName}Middleware extends Security {
    /**
     * 中间件名称
     * @var string
     */
    protected string $name = '{name}';

    /**
     * 中间件别名
     * @var array
     */
    protected array $aliases = ['alias1', 'alias2'];

    /**
     * 构造函数
     *
     * @param array $config 中间件配置
     */
    public function __construct(array $config = []) {
        $this->loadConfig($config);
    }

    /**
     * 加载配置
     *
     * @param array $config 配置数组
     */
    protected function loadConfig(array $config): void {
        // 处理配置
    }

    /**
     * 获取中间件名称
     *
     * @return string
     */
    public function getName(): string {
        return $this->name;
    }

    /**
     * 获取中间件别名
     *
     * @return array
     */
    public function getAliases(): array {
        return $this->aliases;
    }

    /**
     * 标准中间件处理方法
     *
     * @param string $content 待处理的内容（Over 类型有效）
     * @return mixed Over 类型返回处理后的内容，其他类型无返回值
     */
    public function handle(string $content = '') {
        // 获取请求上下文
        $context = self::getRequestContext();
        
        // 中间件逻辑
        
        return $content;
    }
}
```

## 配置方式

### 配置文件

`Source/Inc/Middleware.inc.php`

### 配置格式

#### 格式一：简单类名（无配置）

```php
return [
    'Before' => [
        'APP\Middleware\SimpleMiddleware',
    ],
];
```

#### 格式二：带配置参数（推荐）

```php
return [
    'Before' => [
        'APP\Middleware\JwtAuthMiddleware' => [
            'enabled' => true,
            'except_paths' => ['/login', '/captcha'],
            'required_paths' => ['/admin/*'],
            'csrf_enable' => true,
        ],
    ],
];
```

### 中间件类型

| 类型 | 说明 | 执行时机 | 返回值 |
|------|------|---------|--------|
| `Init` | 初始化中间件 | 安全系统初始化时 | 无 |
| `Before` | 路由前中间件 | URL 解析前 | 无 |
| `Over` | 内容处理中间件 | 视图渲染后，输出前 | 必须返回 `$content` |
| `After` | 请求后中间件 | 控制器执行后 | 无 |
| `Finish` | 输出后中间件 | 响应发送后 | 无 |

### 完整配置示例

```php
<?php
return [
    'Init' => [
        // 初始化中间件
    ],

    'Before' => [
        // JWT 认证中间件
        'APP\Middleware\JwtAuthMiddleware' => [
            'enabled' => true,
            'except_paths' => [
                '/admin/login',
                '/admin/login/index',
                '/admin/login/dologin',
                '/admin/login/code',
            ],
            'required_paths' => ['/admin/*'],
            'csrf_enable' => true,
        ],
    ],

    'Over' => [
        // 内容过滤中间件
        'APP\Middleware\ContentFilterMiddleware' => [
            'filters' => ['script', 'iframe'],
        ],
    ],

    'After' => [
        // 日志记录中间件
        'APP\Middleware\LogMiddleware',
    ],

    'Finish' => [
        // 清理中间件
    ],
];
```

## 请求上下文

框架提供 `self::getRequestContext()` 方法获取请求上下文，返回数组包含：

```php
[
    'path' => '/admin/user/index',           // PATH_INFO
    'request_uri' => '/admin/user/index',    // REQUEST_URI
    'method' => 'GET',                       // 请求方法
    'is_ajax' => false,                      // 是否 AJAX 请求
    'is_get' => true,                        // 是否 GET
    'is_post' => false,                      // 是否 POST
    'is_put' => false,                       // 是否 PUT
    'is_delete' => false,                    // 是否 DELETE
    'is_write' => false,                     // 是否写操作（POST/PUT/DELETE/PATCH）
    'ip' => '127.0.0.1',                     // 客户端 IP
    'user_agent' => 'Mozilla/5.0...',        // User-Agent
    'referer' => '',                         // 来源页面
    'get' => [],                             // $_GET
    'post' => [],                            // $_POST
    'cookie' => [],                          // $_COOKIE
    'server' => [],                          // $_SERVER
]
```

**使用示例**：

```php
public function handle(string $content = '') {
    $context = self::getRequestContext();
    
    // 获取请求路径
    $path = $context['path'];
    
    // 获取请求方法
    $method = $context['method'];
    
    // 判断是否写操作
    if ($context['is_write']) {
        // 处理写操作逻辑
    }
    
    return $content;
}
```

## 中间件开发示例

### 示例 1：日志记录中间件

```php
<?php
declare(strict_types=1);
namespace APP\Middleware;

use Candy\Core\Security;
use Candy\Core\Log;

class LogMiddleware extends Security {
    protected string $name = 'Log';
    protected array $aliases = ['log', 'logger'];

    public function __construct(array $config = []) {}

    public function getName(): string {
        return $this->name;
    }

    public function getAliases(): array {
        return $this->aliases;
    }

    public function handle(string $content = '') {
        $context = self::getRequestContext();
        
        // 记录请求日志
        Log::info('Request: ' . $context['method'] . ' ' . $context['path']);
        
        return $content;
    }
}
```

### 示例 2：内容过滤中间件

```php
<?php
declare(strict_types=1);
namespace APP\Middleware;

use Candy\Core\Security;

class ContentFilterMiddleware extends Security {
    protected string $name = 'ContentFilter';
    protected array $aliases = ['filter', 'content'];
    protected array $filters = [];

    public function __construct(array $config = []) {
        $this->filters = $config['filters'] ?? [];
    }

    public function getName(): string {
        return $this->name;
    }

    public function getAliases(): array {
        return $this->aliases;
    }

    public function handle(string $content = '') {
        if (empty($this->filters)) {
            return $content;
        }

        foreach ($this->filters as $filter) {
            switch ($filter) {
                case 'script':
                    $content = preg_replace('/<script.*?<\/script>/is', '', $content);
                    break;
                case 'iframe':
                    $content = preg_replace('/<iframe.*?<\/iframe>/is', '', $content);
                    break;
            }
        }

        return $content;
    }
}
```

## 最佳实践

### 1. 使用配置而非硬编码

```php
// ❌ 不好
protected array $exceptPaths = ['/login', '/captcha'];

// ✅ 好
public function __construct(array $config = []) {
    $this->exceptPaths = $config['except_paths'] ?? [];
}
```

### 2. 使用请求上下文

```php
// ❌ 不好
$path = $_SERVER['PATH_INFO'] ?? '/';
$method = $_SERVER['REQUEST_METHOD'] ?? 'GET';

// ✅ 好
$context = self::getRequestContext();
$path = $context['path'];
$method = $context['method'];
```

### 3. 提前返回避免嵌套

```php
// ❌ 不好
if ($this->enabled) {
    if (!$this->isExceptPath($path)) {
        if ($this->isRequiredPath($path)) {
            // 处理逻辑
        }
    }
}

// ✅ 好
if (!$this->enabled) {
    return $content;
}
if ($this->isExceptPath($path)) {
    return $content;
}
if (!$this->isRequiredPath($path)) {
    return $content;
}
// 处理逻辑
```

### 4. 使用通配符匹配路径

```php
// 支持通配符
'required_paths' => [
    '/admin/*',      // 匹配 /admin/ 下所有路径
    '/api/v1/*',     // 匹配 /api/v1/ 下所有路径
],
```

## 注意事项

1. **中间件执行顺序**：按配置顺序依次执行
2. **Over 类型必须返回**：`Over` 类型中间件必须返回处理后的 `$content`
3. **终止请求**：使用 `exit` 终止请求（如认证失败）
4. **性能优化**：避免在中间件中进行数据库查询等耗时操作
5. **错误处理**：中间件应该妥善处理异常，不要影响其他中间件

## 常见问题

### Q1: 如何动态添加排除路径？

```php
// 在中间件中提供方法
public function addExceptPaths($paths): self {
    $this->exceptPaths = array_merge($this->exceptPaths, (array)$paths);
    return $this;
}
```

### Q2: 如何在中间件之间传递数据？

```php
// 使用 $_REQUEST 注入数据
$_REQUEST['_auth_user_id'] = $userId;
$_REQUEST['_auth_user'] = $user;
```

### Q3: 如何临时禁用中间件？

```php
// 配置中设置
'APP\Middleware\JwtAuthMiddleware' => [
    'enabled' => false,  // 临时禁用
],
```
