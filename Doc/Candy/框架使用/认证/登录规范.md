# Candy 框架 Admin 登录功能规范

## JWT + Cookie 混合认证流程

### 1. 登录验证流程

```
用户提交登录表单
    ↓
Login::dologin() 接收参数
    ↓
M('Admin')->auth() 验证
    ├── 查询用户 (userName)
    ├── 检查状态 (userStatus)
    ├── 验证密码 (passWordHandle)
    ├── 权限组验证 (D('Group'))
    └── 权限合并 (userPlusAuth)
    ↓
验证成功 → HybridAuth::login() 生成 JWT Token
    ↓
设置安全 Cookie (access_token, refresh_token, csrf_token)
    ↓
跳转到后台首页
```

### 4. Session vs JWT 对比

| 功能 | Session (旧) | JWT + Token (新) |
|------|--------------|------------------|
| 用户信息存储 | `session('adminUserId')`, `session('adminUser')` | JWT Payload (加密) |
| 权限信息 | `session('userRole')`, `session('userAuths')` | JWT Payload + Session (权限) |
| 记住我 | Cookie `userSession` | JWT Token 过期时间 (30天) |
| 登出 | 清除 Session + Cookie | Token 黑名单 (Redis) |
| CSRF 防护 | - | `csrf_token` Cookie |
| 安全特性 | HttpOnly Cookie | JWT + HttpOnly + SameSite |

### 5. 密码失败锁定机制

```php
// 连续失败 N 次后锁定
$passCheck = session('passCheck'); // Session 记录失败次数
if($passCheck['fail'] >= $passCheck['lockPassNum']){
    // 锁定账号
    $userNoLoginDate = date('Y-m-d H:i:s', time() + $passCheck['lockPassTime']);
    $this->where($uid)->save(['userNoLoginDate' => $userNoLoginDate, 'userStatus' => 2]);
}
```

### 6. JWT Token 生命周期

| Token 类型 | 默认有效期 | 记住我有效期 |
|-----------|-----------|-------------|
| Access Token | 2 小时 | 30 天 |
| Refresh Token | 7 天 | 90 天 |

### 7. Common 控制器认证检查

```php
function init(){
    try {
        $this->adminUserId = HybridAuth::getCurrentId();
        if($this->adminUserId > 0){
            $this->adminUser = HybridAuth::getUser();
        } else {
            $this->redirectLogin();
        }
    } catch (\Exception $e) {
        $this->redirectLogin();
    }
}
```
