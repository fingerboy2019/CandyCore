## 架构概述

本方案**完全遵循 Candy 框架规范**在 Admin 项目中实现：

```
┌─────────────────────────────────────────────────────────┐
│  Admin 项目认证流程                                      │
│                                                         │
│  1. 用户访问 /Admin/Login/index                         │
│     └─ 中间件跳过（在 exceptPaths 中）                   │
│     └─ 显示登录页面                                     │
│                                                         │
│  2. 用户提交登录表单 POST /Admin/Login/dologin          │
│     └─ 中间件跳过（在 exceptPaths 中）                   │
│     └─ Login.authenticateUser() 验证用户名密码         │
│     └─ HybridAuth::login() 生成 JWT Token              │
│     └─ 设置 HttpOnly Cookie（access_token, refresh_token）│
│                                                         │
│  3. 访问后台页面 /Admin/Index/index                     │
│     └─ 中间件验证 Token（Before 阶段）                   │
│     └─ Common::init() 获取用户信息                      │
│     └─ 显示后台首页                                     │
│                                                         │
│  4. Token 过期自动刷新                                  │
│     └─ 前端 auth.fetch() 自动检测 401                   │
│     └─ 调用 /Admin/Login/refresh 刷新 Token            │
│     └─ 重试原请求                                      │
└─────────────────────────────────────────────────────────┘
```

## 快速开始

### 1. 配置 JWT

确保 `Source/Inc/Jwt.inc.php` 存在：

```php
<?php
return [
    'algorithms' => 'HS256',
    'access_secret_key' => 'your-secret-key-change-this',
    'access_exp' => 7200,              // Access Token 2小时
    'refresh_secret_key' => 'your-refresh-secret-key',
    'refresh_exp' => 604800,           // Refresh Token 7天
    'refresh_disable' => false,
    'iss' => 'your-domain.com',
    'nbf' => 0,
    'leeway' => 60,
    'is_single_device' => true,        // 单设备登录
    'cache_token_ttl' => 604800,
    'cache_token_pre' => 'JWT:TOKEN:',
    'cache_refresh_token_pre' => 'JWT:REFRESH_TOKEN:',
    'user_model' => function ($uid) {
        // Admin 项目用户模型
        $db = D('User');
        return $db->where("uid=$uid")->find();
    },
];
```

### 2. 配置中间件

`Source/Inc/Middleware.inc.php` 已配置：

```php
return [
    'Before' => [
        'APP\Extend\HybridAuthMiddleware',  // ✅ 自动验证
    ],
];
```

### 3. 创建新控制器

所有 Admin 控制器继承 `Common`：

```php
<?php
namespace APP\Control\Admin;

defined('CANDY') OR die('You Are A Bad Guy. o_O???');

Class User extends Common {  // ✅ 继承 Common
    function index(){
        // Common::init() 已验证认证
        $adminId = $this->adminUserId;
        $admin = $this->adminUser;
        
        // 你的逻辑
        $this->display();
    }
}
```

### 获取当前管理员信息

```php
function profile(){
    // 方式 1：通过 Common 属性
    $adminId = $this->adminUserId;
    $admin = $this->adminUser;
    
    // 方式 2：通过 HybridAuth
    $adminId = \APP\Extend\HybridAuth::getCurrentId();
    $admin = \APP\Extend\HybridAuth::getUser();
    
    // 方式 3：通过 Session（兼容旧代码）
    $adminId = session('adminUserId');
    $admin = session('adminUser');
    
    $this->assign('admin', $admin);
    $this->display();
}
```

## 前端使用

### 登录页面

已自动实现 `/Admin/Views/Login/index.html`，包含：
- ✅ 用户名密码登录
- ✅ 验证码支持
- ✅ 记住登录
- ✅ 自动处理 Token
- ✅ 自动处理 CSRF

### AJAX 请求（自动携带 Token）

```javascript
// 使用 auth.fetch() 自动携带 Token 和 CSRF
auth.fetch('/Admin/User/add', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json'
    },
    body: JSON.stringify({
        username: 'test',
        email: 'test@example.com'
    })
})
.then(result => {
    if(result.code === 200) {
        alert('添加成功');
    } else if(result.code === 401) {
        // 未登录，自动跳转
    }
});
```

### 快捷方法

```javascript
// GET 请求
auth.get('/Admin/User/info')
    .then(result => console.log(result.data));

// POST 请求
auth.post('/Admin/User/update', { id: 1, name: 'New Name' })
    .then(result => console.log(result.msg));
```

## 安全特性

### 1. HttpOnly Cookie
- Token 存储在 HttpOnly Cookie
- JavaScript 无法访问，防止 XSS 攻击

### 2. CSRF 防护
- 所有写操作自动验证 CSRF Token
- 登录页面自动生成 CSRF

### 3. Token 黑名单
- 登出时 Token 加入 Redis 黑名单
- 防止 Token 被重用

### 4. 单设备登录
- 新登录踢出旧设备
- 配置 `is_single_device => true`

### 5. 自动刷新
- Token 过期自动刷新
- 用户无感知

## 常见问题

### Q1: 如何跳过某个操作的认证？

**A:** 在 `Common.class.php` 的 `$exceptActions` 中添加：

```php
$exceptActions = ['index', 'publicAction'];
```

### Q2: 如何修改 Token 过期时间？

**A:** 编辑 `Source/Inc/Jwt.inc.php`：

```php
'access_exp' => 7200,    // 2小时
'refresh_exp' => 604800, // 7天
```

### Q3: 如何禁用单设备登录？

**A:** 修改 JWT 配置：

```php
'is_single_device' => false,
```

### Q4: 如何查看当前登录的管理员信息？

**A:** 三种方式：
```php
// 1. Common 属性
$this->adminUser

// 2. HybridAuth
HybridAuth::getUser()

// 3. Session
session('adminUser')
```

### Q5: Token 存在哪里？

**A:** HttpOnly Cookie 中，浏览器自动管理，JavaScript 无法访问。
