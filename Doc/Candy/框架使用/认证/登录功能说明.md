## 登录流程

```
用户访问 /Admin/Login/index
          ↓
    检查是否已登录
          ↓
    显示登录页面
          ↓
    用户提交表单
          ↓
    验证用户名密码
          ↓
    验证验证码
          ↓
    检查账号状态
          ↓
    生成 JWT Token
          ↓
    设置 HttpOnly Cookie
          ↓
    返回成功，跳转首页
```

## 配置说明

### 1. JWT 配置

文件：`Source/Inc/Jwt.inc.php`

```php
<?php
return [
    'algorithms' => 'HS256',
    'access_secret_key' => 'your-secret-key',
    'access_exp' => 7200,              // Access Token 2 小时
    'refresh_secret_key' => 'your-refresh-secret-key',
    'refresh_exp' => 604800,           // Refresh Token 7 天
    'is_single_device' => true,        // 单设备登录
    'cache_token_pre' => 'JWT:TOKEN:',
    'cache_refresh_token_pre' => 'JWT:REFRESH_TOKEN:',
    'user_model' => function ($uid) {
        $db = D('User');
        return $db->where("uid=$uid")->find();
    },
];
```

### 2. 验证码配置

文件：`Source/Inc/Config.inc.php`

```php
<?php
return [
    // 是否启用验证码
    'captcha_enable' => true,
    
    // 其他配置...
];
```

### 3. 日志自动记录

框架的 `__destructor` 函数会自动检查并记录日志，无需手动实现：

```php
// Candy/Func/global.func.php
function __destructor(): void
{
    if(function_exists('addLogs') && C('actInfo.Log') === true){
        addLogs();
    }
}
```

**条件：**
- `addLogs` 函数存在
- `C('actInfo.Log') === true`

## 多语言支持

### 支持的语言

| 语言 | 代码 | 文件 |
|------|------|------|
| 简体中文 | zh-cn | `Languages/zh-cn/Login.lang.php` |
| 英文 | en-us | `Languages/en-us/Login.lang.php` |

### 切换语言

登录页面右上角有语言切换链接：

```html
<a href="?lang=zh-cn">简体中文</a>
<a href="?lang=en-us">English</a>
```

### 语言文件位置

```
Application/Admin/Languages/
├── zh-cn/
│   ├── Common.lang.php      # 公共语言
│   └── Login.lang.php       # 登录专属
└── en-us/
    ├── Common.lang.php
    └── Login.lang.php
```

## 前端交互

### 表单验证

```javascript
// 用户名不能为空
if(!username) {
    showError('用户名不能为空');
}

// 密码不能为空
if(!password) {
    showError('密码不能为空');
```

```javascript

messageDiv.className = 'error';
messageDiv.textContent = errorMessage;
messageDiv.style.display = 'block';
```

### 加载状态

```javascript
// 登录中...
loginBtn.disabled = true;
loginBtn.textContent = '登录中...';

// 恢复按钮
loginBtn.disabled = false;
loginBtn.textContent = '登录';
```

```javascript

    this.src = U('Login/code') + '?t=' + Date.now();
});
```

## 常见问题

### Q1: 登录成功后没有跳转？

**A:** 检查：
1. 浏览器控制台是否有 JavaScript 错误
2. 网络请求是否成功
3. 返回的 `redirect` 字段是否正确

### Q2: 验证码不显示？

**A:** 检查：
1. `captcha_enable` 配置是否为 `true`
2. GD 扩展是否安装
3. 浏览器控制台是否有错误

### Q3: 记住登录不生效？

**A:** 检查：
1. 浏览器是否允许 Cookie
2. Cookie 是否设置为 HttpOnly
3. Token 过期时间是否正确

### Q4: 如何查看登录日志？

**A:** 框架自动记录，可在数据库中查看：
```sql
SELECT * FROM user_log ORDER BY create_time DESC LIMIT 10;
```

### Q5: 如何禁用单设备登录？

**A:** 修改 JWT 配置：
```php
'is_single_device' => false,
```
