# 代码生成与空间创建（`/sys/init`）

> 用浏览器完成两类操作，等价于 `php candy make:*`，不用开终端：
> ① **空间创建**：主应用 / 扩展 / 插件；② **类生成**：Control / Model / Schema / Validate。

## 前提（两个硬条件）

1. **已配置 token**：`sys/init` 会写文件，token 为空时框架的 `authorize()` 会放行，所以端点内部强制要求 token 非空且正确（否则返回 403 JSON）。
2. **DEBUG 模式**：`isDebug()` 为真才可用 —— 与 `Bootstrap::route()` 里 `Build::start` 的入口判定一致（`DEBUG==1 && $GLOBALS['debug']===1`）。开启方式：`.env` 的 `APP_DEBUG=1`，或 `Source/Inc/Sys.inc.php` 的 `runtime.debug = true`；生产默认关闭，一律 403。

> token 取值优先级（框架统一规则）：
> `Sys.inc.php` 的 `security.token` → `Endpoint.inc.php` 的 `token` → 默认 `candy-sys` → `Runtime/.endpoint-token`。
> 可以先访问 `/sys/url` 输入令牌（存 cookie），再调用本端点。

## 通用参数

| 参数 | 必填 | 说明 |
|---|---|---|
| `type` | ✅ | `app` / `addon` / `plug` / `control` / `model` / `schema` / `validate` |
| `app` | ✅ | 项目名 / 空间名 / 类所属应用名（大写开头，字母/数字/下划线，≤40） |
| `name` | | 类名（仅类生成用），默认 = `app` |
| `dry=1` | | 只预览，不落盘 |
| `overwrite=1` | | 仅类生成：目标已存在时覆盖（先备份 `.bak`） |
| `token` | ✅ | 也可用 `Authorization: Bearer` 或 cookie |

```bash
# 预览一个应用
curl -s "http://<host>/sys/init?type=app&app=Demo&dry=1&token=<token>"
# 生成一个控制器
curl -s "http://<host>/sys/init?type=control&app=Admin&name=Article&token=<token>"
```

## 一、空间创建（复用 `Build::bulidSpaces()` 的三种类型）

| type | 创建内容 |
|---|---|
| `app` | `Application/{Name}/`（Controls / Models / Services / Validates / Schemas / Vendor / Languages / Views）+ **同时创建 `Plugins/{Name}/`** + `Source/Inc/{Name}Route.inc.php` + 写 `Runtime/init.lock` 创建记录 |
| `addon` | `Addons/{Name}/`（从 `Candy/Tpl/demo/Addon` 复制并替换命名空间）；**需项目开启 `$addons`**，否则 403 |
| `plug` | `Plugins/{Name}/`（目录骨架 + `Hook/` + `conf.php`） |

- 名称会被规范成 **首字母大写 + 其余小写**（框架 `ucfirst(strtolower())`）：`DemoApp` → `Demoapp`；
- 已存在返回 `409`，绝不覆盖；
- `dry=1` 只返回计划路径，不落盘。

## 二、类生成

| type | 路径 | 命名空间 |
|---|---|---|
| `control` | `Application/{App}/Controls/{Name}.class.php` | `APP\Control\{App}` |
| `model` | `Application/{App}/Models/{Name}.class.php` | `APP\Model\{App}` |
| `schema` | `Application/{App}/Schemas/{Name}.class.php` | `APP\Schema\{App}` |
| `validate` | `Application/{App}/Validates/{Name}.class.php` | `APP\Validate\{App}` |

`control` 类型会顺带创建语言库 `Application/{App}/Languages/zh-cn/{Name}.lang.php`（已存在则跳过）。

## 不会越界

三层校验：

1. `app` / `name` 必须匹配 `^[A-Z][A-Za-z0-9_]{0,39}$`（挡住 `../`、`\`、空格等）；
2. 类生成目标目录做 `realpath` 前缀校验，必须落在 `Application/` 之下；
3. 写入后调用 `php -l` 校验，语法错误自动删除并返回错误。

## 返回

```json
{"code":0,"message":"created","data":{"type":"app","name":"Demoapp",
 "path":"/Application/Demoapp/","files":7,"note":"默认分支同时创建了 Plugins/Demoapp/"}}
```

`code`：`0` 成功 / `400` 参数非法 / `403` token 或环境不满足 / `409` 已存在 / `500` 写入或语法失败。
