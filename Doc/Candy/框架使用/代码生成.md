# 代码生成（`/sys/init`）

> 用浏览器生成 `Control` / `Model` / `Schema` / `Validate` 空类，等价于
> `php candy make:control|model|schema|validate`，不用开终端。

## 前提（两个硬条件）

1. **已配置 token**：`sys/init` 会写文件，token 为空时框架的 `authorize()` 会放行，所以端点内部强制要求 token 非空（否则返回 403）。
2. **开发环境**：`Source/Inc/Init.inc.php` 里定义 `DEV` 才可用；生产（未定义 `DEV`）一律 403。

> token 取值优先级（框架统一规则）：
> `Sys.inc.php` 的 `security.token` → `Endpoint.inc.php` 的 `token` → 默认 `candy-sys` → `Runtime/.endpoint-token`。
> 可以先访问 `/sys/url` 输入令牌（存 cookie），再调用本端点。

## 用法

| 参数 | 必填 | 说明 |
|---|---|---|
| `app` | ✅ | 项目名（大写开头，字母/数字/下划线，≤40） |
| `type` | ✅ | `control` / `model` / `schema` / `validate` |
| `name` | | 类名，默认 = `app` |
| `dry=1` | | 只预览，不写文件 |
| `overwrite=1` | | 目标已存在时覆盖（覆盖前备份 `.bak`） |
| `token` | ✅ | 也可用 `Authorization: Bearer` 或 cookie |

```bash
# 预览
curl -s "http://<host>/sys/init?app=Admin&type=control&name=Article&dry=1&token=<token>"

# 生成
curl -s "http://<host>/sys/init?app=Admin&type=control&name=Article&token=<token>"
```

## 生成到哪里

| type | 路径 | 命名空间 |
|---|---|---|
| `control` | `Application/{App}/Controls/{Name}.class.php` | `APP\Control\{App}` |
| `model` | `Application/{App}/Models/{Name}.class.php` | `APP\Model\{App}` |
| `schema` | `Application/{App}/Schemas/{Name}.class.php` | `APP\Schema\{App}` |
| `validate` | `Application/{App}/Validates/{Name}.class.php` | `APP\Validate\{App}` |

`control` 类型会顺带创建语言库 `Application/{App}/Languages/zh-cn/{Name}.lang.php`（已存在则跳过）。

## 不会越界

三层校验：

1. `app` / `name` 必须匹配 `^[A-Z][A-Za-z0-9_]{0,39}$`（挡住 `../`、`\`、空格等）；
2. 目标目录做 `realpath` 前缀校验，必须落在 `Application/` 之下；
3. 写入后调用 `php -l` 校验，语法错误自动删除并返回错误。

## 返回

```json
{"code":0,"message":"created","data":{"type":"control","app":"Admin","name":"Article",
 "namespace":"APP\\Control\\Admin","file":"/Application/Admin/Controls/Article.class.php",
 "preview":"<?php ..."}}
```

`code`：`0` 成功 / `400` 参数非法 / `403` token 或环境不满足 / `409` 文件已存在 / `500` 写入或语法失败。
