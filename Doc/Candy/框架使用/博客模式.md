# Markdown博客模式

## 概述

基于 Markdown 文件的轻量博客，与文档站共用 `Candy\Core\Markdown` 与 `Candy\Extend\Doc\Markdown\Engine` 解析引擎。初始化后与 MVCS、`/Doc/` **三轨并行**，通过 **`/Blog/` URL** 访问。

## 访问与路由

| 路径 | 处理方式 |
|------|----------|
| `/Blog/`、`/Blog/分类/文章` | 主站 `index.php` → `UrlParser` 劫持 → Markdown 博客模式 |
| `/Doc/Blog/Static/` | Nginx 直接输出 CSS/JS |
| `/Doc/Blog/{其他}` | **禁止直接访问**（404） |
| `/Doc/` | 同文档站（`UrlParser` 劫持或 `Doc/index.php`） |
| `/Admin/` 等 | 正常 MVCS |

**注意**：勿在站点根目录创建物理 `Blog/` 文件夹（会导致 Nginx `try_files` 直接 403）。

## 安全：正文目录不可猜测

博客正文**不**使用固定的 `post/` 路径。初始化时会在 `Doc/Blog/` 下创建 **8 位随机目录**（如 `k7m3x9ab`），目录名写入 `Source/Inc/BlogConfig.inc.php` 的 `content_dir`，仅框架解析时读取。

```
Doc/Blog/
├── Static/           # 公开：CSS/JS
├── views/            # 禁止 Web 直访
├── k7m3x9ab/         # 正文（随机名，配置 content_dir）
│   ├── README.md
│   └── 分类/
└── ...
```

- 公开 URL **不含** `content_dir` 与 `post`
- URL 中出现 `post` 或 `content_dir` 同名段 → 404
- PHP 层：`UrlParser::rejectDirectBlogDiskAccess()` 拦截 `/Doc/Blog/`（除 `Static`）
- Nginx 层：推荐启用 `Doc/nginx-snippets/blog-content-deny.conf`（宝塔可放入 `extension/站点/`）

## 初始化

```
https://你的域名/?init=mdblog
```

自动创建：

- `Source/Inc/BlogConfig.inc.php`（含随机 `content_dir`）
- `Doc/Blog/{content_dir}/README.md`（首页）
- `Doc/Blog/{content_dir}/默认分类/`
- `Doc/Blog/views/*.tpl.php`（接入 `Candy/Class/Doc/Blog/layout.tpl.php`）

完成后跳转到 `/Blog/`。

## 管理后台

隐藏入口（须与配置中 `content_dir` 一致）：

```
/Blog/{content_dir}/admin
```

示例：`/Blog/kle0d68a/admin`（`kle0d68a` 见 `Source/Inc/BlogConfig.inc.php`）。

| 能力 | 说明 |
|------|------|
| 登录 | `auth.username` / `auth.password`（`BlogConfig.inc.php`） |
| 验证码 | `auth.captcha`，复用框架 `verificationCode` / `captcha_verify` |
| 保持登录 | Session + 签名 Cookie（30 天） |
| 文章编辑 | 正文目录内 Markdown 浏览/编辑（登录后可写，不依赖 DEBUG） |
| 系统配置 | Tab：站点、导航、资料、友链、列表数量、订阅与地图、模板变量、后台账号 |

默认账号：`admin` / `admin123`（安装后请立即在「后台账号」Tab 修改）。

公开博客 URL **仍不含** `content_dir`；仅管理地址需要随机码，用于隐藏入口。

## URL 规则

| 磁盘路径（示例） | 访问 URL |
|------------------|----------|
| `{content_dir}/README.md` | `/Blog/` |
| `{content_dir}/默认分类/README.md` | `/Blog/默认分类/` |
| `{content_dir}/默认分类/我的文章.md` | `/Blog/默认分类/我的文章` |
| —（聚合） | `/Blog/tag/{标签名}` |
| —（订阅） | `/Blog/rss.xml` |
| —（地图） | `/Blog/sitemap.xml` |

`{content_dir}` 为配置中的 8 位随机串，**勿写入 URL**。独立域名模式下前缀为 `/`（如 `/rss.xml`、`/tag/PHP`、`/sitemap.xml`）。

## 发布文章

### 方式一：CLI（推荐草稿脚手架）

```bash
cd backend
php candy blog:new "文章标题" --category=默认分类 --tags=PHP,Candy
# 默认写入 draft: true；公开后去掉该字段或改 false，或创建时加 --publish
# 可选：--slug=my-post  -f 覆盖已存在文件
```

写入 `{content_dir}/{分类}/{标题或slug}.md`（含 Front Matter），并清除门户索引缓存。

### 方式二：管理后台

登录 `/Blog/{content_dir}/admin`，在文件树中新建/编辑 Markdown。

### 方式三：直接写文件

1. 在 `Doc/Blog/{content_dir}/` 或子分类目录新建 `.md`（`content_dir` 见 `BlogConfig.inc.php`）
2. 可选 Front Matter（与文档站相同）：

```yaml
---
title: 文章标题
description: 摘要
date: 2026-07-16
tags: [PHP, Candy]
draft: true   # 草稿：不进入首页/RSS/Sitemap/搜索，直链 404
---
```

3. 浏览器访问对应 `/Blog/...` URL；标签云点击可进入 `/Blog/tag/...` 归档页

## 草稿

- Front Matter：`draft: true`（或 `status: draft`）
- 公开侧：首页、分类/标签、RSS、Sitemap、全文搜索均排除；直接访问文章 URL 返回 404
- 后台：仍可在 `/Blog/{content_dir}/admin` 编辑磁盘文件
- 发布：删除 `draft` 字段，或改为 `false` / `0`

## RSS

- 动态地址：`/Blog/rss.xml`（独立域名：`/rss.xml`）
- 条数：`feed_limits.rss_items`（默认 20；后台「订阅与地图」或「列表数量」可改；空值生成时兜底 20）
- 静态副本：`/Doc/Blog/Static/feed/rss.xml`（后台可一键生成；保存/上传 `.md` 后自动更新）
- 页面 `<head>` 已输出 `rel="alternate"` 订阅链接

## Sitemap

- 动态地址：`/Blog/sitemap.xml`（独立域名：`/sitemap.xml`）
- 条数：`feed_limits.sitemap_items`（默认 1000；空值生成时兜底 1000）
- 内容：首页、分类页、标签页、已发布文章（含 `lastmod`）
- 静态副本：`/Doc/Blog/Static/feed/sitemap.xml`
- 可在搜索引擎站长平台提交动态或静态 URL

## 评论

存储：`Doc/Blog/{content_dir}/.comments/{crc32(相对路径.md)}.json`（相对路径含分类，避免同名冲突）。

| 能力 | 说明 |
|------|------|
| 前台 | 文章页底部评论区；嵌套回复（默认最多 4 层）；标签；`:smile:` 等短码（复用 Markdown 表情表） |
| 审核 | 默认 `require_approve=true`，后台「评论管理」通过 / 垃圾 / 删除 / 博主回复 |
| 验证码 | 默认开启（`comments.captcha`） |
| 防刷 | 同 IP 同文约 45 秒限频（Cache） |

`BlogConfig.inc.php`：

```php
'comments' => [
    'enabled' => true,
    'require_approve' => true,
    'max_depth' => 4,
    'captcha' => true,
],
```

## 配置 `Source/Inc/BlogConfig.inc.php`

> 博客配置放在 **`Source/Inc/`**（与 `Init.inc.php`、`Config.inc.php` 同级），**不要**写到 `backend/Config/`，以免与框架配置系统混淆。

```php
<?php
return [
    'doc_root' => 'Doc/Blog/',
    'content_dir' => 'k7m3x9ab',  // 自动生成，勿随意修改；删错会导致找不到文章
    'site_name' => 'Candy 博客',
    'site_description' => '基于 Markdown 的轻量博客',
    // 'template' => C('CANDYROOT') . '自定义/views/',  // 可选：覆盖 views 目录
];
```

读取方式：`Candy\Extend\Doc\Blog\Config::load()` 或 `loadConfig('BlogConfig')`。

| 配置项 | 说明 |
|--------|------|
| `doc_root` | 博客安装根（views、Static），相对 `CANDYROOT` |
| `content_dir` | 正文 Markdown 子目录名（8 位 `a-z0-9`，初始化随机生成） |
| `site_name` | 侧栏标题、页脚版权名 |
| `site_description` | 站点描述（可写入 meta） |
| `site_url` | RSS/Sitemap 绝对链接前缀；留空则按绑定域名或当前请求推导 |
| `template` | 自定义模板目录前缀，拼接 `index`/`post`/`list`/`404` + `.tpl.php` |
| `feed_limits.rss_items` | RSS 输出条数（默认 20） |
| `feed_limits.sitemap_items` | Sitemap 文章上限（默认 1000） |

## 模板

默认页面壳：`Candy/Class/Doc/Blog/layout.tpl.php`（独立博客布局，站点名来自 `BlogConfig`）。  
静态资源 URL 为 **`/Doc/Blog/Static/`**（与磁盘目录 `Doc/Blog/Static/` 一致，由 Nginx 直接输出）；模板内须用字符串拼接写入路径，不可在单引号串中写 `{$var}`。

## 菜单排序

在正文目录下放置 `.order` 文件，每行一个文件名或目录名，`#` 开头为注释。

## 与文档站差异（当前）

| 能力 | 文档站 | 博客 |
|------|--------|------|
| 路由前缀 | `/Doc/` | `/Blog/` |
| 内容目录 | `Doc/Candy/` | `Doc/Blog/{content_dir}/` |
| 页面模板 | `Site/layout.tpl.php` | `Blog/layout.tpl.php` |
| 静态主题 | `/Doc/Static/` | `/Doc/Blog/Static/`（`blog.css`） |
| 直链下载 MD | 可（文档本身公开） | **禁止**（Nginx + PHP 双层） |
| 全文搜索 | ✅ | ✅（索引正文目录） |
| 无刷新跳转 | ✅ | ✅（`data-doc-base="/Blog/"`） |

## 常见问题

**访问 `/Blog/` 空白**  
检查 `Doc/Blog/views/*.tpl.php` 是否 `require` 了 `Candy/Class/Doc/Blog/layout.tpl.php`。

**仍能下载 `/Doc/Blog/.../*.md`**  
确认 Nginx 已加载 `blog-content-deny.conf` 并 `nginx -s reload`。

**403**  
删除站点根下空的 `backend/Blog/` 物理目录。

**找不到文章**  
确认 `Source/Inc/BlogConfig.inc.php` 中 `content_dir` 与 `Doc/Blog/` 下正文目录名一致，且该目录存在。
