# 推送客户端 SDK（`candy-push.js`）

> 页面侧连推送网关（GatewayWorker，端口 4020）的最小客户端：连接、自动 login、心跳、断线重连、分组、事件回调。
> 无依赖、UMD（`window.CandyPush` / `require`）。

## 引入

框架提供源码：`Candy/Tpl/push/client.js`。
项目里复制一份到可公开访问的位置（`Candy/` 目录不对外）：

```bash
cp Candy/Tpl/push/client.js Public/static/plugs/candy-push.js
```

页面：

```html
<script src="/Public/static/plugs/candy-push.js"></script>
```

## 最小用法

```html
<script>
var push = new CandyPush({
  app: 'home',            // 应用名（与 Registry 注册一致）
  uid: {$user.id},        // 必填：由服务端登录态下发，不要在 JS 里硬编码
  tags: {$user.tags},     // 可选：初始分组，如 ['dept-12']
  debug: false            // 开发期打开看日志
});

push.on('login', function (r) {
  console.log('已绑定', r.uid, '补发离线', r.flushed || 0);
});

push.on('message', function (m) {
  console.log(m.title, m.body, m.payload);
  // 业务转发帧：按 payload.entity/action 只刷新对应区域
  // if (m.payload && m.payload.entity === 'ticket') refreshTicket(m.payload.id);
});

push.on('close',   function (e) { console.log('断开', e.code); });
push.on('error',   function (e) { console.warn(e.message); });

push.connect();
</script>
```

## 选项

| 选项 | 默认 | 说明 |
|---|---|---|
| `url` | 自动 `ws(s)://<host>:4020` | https 页面自动用 `wss` |
| `app` | `home` | 应用名 |
| `uid` | `null` | **必填**，为空会触发 `error` |
| `tags` | `[]` | 初始分组 |
| `heartbeat` | `30000` | 心跳毫秒，0 关闭 |
| `reconnect` | `true` | 断线自动重连 |
| `maxRetry` | `10` | 最大重连次数 |
| `retryBase` | `1000` | 退避基数（指数增长，上限 30s） |
| `debug` | `false` | 控制台日志 |

## 方法

| 方法 | 作用 |
|---|---|
| `connect()` | 建立连接（幂等），连上后自动 `login` |
| `login()` | 手动重新绑定（换 uid 后调用） |
| `join(tag)` / `leave(tag)` | 加入 / 退出分组 |
| `send({...})` | 发任意帧（未连接时返回 false） |
| `on(evt, fn)` / `off(evt, fn)` | 事件注册 / 移除（`'*'` 监听全部） |
| `close()` | 主动关闭且不再重连 |

## 事件

`open` · `welcome` · `login` · `message` · `pong` · `error` · `close` · `reconnect` · `frame`（未识别帧）· `*`（全部）

## 协议对照（`Candy\Extend\Tools\Push\Events`）

```
发 → {"act":"login","app":"home","uid":34,"tags":["dept-12"]}
发 → {"act":"join","tag":"dept-12"} / {"act":"leave","tag":"dept-12"} / {"act":"ping"}
收 → {"act":"welcome","client_id":"..."}
收 → {"act":"login","ok":true,"uid":"home:34","flushed":2}
收 → {"act":"message","msg_id":"...","title":"","body":"","payload":{}}
```

## 注意事项

1. **uid 只能来自服务端登录态**（模板 assign），不要从 URL 或前端存储取——否则任何人能冒充别人收消息。
2. **wss 需要网关证书**；没有证书时 https 页面连不上 `wss`，需要给 4020 配 TLS 或让页面走 http（面板用轮询兜底，业务页可参照）。
3. 服务端对**同 IP 连接数**和**消息频率**有限制，收到 `{"act":"error"}` 时看 `message`。
4. 离线消息由服务端在 `login` 时补发（`flushed` 是条数），客户端无需自己拉历史。
