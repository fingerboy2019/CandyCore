## 模板引擎概述

### 核心特性

| 特性 | 说明 |
|------|------|
| 分隔符 | `<{` 和 `}>` （可自定义） |
| 文件后缀 | `.html` |
| 模板目录 | `Application/{项目}/Views/` |
| 编译目录 | `Runtime/Comps/` |
| 缓存机制 | 支持文件缓存和内存缓存 |
| 模板继承 | 支持 `<{extend name='模板名'}>` |
| 钩子系统 | 支持 `<!--{hook 路径}-->` |
| 千人千面 | 支持个性化模板 |

### 模板路径规则

```
Application/Admin/Views/
├── {控制器名}/
│   ├── {操作名}.html           # 默认模板
│   └── 其他模板.html
├── Public/                     # 公共模板目录
│   ├── 404.html
│   └── success.html
└── 其他目录/
```

**示例：**
- 控制器：`Index`
- 操作：`index`
- 模板路径：`Application/Admin/Views/Index/index.html`

## 模板文件结构

### 基本结构

```html
<!DOCTYPE html>
<html>
<head>
    <title><{$pageTitle}></title>
    <meta charset="UTF-8">
</head>
<body>
    <h1><{$title}></h1>
    <p><{$content}></p>
</body>
</html>
```

### 完整示例（登录页）

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title><{$pageTitle}></title>
    <style>
        /* 样式 */
    </style>
</head>
<body>
    <div class="login-container">
        <form id="loginForm">
            <div class="form-group">
                <label for="username"><{L('name')}></label>
                <input type="text" id="username" name="username">
            </div>
            <button type="submit"><{L('login')}></button>
        </form>
    </div>
    <script>
        // JavaScript 代码
    </script>
</body>
</html>
```

## 模板语法

### 1. 变量输出

```html
<!-- 基本变量 -->
<{$username}>
<{$email}>

<!-- 数组访问 -->
<{$user.username}>
<{$user.email}>

<!-- 多维数组 -->
<{$user.profile.name}>
<{$user.profile.email}>
```

### 2. 条件判断

```html
<!-- if 条件 -->
<{if $isAdmin}>
    <p>管理员</p>
<{else}>
    <p>普通用户</p>
<{/if}>

<!-- if-elseif-else -->
<{if $status == 1}>
    <p>正常</p>
<{elseif $status == 0}>
    <p>待审核</p>
<{else}>
    <p>已禁用</p>
<{/if}>

<!-- 空值判断 -->
<{if empty($username)}>
    <p>用户名为空</p>
<{/if}>
```

### 3. 循环遍历

```html
<!-- foreach 循环 -->
<{foreach $users as $user}>
    <div class="user">
        <p>用户名：<{$user.username}></p>
        <p>邮箱：<{$user.email}></p>
    </div>
<{/foreach}>

<!-- 带索引的循环 -->
<{foreach $users as $key => $user}>
    <p>序号：<{$key}></p>
    <p>用户名：<{$user.username}></p>
<{/foreach}>

<!-- 带 @key, @value, @index -->
<{foreach $users as $user}>
    <p>索引：<{$user@index}></p>
    <p>键名：<{$user@key}></p>
    <p>值：<{$user@value}></p>
<{/foreach}>
```

### 4. 系统变量

```html
<!-- GET 参数 -->
<{$get.id}>
<{$get.name}>

<!-- POST 参数 -->
<{$post.username}>
<{$post.password}>

<!-- Session -->
<{$session.adminUser}>
<{$session.userId}>

<!-- Cookie -->
<{$cookie.locale}>

<!-- Server -->
<{$server.HTTP_HOST}>
<{$server.REQUEST_URI}>

<!-- 常量 -->
<{$const.CANDY_VERSION}>
<{$const.APPNAME}>

<!-- 请求信息 -->
<{$request.api}>
<{$request.method}>
```

### 5. 函数调用

```html
<!-- 调用 PHP 函数 -->
<{date('Y-m-d H:i:s')}>
<{strtoupper($username)}>
<{count($users)}>

<!-- 带参数 -->
<{substr($content, 0, 100)}>
<{in_array($status, [1, 2, 3])}>
```

### 6. 原样输出

```html
<!-- literal 标签内的内容不会被编译 -->
<{literal}>
    <{$thisWillNotBeParsed}>
    <{foreach $items as $item}>
        ...
    <{/foreach}>
<{/literal}>
```

## 模板变量

### 控制器分配变量

```php
<?php
namespace APP\Control\Admin;

Class Index extends Common {
    function index(){
        // 分配单个变量
        $this->assign('title', '后台首页');
        $this->assign('username', 'admin');
        
        // 分配数组
        $this->assign('users', [
            ['username' => 'admin', 'email' => 'admin@example.com'],
            ['username' => 'user', 'email' => 'user@example.com'],
        ]);
        
        // 分配对象
        $this->assign('user', (object)[
            'username' => 'admin',
            'email' => 'admin@example.com'
        ]);
        
        $this->display();
    }
}
```

### 模板中使用

```html
<h1><{$title}></h1>
<p>用户名：<{$username}></p>

<!-- 数组 -->
<{foreach $users as $user}>
    <p><{$user.username}> - <{$user.email}></p>
<{/foreach}>

<!-- 对象 -->
<p><{$user.username}> - <{$user.email}></p>
```

### 自动分配的变量

| 变量名 | 说明 | 示例 |
|--------|------|------|
| `root` | 项目根目录 | `/www/wwwroot/candy/` |
| `app` | 当前应用名 | `Admin` |
| `public` | 公共资源路径 | `/Public/` |
| `res` | 资源路径 | 资源 URL |
| `candy_ver` | 框架版本号 | `5.1.7` |
| `cli` | 是否为命令行 | `true/false` |
| `ismobile` | 是否为移动设备 | `true/false` |

## 模板标签

### 1. 条件标签

```html
<!-- 基本 if -->
<{if $condition}>
    内容
<{/if}>

<!-- if-else -->
<{if $condition}>
    条件为真
<{else}>
    条件为假
<{/if}>

<!-- if-elseif-else -->
<{if $status == 1}>
    状态 1
<{elseif $status == 2}>
    状态 2
<{else}>
    其他状态
<{/if}>
```

### 2. 循环标签

```html
<!-- 基本 foreach -->
<{foreach $items as $item}>
    <{$item}>
<{/foreach}>

<!-- 带键名 -->
<{foreach $items as $key => $item}>
    <{$key}: <{$item}>
<{/foreach}>

<!-- 带修饰符 -->
<{foreach $items as $item}>
    当前索引：<{$item@index}>
    当前键名：<{$item@key}>
    当前值：<{$item@value}>
    是否首次：<{$item@first}>
    是否末次：<{$item@last}>
    总计：<{$item@total}>
<{/foreach}>
```

### 3. 变量调节器（管道符）

```html
<!-- 格式化日期 -->
<{$createTime|date='Y-m-d H:i:s'}>

<!-- 字符串转换 -->
<{$username|strtoupper}>
<{$content|strtolower}>

<!-- 截取字符串 -->
<{$content|substr=0,100}>

<!-- 多个调节器链式调用 -->
<{$content|strtoupper|substr=0,100}>
```

### 4. 注释标签

```html
<!-- 模板注释（编译时会被移除） -->
<!-- 这是注释 -->

<!-- 将变量标记为注释，编译时展开 -->
<!--{$var}-->
<!--{$user.username}-->
```

## 模板继承

### 父模板（布局模板）

```html
<!-- Application/Admin/Views/Public/layout.html -->
<!DOCTYPE html>
<html>
<head>
    <title><{block name='title'}>默认标题<{/block}></title>
    <meta charset="UTF-8">
    <{block name='head'}>
    <link rel="stylesheet" href="/Public/css/main.css">
    <{/block}>
</head>
<body>
    <{block name='header'}>
    <header>
        <h1>网站头部</h1>
    </header>
    <{/block}>
    
    <{block name='content'}>
    <main>
        默认内容
    </main>
    <{/block}>
    
    <{block name='footer'}>
    <footer>
        <p>网站底部</p>
    </footer>
    <{/block}>
    
    <{block name='script'}>
    <script src="/Public/js/main.js"></script>
    <{/block}>
</body>
</html>
```

### 子模板（继承父模板）

```html
<!-- Application/Admin/Views/Index/index.html -->
<{extend name='Public/layout'}>

<{block name='title'}>后台首页<{/block}>

<{block name='content'}>
<div class="dashboard">
    <h2>欢迎，<{$adminName}></h2>
    <p>这是后台首页内容</p>
</div>
<{/block}>

<{block name='script'}>
<script src="/Public/js/dashboard.js"></script>
<{/block}>
```

### 继承规则

1. `<{extend}>` 必须在模板最前面
2. 可以嵌套继承
3. 子模板可以覆盖父模板的 block
4. 未覆盖的 block 使用父模板内容

## 模板钩子

### 什么是钩子？

钩子允许插件在模板的特定位置插入内容，实现插件化扩展。

### 使用钩子

```html
<!-- 在模板中放置钩子 -->
<!--{hook Index/header}-->

<div class="content">
    页面主体内容
</div>

<!--{hook Index/sidebar}-->
<!--{hook Index/footer}-->
```

### 钩子解析规则

```
<!--{hook 控制器/文件名}-->
```

框架会自动加载：
```
Plugins/{插件名}/Hook/控制器/文件名.html
```

### 钩子示例

**模板中：**
```html
<!--{hook Index/header}-->
```

**插件中：**
```html
<!-- Plugins/Demo/Hook/Index/header.html -->
<div class="plugin-header">
    插件插入的头部内容
</div>
```

### Public 目录结构

```
Application/Admin/Views/Public/
├── layout.html          # 布局模板
├── header.html          # 头部模板
├── footer.html          # 底部模板
├── sidebar.html         # 侧边栏模板
├── 404.html            # 404 页面
├── success.html        # 成功提示页面
└── error.html          # 错误提示页面
```

### 引用公共模板

```html
<!-- 方式 1：include -->
<{include file='Public/header'}>

<!-- 方式 2：直接路径 -->
<{include file='Public/sidebar'}>
```

### 成功/错误页面

框架自动处理，模板示例：

```html
<!-- Public/success.html -->
<!DOCTYPE html>
<html>
<head>
    <meta http-equiv="Content-Type" content="text/html; charset=utf-8" />
    <{if $timeout > 0}>
    <meta http-equiv="refresh" content="<{$timeout}>;URL=<{$location}>" />
    <{/if}>
    <title>提示消息</title>
</head>
<body>
    <div class="candy-msg">
        <div class="candy-msg-title">提示信息</div>
        <div class="candy-msg-body">
            <div class="candy-info"><{$mess}></div>
            <{if $timeout > 0}>
            <p>本页面将在 <{$timeout}> 秒后跳转...</p>
            <{else}>
            <p><a href="javascript:history.back(-1)">点击返回</a></p>
            <{/if}>
        </div>
    </div>
</body>
</html>
```

## 最佳实践

### 1. 模板文件组织

```
Application/Admin/Views/
├── Public/                    # 公共模板
│   ├── layout.html           # 主布局
│   ├── header.html           # 头部
│   ├── footer.html           # 底部
│   └── 404.html             # 404 页面
├── Index/                    # 首页控制器
│   ├── index.html           # 首页
│   └── dashboard.html       # 仪表盘
├── User/                     # 用户控制器
│   ├── index.html           # 列表页
│   ├── add.html             # 添加页
│   └── edit.html            # 编辑页
└── Login/                    # 登录控制器
    └── index.html           # 登录页
```

### 2. 使用布局模板

```html
<!-- 所有页面继承 Public/layout -->
<{extend name='Public/layout'}>

<{block name='title'}>页面标题<{/block}>

<{block name='content'}>
<!-- 页面内容 -->
<{/block}>
```

### 3. 多语言支持

```html
<!-- 使用 L() 函数 -->
<title><{L('pageTitle')}></title>
<button><{L('submit')}></button>
<label><{L('username')}></label>
```

### 4. URL 生成

```html
<!-- 使用 U() 函数 -->
<a href="<{U('Index/index')}>">首页</a>
<a href="<{U('User/edit', ['id' => $user.id])}>">编辑</a>
<form action="<{U('Login/dologin')}>" method="post">
```

### 5. 资源引用

```html
<!-- CSS -->
<link rel="stylesheet" href="<{$public}>css/main.css">

<!-- JavaScript -->
<script src="<{$public}>js/main.js"></script>

<!-- 图片 -->
<img src="<{$public}>images/logo.png">
```

### 6. 安全注意事项

```html
<!-- ❌ 禁止在模板中使用 PHP 代码 -->
<?php echo $var; ?>  <!-- 禁止！ -->

<!-- ✅ 使用模板语法 -->
<{$var}>

<!-- ✅ 转义输出（防止 XSS） -->
<{$content|htmlspecialchars}>
```

### 7. 性能优化

```html
<!-- 使用缓存 -->
<{cache id='sidebar' ttl=3600}>
    <{include file='Public/sidebar'}>
<{/cache}>

<!-- 避免在循环中调用函数 -->
<{foreach $users as $user}>
    <!-- ❌ 不好 -->
    <{date('Y-m-d', $user.createTime)}>
    
    <!-- ✅ 好：在控制器中处理 -->
    <{$user.createTimeFormatted}>
<{/foreach}>
```

## 常见问题

### Q1: 模板不生效怎么办？

**A:** 检查以下几点：
1. 模板文件路径是否正确
2. 文件名是否为 `{控制器名}/{操作名}.html`
3. 清除 `Runtime/Comps/` 编译缓存
4. 检查模板分隔符是否为 `<{` 和 `}>`

### Q2: 变量不显示怎么办？

**A:** 检查：
1. 控制器中是否使用 `$this->assign()` 分配变量
2. 变量名是否正确（区分大小写）
3. 是否使用了保留变量名（如 foreach, if 等）

### Q3: 如何调试模板？

**A:** 开启 Debug 模式：
```php
// 在配置中开启
define('DEBUG', true);
```

### Q4: 模板继承如何使用？

**A:** 在子模板第一行使用：
```html
<{extend name='Public/layout'}>
```
