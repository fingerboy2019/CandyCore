# Candy框架语言功能

## 概述

Candy框架提供了完善的语言国际化支持，允许开发者轻松创建支持多语言的应用程序。框架通过语言文件加载和管理机制，实现了应用程序的国际化和本地化。

## 核心功能

### 语言文件加载机制

框架的语言功能主要在`App.class.php`文件的`run()`方法中实现，具体代码位于第280-301行。加载过程遵循以下优先级顺序：

1. **项目公共语言库**
2. **操作语言库**
3. **插件语言库**

### 核心实现代码

```php
//项目公共语言库
$LANG = [];
$lg = G('LANG') ?: 'zh';
$clangfile = T('APP_PATH') .'Languages/'. $lg .'/Common.lang.php';
if(fileExistsCase($clangfile))
    include PFILE . $clangfile;

//操作语言库（保留多驼峰：DemoItem.lang.php，禁止 ucfirst(strtolower)）
$controller = \Candy\Extend\Str::controlName((string) ($_GET['m'] ?? ''));
$langfile = T('APP_PATH') .'Languages/'. $lg .'/'. $controller .'.lang.php';
if(fileExistsCase($langfile))
    include PFILE . $langfile;

//插件语言库
$plangfile = C('PLUGPATH') . T('RAPPNAME') . '/Languages/'. $lg .'/'. $controller .'.lang.php';
if(fileExistsCase($plangfile)){
    include PFILE . $plangfile;
    $plangfile = $langfile;
}
//储存语言
C('LANGINFO', $LANG);
```

## 详细功能解析

### 1. 语言参数获取

- **默认语言**: 框架默认使用`zh`(中文)
- **动态切换**: 通过`G('LANG')`获取请求中的语言参数，支持动态切换语言
- **语言变量**: 语言参数存储在`$lg`变量中，用于后续加载对应语言文件

### 2. 项目公共语言库

- **路径**: `APP_PATH/Languages/{语言代码}/Common.lang.php`
- **作用**: 存储应用程序的公共语言常量，被所有模块共享
- **加载条件**: 文件存在且大小写匹配

### 3. 操作语言库

- **路径**: `APP_PATH/Languages/{语言代码}/{模块名}.lang.php`
- **作用**: 存储特定模块的语言常量
- **命名规则**: 模块名首字母大写，其余小写
- **加载条件**: 文件存在且大小写匹配

### 4. 插件语言库

- **路径**: `PLUGPATH/{项目名}/Languages/{语言代码}/{模块名}.lang.php`
- **作用**: 存储插件的语言常量
- **命名规则**: 与操作语言库相同
- **加载条件**: 文件存在且大小写匹配
- **覆盖机制**: 插件语言可以覆盖项目的操作语言

### 5. 语言存储

- **全局变量**: 所有加载的语言常量存储在`$LANG`数组中
- **配置存储**: 通过`C('LANGINFO', $LANG)`将语言信息存储到框架配置中，供全局访问

## 语言文件结构

### 公共语言文件(Common.lang.php)

```php

/**
 * 公共语言文件
 */
$LANG = [
    'welcome' => '欢迎使用Candy框架',
    'submit' => '提交',
    'cancel' => '取消',
    // 更多公共语言常量...
];
```

### 模块语言文件(如User.lang.php)

```php

/**
 * 用户模块语言文件
 */
$LANG = [
    'user_login' => '用户登录',
    'user_register' => '用户注册',
    'username' => '用户名',
    'password' => '密码',
    // 更多模块语言常量...
];
```

## 使用方法

### 1. 创建语言文件

在项目目录下创建`Languages`文件夹，并按语言代码创建子目录：

```
Application/
└── Languages/
    ├── zh/
    │   ├── Common.lang.php
    │   ├── User.lang.php
    │   └── ...
    ├── en/
    │   ├── Common.lang.php
    │   ├── User.lang.php
    │   └── ...
    └── ...
```

### 2. 在代码中使用

```php
// 从配置中获取语言信息
$lang = C('LANGINFO');

// 使用语言常量
echo $lang['welcome'];
// 输出: 欢迎使用Candy框架
```

### 3. 动态切换语言

通过URL参数切换语言：

```
http://example.com/index.php?m=Index&a=index&LANG=en
```

## 特性与优势

1. **灵活的语言切换**: 支持通过URL参数动态切换语言
2. **分层加载机制**: 遵循公共→模块→插件的优先级加载顺序
3. **插件支持**: 插件可以拥有自己的语言文件，实现插件的国际化
4. **全局访问**: 加载的语言常量可以全局访问，方便在视图和控制器中使用
5. **兼容大小写**: 使用`fileExistsCase()`函数确保语言文件的大小写兼容

## 最佳实践

1. **语言常量命名**: 使用统一的命名规范，如`module_keyword`
2. **公共语言提取**: 将多个模块共享的语言常量提取到公共语言文件
3. **插件语言隔离**: 插件语言文件应避免与主应用语言冲突
4. **语言文件组织**: 按模块和语言代码合理组织语言文件结构
5. **默认语言设置**: 为应用程序设置合适的默认语言

## 注意事项

1. 语言文件必须返回`$LANG`数组
2. 确保语言文件路径正确，特别是在多项目开发模式下
3. 插件语言会覆盖同名的项目语言常量
4. 语言文件应使用UTF-8编码，确保特殊字符正确显示

## 总结

Candy框架的语言功能提供了简单而强大的国际化支持，通过分层加载机制和灵活的语言切换功能，使开发者能够轻松创建支持多语言的应用程序。框架的语言功能设计合理，使用方便，为应用程序的国际化和本地化提供了良好的支持。
