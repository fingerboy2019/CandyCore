# Candy 框架配置管理指南

## 一、配置文件结构
Candy 框架采用模块化配置方式，配置文件按功能分类存放于 `Application/Common/Conf` 目录下（全局配置）及各模块的 `Conf` 目录下（模块级配置）。默认包含以下核心配置文件：

- `config.php`：基础配置（数据库、时区、调试模式等）
- `route.php`：路由规则配置
- `middleware.php`：中间件注册配置
- `cache.php`：缓存驱动配置

### 1.1 配置文件示例
```php
// Application/Common/Conf/config.php
return [
    'debug'         => true,  // 调试模式
    'timezone'      => 'Asia/Shanghai',  // 时区
    'database'      => [
        'type'     => 'mysql',
        'host'     => 'localhost',
        'name'     => 'candy_db',
        'user'     => 'root',
        'password' => '123456'
    ],
    'template'      => [
        'left_delimiter'  => '{',
        'right_delimiter' => '}'
    ]
];
```

## 二、配置读取
通过 `C()` 函数或 `Config` 类读取配置，支持多级嵌套配置项。

### 2.1 基础读取示例
```php
// 读取全局配置
$debug = C('debug');  // 结果：true

// 读取嵌套配置（数据库类型）
$dbType = C('database.type');  // 结果：'mysql'

// 读取模块级配置（假设当前模块为 'Admin'）
$moduleConfig = C('Admin.upload.max_size');  // 读取 Admin 模块 upload 配置中的 max_size
```

## 三、动态修改配置
支持在运行时动态修改配置，修改仅在当前请求周期内生效。

### 3.1 动态修改示例
```php
// 修改调试模式
C('debug', false);

// 修改数据库密码（嵌套配置）
C('database.password', 'new_password');
```

## 四、多环境配置
支持根据运行环境（开发/测试/生产）加载不同配置，通过 `APP_ENV` 环境变量指定当前环境。

### 4.1 环境配置文件结构
```
Application/
    Common/
        Conf/
            config.php          // 基础配置
            config_dev.php      // 开发环境配置（覆盖基础配置）
            config_test.php     // 测试环境配置
            config_prod.php     // 生产环境配置
```

### 4.2 环境变量设置
通过 `.env` 文件或服务器环境变量设置 `APP_ENV=dev`（开发环境），框架将自动加载 `config_dev.php` 覆盖基础配置。

> **提示**：`.env` 文件需放置于项目根目录，格式为 `APP_ENV=dev`，框架通过 `getenv('APP_ENV')` 读取。

## 五、配置优先级
配置加载遵循以下优先级（从高到低）：
1. 运行时动态修改的配置
2. 当前环境的环境配置（如 `config_dev.php`）
3. 模块级配置（如 `Admin/Conf/config.php`）
4. 全局基础配置（`config.php`）

## 六、配置调试
可通过访问 `/debug/config` 查看所有已加载的配置项及其来源，帮助定位配置冲突或未生效问题。

> **提示**：生产环境应关闭调试模式（`debug=false`），避免泄露配置敏感信息。
