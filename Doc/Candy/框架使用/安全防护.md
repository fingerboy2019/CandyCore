# Candy框架安全模块文档

## 1. 概述

Candy框架的`Security`类是一个全面的安全防护系统，提供了多层次的安全保护机制，包括CSRF防护、XSS过滤、SQL注入防护、IP黑白名单管理、中间件机制和攻击日志记录等功能。该类采用静态方法设计，便于在应用程序的任何地方调用，确保系统的安全性。

## 2. 类结构

### 2.1 基本信息

```php
namespace Candy\Core;

class Security
{
    // 类定义
}
```

### 2.2 核心属性

| 属性名 | 类型 | 描述 |
|--------|------|------|
| `$csrfToken` | string | CSRF令牌值 |
| `$blackList` | array | IP黑名单 |
| `$whiteList` | array | IP白名单 |
| `$rank` | string | 安全等级 |
| `$Middlewares` | array | 中间件集合 |
| `$checkData` | array | 检查数据 |
| `$antiSqlInjectionPatterns` | array | SQL注入检测正则表达式 |

## 3. 核心安全功能

### 3.1 CSRF防护

CSRF（跨站请求伪造）防护机制用于防止恶意网站利用用户的身份执行未授权操作。

#### 3.1.1 主要方法

- `generateToken()`: 生成CSRF令牌
- `checkToken()`: 验证CSRF令牌
- `getToken()`: 获取当前CSRF令牌
- `removeToken()`: 移除CSRF令牌

#### 3.1.2 使用示例

```html
// 生成并输出CSRF令牌表单字段
<form method="post">
    <?php echo Security::getToken(); ?>
    <input type="submit" value="提交">
</form>

// 在控制器中验证CSRF令牌
if (!Security::checkToken()) {
    die('CSRF令牌验证失败');
}
```

### 3.2 XSS过滤

XSS（跨站脚本）过滤功能用于防止恶意脚本注入到网页中。

#### 3.2.1 主要方法

- `removeXss()`: 移除XSS攻击代码
- `isXssSafe()`: 检查内容是否安全

#### 3.2.2 使用示例

```php
// 过滤用户输入
$safeContent = Security::removeXss($_POST['content']);

// 检查内容是否安全
if (!Security::isXssSafe($userInput)) {
    die('输入包含不安全内容');
}
```

### 3.3 SQL注入防护

SQL注入防护功能用于检测和防止SQL注入攻击。

#### 3.3.1 主要方法

- `checkSqlInjection()`: 检查SQL注入攻击

#### 3.3.2 实现原理

系统使用正则表达式匹配常见的SQL注入模式，包括：
- 注释攻击（`--`, `#`, `/* */`）
- 联合查询攻击（`UNION SELECT`）
- 布尔盲注攻击（`AND 1=1`）
- 时间盲注攻击（`SLEEP()`）
- 其他常见SQL注入模式

### 3.4 IP黑白名单管理

IP黑白名单管理功能用于控制允许或拒绝访问系统的IP地址。

#### 3.4.1 主要方法

- `IPList()`: 加载IP黑白名单
- `add()`: 添加IP到黑白名单
- `delete()`: 从黑白名单中删除IP
- `check()`: 检查IP是否在指定名单中
- `getAll()`: 获取所有IP名单
- `find()`: 查找指定IP是否在名单中
- `clean()`: 清理或重置IP名单

#### 3.4.2 使用示例

```php
// 将当前IP添加到黑名单，有效期1小时
Security::add(['type' => 'b', 'exp_time' => time() + 3600]);

// 添加指定IP范围到白名单
Security::add([
    'type' => 'w',
    'ip_start' => '192.168.1.1',
    'ip_end' => '192.168.1.100'
]);

// 检查当前IP是否在黑名单中
if (Security::check()) {
    die('您的IP已被限制访问');
}
```

### 3.5 中间件机制

中间件机制允许在请求处理的不同阶段执行安全检查和处理。

#### 3.5.1 主要方法

- `runMiddlewares()`: 运行中间件
- `loadMiddleware()`: 加载中间件
- `addMiddlewares()`: 添加多个中间件
- `addMiddleware()`: 添加单个中间件

#### 3.5.2 中间件类型

- `Init`: 初始化阶段中间件
- `Before`: 请求处理前中间件
- `After`: 请求处理后中间件
- `Over`: 响应生成后中间件

### 3.6 攻击日志记录

攻击日志记录功能用于记录检测到的安全攻击，并在必要时自动将攻击者IP加入黑名单。

#### 3.6.1 主要方法

- `_saveAttackLog()`: 保存攻击日志

#### 3.6.2 攻击处理逻辑

1. 记录攻击详情（URL、IP、时间、攻击类型、攻击值、用户代理）
2. 检查攻击频率：
   - 同一IP出现10次以上攻击，自动加入黑名单
   - 同一IP在20秒内对同一URL发起攻击，自动加入黑名单
3. 自动将攻击者IP加入黑名单，默认有效期1小时
4. 显示攻击警告信息

## 4. 安全等级设置

Candy框架支持三种安全等级：

| 等级 | 描述 |
|------|------|
| `low` | 低级安全，仅进行基本的安全检查 |
| `medium` | 中级安全，进行较为严格的安全检查 |
| `high` | 高级安全，进行全面的安全检查 |

可以通过配置文件设置安全等级：

```php
C('securityRank', 'medium');
```

## 5. 配置说明

### 5.1 基本配置

| 配置项 | 类型 | 默认值 | 描述 |
|--------|------|--------|------|
| `securityRank` | string | `medium` | 安全等级 |
| `REMOVEXSS` | bool | `null` | 是否移除XSS攻击代码 |
| `blacklocktime` | int | `3600` | 黑名单锁定时间（秒） |
| `LOGPATH` | string | `./Log/` | 日志文件路径 |

### 5.2 中间件配置

中间件配置文件`Middleware.php`用于定义应用程序使用的中间件：

```php
return [
    'Init' => [
        // 初始化阶段中间件
    ],
    'Before' => [
        // 请求处理前中间件
    ],
    'After' => [
        // 请求处理后中间件
    ],
    'Over' => [
        // 响应生成后中间件
    ],
];
```

## 6. 使用示例

### 6.1 基本安全防护

```php
// 初始化安全模块
Security::init();

// 验证CSRF令牌
if (!Security::checkToken()) {
    die('CSRF令牌验证失败');
}

// 过滤用户输入
$safeContent = Security::removeXss($_POST['content']);

// 检查SQL注入
Security::checkSqlInjection($_GET);

// 检查IP是否在黑名单中
if (checkIP()) {
    die('您的IP已被限制访问');
}
```

### 6.2 IP黑白名单管理

IP黑白名单管理功能已通过全局辅助函数进行了封装，提供了更简洁的调用方式。详细使用方法请参考第7章 全局辅助函数中的IP黑白名单管理辅助函数部分。

### 6.3 中间件使用

```php
// 运行初始化阶段中间件
Security::runMiddlewares('Init');

// 运行请求处理前中间件
Security::runMiddlewares('Before');

// 运行请求处理后中间件
Security::runMiddlewares('After');

// 运行响应生成后中间件
$content = Security::runMiddlewares('Over', $content);
```

## 7. 全局辅助函数

为了方便使用，Candy框架在`global.func.php`中提供了一系列全局辅助函数，这些函数封装了`Security`类的核心功能，提供了更简洁的调用方式。

### 7.1 IP黑白名单管理辅助函数

#### 7.1.1 `addIPList()`

添加IP到黑白名单。

```php
// 添加当前IP到黑名单，有效期1小时
addIPList('b', '', time() + 3600);

// 添加指定IP到白名单
addIPList('w', '192.168.1.10');

// 添加IP范围到黑名单
addIPList('b', ['192.168.1.1', '192.168.1.100']);
```

#### 7.1.2 `delIPList()`

从黑白名单中删除IP。

```php
// 删除当前IP从黑名单
 delIPList('b');

// 删除指定IP从白名单
 delIPList('w', '192.168.1.10');

// 删除IP范围从黑名单
 delIPList('b', ['192.168.1.1', '192.168.1.100']);
```

#### 7.1.3 `checkIP()`

检查IP是否在指定名单中。

```php
// 检查当前IP是否在黑名单
if (checkIP()) {
    die('您的IP已被限制访问');
}

// 检查指定IP是否在白名单
if (checkIP('w', '192.168.1.10')) {
    // 允许访问特权功能
}
```

#### 7.1.4 `cleanIPList()`

清理或重置IP名单。

```php
// 清理黑名单中所有过期记录
cleanIPList('b');

// 清空白名单中所有记录
cleanIPList('w', true);

// 清理所有类型名单的过期记录
cleanIPList();
```

#### 7.1.5 `getIPList()`

获取所有IP名单。

```php
// 获取所有黑名单记录
$blacklist = getIPList();

// 获取所有白名单记录
$whitelist = getIPList('w');

// 遍历黑名单记录
foreach ($blacklist as $item) {
    echo "IP范围: {$item[0]} - {$item[1]}, 过期时间: " . ($item[2] ? date('Y-m-d H:i:s', $item[2]) : '永不过期') . "\n";
}
```

## 8. 最佳实践

1. **始终启用CSRF防护**：在所有表单提交和AJAX请求中使用CSRF令牌
2. **过滤所有用户输入**：使用`removeXss()`方法过滤所有用户提供的内容
3. **验证用户输入**：在处理用户输入前验证其格式和内容
4. **使用IP黑白名单**：限制对敏感功能的访问
5. **定期检查攻击日志**：监控系统的安全状态
6. **根据需求调整安全等级**：在安全性和性能之间取得平衡

## 9. 总结

Candy框架的`Security`类提供了全面的安全防护机制，可以有效防止常见的Web安全攻击。通过合理配置和使用这些安全功能，可以大大提高应用程序的安全性。建议开发者在开发过程中充分利用这些安全功能，确保系统的安全性。
