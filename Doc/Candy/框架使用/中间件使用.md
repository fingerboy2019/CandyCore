## 中间件概述

Candy 框架的中间件机制是通过 `Security` 类实现的核心安全组件，用于在应用请求处理过程中的不同阶段执行特定功能。中间件支持多种类型（Init、Before、Over、After 等），可以灵活地扩展框架功能、增强安全性和实现业务逻辑。

**核心特点**：
- 继承 `Candy\Core\Security` 类
- 实现 `handle()` 方法
- 支持配置参数
- 按类型分类执行

---

## 中间件类型

Candy 框架支持以下几种中间件类型，它们按照特定的执行顺序运行：

| 类型 | 执行时机 | 功能特点 | 返回值 |
|------|----------|----------|--------|
| Init | 应用初始化阶段 | 系统级初始化工作，如环境检查、日志初始化 | 无 |
| Before | 请求处理前 | 请求参数预处理、权限验证、身份认证 | 无 |
| Over | 请求处理中 | 内容处理、数据转换、响应内容修改 | 必须返回 `$content` |
| After | 请求处理后 | 日志记录、资源清理、响应头设置 | 无 |
| Finish | 输出后 | 响应输出后执行 | 无 |

## 中间件创建

### 标准中间件

创建中间件需要继承 `Candy\Core\Security` 类，并实现 `handle()` 方法：

```php
<?php
declare(strict_types=1);
namespace App\Middleware;

use Candy\Core\Security;

class AuthMiddleware extends Security {
    /**
     * 中间件名称
     * @var string
     */
    protected string $name = 'Auth';

    /**
     * 中间件别名
     * @var array
     */
    protected array $aliases = ['auth', 'login'];

    /**
     * 中间件处理逻辑
     * @return void
     */
    public function handle() {
        // 验证用户身份
        if (!isset($_SESSION['user_id'])) {
            // 未登录处理逻辑
            $this->halt('请先登录', 302);
        }
    }

    /**
     * 获取中间件名称
     * @return string
     */
    public function getName(): string {
        return $this->name;
    }

    /**
     * 获取中间件别名
     * @return array
     */
    public function getAliases(): array {
        return $this->aliases;
    }
}
```

### Over 类型中间件（内容处理）

Over 类型中间件用于处理内容，需要接收并返回处理后的内容：

```php
<?php
declare(strict_types=1);
namespace App\Middleware;

use Candy\Core\Security;

class ContentMiddleware extends Security {
    /**
     * 中间件名称
     * @var string
     */
    protected string $name = 'ContentFilter';

    /**
     * 中间件别名
     * @var array
     */
    protected array $aliases = ['filter', 'content'];

    /**
     * 内容处理中间件
     * @param string $content 待处理内容
     * @return string 处理后的内容
     */
    public function handle(string $content): string {
        // 内容处理逻辑，如替换关键词、添加水印等
        $content = str_replace('旧内容', '新内容', $content);
        
        // 过滤脚本标签
        $content = preg_replace('/<script.*?<\/script>/is', '', $content);
        
        return $content;
    }

    public function getName(): string {
        return $this->name;
    }

    public function getAliases(): array {
        return $this->aliases;
    }
}
```

### 带配置参数的中间件

中间件可以通过构造函数接收配置参数：

```php
<?php
declare(strict_types=1);
namespace App\Middleware;

use Candy\Core\Security;

class LogMiddleware extends Security {
    /**
     * 中间件名称
     * @var string
     */
    protected string $name = 'Log';

    /**
     * 中间件别名
     * @var array
     */
    protected array $aliases = ['log', 'logger'];

    /**
     * 日志级别
     * @var string
     */
    protected string $logLevel = 'info';

    /**
     * 日志文件路径
     * @var string
     */
    protected string $logPath = '/var/log/candy/';

    /**
     * 构造函数
     * @param array $config 中间件配置
     */
    public function __construct(array $config = []) {
        $this->logLevel = $config['log_level'] ?? 'info';
        $this->logPath = $config['log_path'] ?? '/var/log/candy/';
    }

    /**
     * 日志记录中间件
     * @return void
     */
    public function handle() {
        // 获取请求上下文
        $context = self::getRequestContext();

        // 记录请求日志
        Log::info($this->logLevel, 'Request: ' . $context['method'] . ' ' . $context['path']);
    }

    public function getName(): string {
        return $this->name;
    }

    public function getAliases(): array {
        return $this->aliases;
    }
}
```

## 中间件配置

### 配置文件

中间件通过配置文件加载，默认配置文件路径为 `Source/Inc/Middleware.inc.php`：

```php
<?php
return [
    // 初始化中间件
    'Init' => [
        'APP\Middleware\InitMiddleware',
    ],
    
    // 请求前中间件
    'Before' => [
        'APP\Middleware\AuthMiddleware' => [
            'enabled' => true,
            'except_paths' => ['/login', '/captcha'],
            'required_paths' => ['/admin/*'],
        ],
    ],
    
    // 内容处理中间件
    'Over' => [
        'APP\Middleware\ContentMiddleware' => [
            'filters' => ['script', 'iframe'],
        ],
    ],
    
    // 请求后中间件
    'After' => [
        'APP\Middleware\LogMiddleware' => [
            'log_level' => 'info',
            'log_path' => '/var/log/candy/',
        ],
    ],
    
    // 请求后中间件
    'Finish' => [
        'APP\Middleware\FinishMiddleware',
    ],
];
```

### 配置格式

#### 格式一：简单类名（无配置）

```php
'Before' => [
    'APP\Middleware\SimpleMiddleware',
],
```

#### 格式二：带配置参数（推荐）

```php
'Before' => [
    'APP\Middleware\JwtAuthMiddleware' => [
        'enabled' => true,
        'except_paths' => ['/login', '/captcha'],
        'required_paths' => ['/admin/*'],
        'csrf_enable' => true,
    ],
],
```

## 中间件执行流程

1. **应用启动**：调用 `Security::run()` 初始化安全系统
2. **中间件加载**：从配置文件加载所有中间件
3. **中间件注册**：将中间件按类型注册到中间件集合中
4. **中间件执行**：
   - `Init` 中间件：在应用初始化阶段执行
   - `Before` 中间件：在请求处理前执行
   - `Over` 中间件：在请求处理中执行，用于内容处理
   - `After` 中间件：在请求处理后执行
   - `Finish` 中间件：在响应输出后执行

**执行顺序示例**：

```
┌─────────────────────────────────────────────────────┐
│  1. Init 中间件（系统初始化）                        │
│  └─ 环境检查、日志初始化等                           │
├─────────────────────────────────────────────────────┤
│  2. Before 中间件（请求处理前）                     │
│  └─ 认证验证、权限检查等                            │
├─────────────────────────────────────────────────────┤
│  3. Over 中间件（内容处理）                         │
│  └─ 内容过滤、数据转换等                            │
├─────────────────────────────────────────────────────┤
│  4. After 中间件（请求处理后）                      │
│  └─ 日志记录、清理资源等                            │
├─────────────────────────────────────────────────────┤
│  5. Finish 中间件（输出后）                         │
│  └─ 压缩响应、添加头信息等                          │
└─────────────────────────────────────────────────────┘
```

## 请求上下文

框架提供 `self::getRequestContext()` 方法获取请求上下文，返回数组包含：

```php
[
    'path' => '/admin/user/index',           // PATH_INFO
    'request_uri' => '/admin/user/index',    // REQUEST_URI
    'method' => 'GET',                       // 请求方法
    'is_ajax' => false,                      // 是否 AJAX 请求
    'is_get' => true,                        // 是否 GET
    'is_post' => false,                      // 是否 POST
    'is_put' => false,                       // 是否 PUT
    'is_delete' => false,                    // 是否 DELETE
    'is_write' => false,                     // 是否写操作（POST/PUT/DELETE/PATCH）
    'ip' => '127.0.0.1',                     // 客户端 IP
    'user_agent' => 'Mozilla/5.0...',        // User-Agent
    'referer' => '',                         // 来源页面
    'get' => [],                             // $_GET
    'post' => [],                            // $_POST
    'cookie' => [],                          // $_COOKIE
    'server' => [],                          // $_SERVER
]
```

**使用示例**：

```php
public function handle(string $content = '') {
    $context = self::getRequestContext();
    
    // 获取请求路径
    $path = $context['path'];
    
    // 获取请求方法
    $method = $context['method'];
    
    // 判断是否写操作
    if ($context['is_write']) {
        // 处理写操作逻辑
    }
    
    return $content;
}
```

## 开发示例

### 示例 1：日志记录中间件

```php
<?php
declare(strict_types=1);
namespace App\Middleware;

use Candy\Core\Security;
use Candy\Core\Log;

class LogMiddleware extends Security {
    protected string $name = 'Log';
    protected array $aliases = ['log', 'logger'];

    public function __construct(array $config = []) {}

    public function getName(): string {
        return $this->name;
    }

    public function getAliases(): array {
        return $this->aliases;
    }

    public function handle(string $content = '') {
        $context = self::getRequestContext();
        
        // 记录请求日志
        Log::info('Request: ' . $context['method'] . ' ' . $context['path']);
        
        return $content;
    }
}
```

### 示例 2：内容过滤中间件

```php
<?php
declare(strict_types=1);
namespace App\Middleware;

use Candy\Core\Security;

class ContentFilterMiddleware extends Security {
    protected string $name = 'ContentFilter';
    protected array $aliases = ['filter', 'content'];
    protected array $filters = [];

    public function __construct(array $config = []) {
        $this->filters = $config['filters'] ?? [];
    }

    public function getName(): string {
        return $this->name;
    }

    public function getAliases(): array {
        return $this->aliases;
    }

    public function handle(string $content = '') {
        if (empty($this->filters)) {
            return $content;
        }

        foreach ($this->filters as $filter) {
            switch ($filter) {
                case 'script':
                    $content = preg_replace('/<script.*?<\/script>/is', '', $content);
                    break;
                case 'iframe':
                    $content = preg_replace('/<iframe.*?<\/iframe>/is', '', $content);
                    break;
            }
        }

        return $content;
    }
}
```

### 示例 3：JWT 认证中间件

```php
<?php
declare(strict_types=1);
namespace App\Middleware;

use Candy\Core\Security;

class JwtAuthMiddleware extends Security {
    protected string $name = 'JwtAuth';
    protected array $aliases = ['jwt', 'auth'];
    protected bool $enabled = true;
    protected array $exceptPaths = [];
    protected array $requiredPaths = [];

    public function __construct(array $config = []) {
        $this->enabled = $config['enabled'] ?? true;
        $this->exceptPaths = $config['except_paths'] ?? [];
        $this->requiredPaths = $config['required_paths'] ?? [];
    }

    public function getName(): string {
        return $this->name;
    }

    public function getAliases(): array {
        return $this->aliases;
    }

    public function handle(string $content = '') {
        if (!$this->enabled) {
            return $content;
        }

        $context = self::getRequestContext();
        $path = $context['path'];

        // 检查是否在排除路径中
        if ($this->isExceptPath($path)) {
            return $content;
        }

        // 检查是否在必需路径中
        if ($this->isRequiredPath($path)) {
            // 验证 JWT Token
            if (!\APP\Extend\HybridAuth::isAuthenticated()) {
                $this->halt('请先登录', 302);
            }
        }

        return $content;
    }

    protected function isExceptPath(string $path): bool {
        foreach ($this->exceptPaths as $except) {
            if ($this->matchPath($path, $except)) {
                return true;
            }
        }
        return false;
    }

    protected function isRequiredPath(string $path): bool {
        foreach ($this->requiredPaths as $required) {
            if ($this->matchPath($path, $required)) {
                return true;
            }
        }
        return false;
    }

    protected function matchPath(string $path, string $pattern): bool {
        if ($pattern === $path) {
            return true;
        }

        // 支持通配符
        if (strpos($pattern, '*') !== false) {
            $pattern = str_replace('*', '.*', $pattern);
            return preg_match('/^' . $pattern . '$/', $path) === 1;
        }

        return false;
    }

    public function halt($message, $code = 401): void {
        $this->exit($message, $code);
    }
}
```

## 最佳实践

### 1. 使用配置而非硬编码

```php
// ❌ 不好
protected array $exceptPaths = ['/login', '/captcha'];

// ✅ 好
public function __construct(array $config = []) {
    $this->exceptPaths = $config['except_paths'] ?? [];
}
```

### 2. 使用请求上下文

```php
// ❌ 不好
$path = $_SERVER['PATH_INFO'] ?? '/';
$method = $_SERVER['REQUEST_METHOD'] ?? 'GET';

// ✅ 好
$context = self::getRequestContext();
$path = $context['path'];
$method = $context['method'];
```

### 3. 提前返回避免嵌套

```php
// ❌ 不好
if ($this->enabled) {
    if (!$this->isExceptPath($path)) {
        if ($this->isRequiredPath($path)) {
            // 处理逻辑
        }
    }
}

// ✅ 好
if (!$this->enabled) {
    return $content;
}
if ($this->isExceptPath($path)) {
    return $content;
}
if (!$this->isRequiredPath($path)) {
    return $content;
}
// 处理逻辑
```

### 4. 使用通配符匹配路径

```php
// 支持通配符
'required_paths' => [
    '/admin/*',      // 匹配 /admin/ 下所有路径
    '/api/v1/*',     // 匹配 /api/v1/ 下所有路径
],
```

### 5. Over 类型必须返回

```php
// Over 类型中间件必须返回处理后的内容
public function handle(string $content): string {
    // 处理逻辑
    return $content;  // 必须返回
}
```

### 6. 性能优化

```php
// ❌ 不好：在中间件中执行数据库查询
public function handle() {
    $users = DB::query("SELECT * FROM users");
    // ...
}

// ✅ 好：在控制器中执行
public function handle() {
    // 只做轻量级操作
    Log::info('Request processed');
}
```

## 常见问题

### Q1: 如何动态添加排除路径？

```php
// 在中间件中提供方法
public function addExceptPaths($paths): self {
    $this->exceptPaths = array_merge($this->exceptPaths, (array)$paths);
    return $this;
}
```

### Q2: 如何在中间件之间传递数据？

```php
// 使用 $_REQUEST 注入数据
$_REQUEST['_auth_user_id'] = $userId;
$_REQUEST['_auth_user'] = $user;
```

### Q3: 如何临时禁用中间件？

```php
// 配置中设置
'APP\Middleware\JwtAuthMiddleware' => [
    'enabled' => false,  // 临时禁用
],
```
