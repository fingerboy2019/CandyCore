# Candy 类验证（Validate）

## 概述

Candy 使用**类规则验证器**（运行时继承 `Candy\Extend\Validate\Base`），不再使用 XML。  
规则写在 `Application/{App}/Validates/{Name}.class.php`（短名），ORM `insert`/`update` 开启验证可自动解析。

统一 API 返回外壳仍为 `{code, message, data}`；响应 `data` 形状见 [响应 Schema](响应Schema.md)。

**约定**：短名源码**不写** `extends`；编译时追加 `{Name}Validate` 后缀并挂到框架 Base（与 Model/Service 相同）。短名互继承写 `class Foo extends Group`，编译为 `FooValidate extends GroupValidate`。

## 目录约定

```
Application/{App}/Validates/{Name}.class.php   # 源码短名，如 Group.class.php
Runtime/Validates/{App}/groupvalidate.*.php    # 编译产物，类名 GroupValidate
```

命名空间：`APP\Validate\{App}`；运行时类名：`{Name}Validate`（与 Model→Model、Service→Service 同一套 Runtime 编译）。

## 快速示例

```php
<?php
namespace APP\Validate\Admin;

// 短名类：不写 extends、不写 Validate 后缀；二者均由编译追加
class Group
{
    protected array $fields = [
        'authCode' => '授权码',
        'name'     => '组名',
    ];

    protected array $rules = [
        'authCode' => 'require|unique:gid',
        'name'     => 'require|unique:gid',
    ];

    protected array $scenes = [
        'add' => ['authCode', 'name'],
        'mod' => [
            'authCode' => 'unique:gid',
            'name'     => 'require|unique:gid',
        ],
    ];

    protected array $messages = [
        'authCode.unique' => '授权码已存在，请换一个',
        'name.unique'     => '组名已存在',
    ];
}
```

手动校验（使用编译后的运行时类名）：

```php
$ok = \APP\Validate\Admin\GroupValidate::make($data)->setDb($db)->scene('add')->check();
```

Apidoc 可通过 `#[ApiContract]` / 约定从 Validate 补全请求字段，见 `Doc/Candy/第三方类库/Apidoc使用文档.md` §1.1。

## ORM 自动接线

`insert` / `update`（及 `add` / `save`）在 `$validate = 1` 或数据含 `token` 时调用 `DbBridge`：

1. CSRF：`token` / `csrf` / `HTTP_USER_TOKEN_CSRF`；无 token 时校验 Referer 同源
2. 解析 `APP\Validate\{App}\{Table}Validate`（或 Model 上 `public string $validateClass`）
3. 场景：`add`（insert）/ `mod`（update）；亦识别 `create`/`update` 等同义 scene 名

无对应 Validate 类时：仅做 CSRF，跳过字段规则（与「无 XML 仅 token」行为一致）。

```php
$db->insert($data, 1, 1);           // 开启验证
$db->where('id', 1)->update($data, 1, 1);
```

## 规则 DSL

| 规则 | 说明 |
|------|------|
| `require` / `notnull` | 非空 |
| `string` / `int` / `numeric` / `array` / `bool` | 类型 |
| `email` / `url` / `mobile` | 格式 |
| `max:n` / `min:n` / `length:m,n` / `between:a,b` | 长度/区间 |
| `in:a,b,c` / `notIn:...` | 枚举 |
| `confirm:field` | 与另一字段一致 |
| `unique` / `unique:主键` | 库内唯一（需 `setDb`；更新时排除自身主键） |
| `regex:/.../` | 自定义正则 |
| 点号字段 | `profile.email`；数组项 `tags.*`（通配） |

## CSRF

```php
takeToken();                          // 表单 hidden
$token = \Candy\Extend\Validate\Csrf::create();
\Candy\Extend\Validate\Csrf::check($token);
```

链式写操作：`$db->token($token)->delete(...)` 等走同一套 Csrf。

## 插件相关：两套机制（勿混用）

与 Control / Model / Service **完全相同**：

### 1. Hook 挂载（片段注入）

源码里的 `// hook xxx.php` 在编译进 Runtime 时，替换为各启用插件 `Plugins/{Plug}/Hook/xxx.php` 的内容。只拼片段，不产生新类。

### 2. 插件类：继承 / 覆写 / 替代

编译时同时读应用与扩展项目目录：

```
Application/{App}/Validates/Group.class.php
Plugins/{RAPPNAME}/Validates/Group.class.php
    ↓
Runtime/Validates/{App}/…（运行时类名 GroupValidate）
```

| 场景 | 行为 |
|------|------|
| 仅应用有 | 编译应用 |
| 仅插件有 | 以插件编译（替代） |
| 两者都有，插件类**无** `extends` | 应用 → `*ValidateBase`，插件 → `*Validate extends *ValidateBase`（继承扩展） |
| 两者都有，插件类**有** `extends` | 以插件为准（覆写） |

## 生成骨架

```bash
php candy make:validate Admin Group
# → Application/Admin/Validates/Group.class.php（源码）
# → 首次加载编译为 Runtime/Validates/Admin/groupvalidate.*.php（类名 GroupValidate）
```

## Schema（响应）

响应文档用应用层 `Schemas/`（编译为 `{Name}Schema`），见 [响应 Schema](响应Schema.md)。Validate 管入参，Schema 管出参 `data`。
