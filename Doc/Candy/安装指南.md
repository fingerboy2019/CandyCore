# Candy 框架安装指南

## 环境要求

- **PHP** 8.4+
- **数据库** MySQL 5.7+ / MariaDB 10.3+（或 PostgreSQL、SQLite，见数据库文档）
- **Web 服务器** Nginx / Apache，需支持 **PATHINFO** 与伪静态
- **推荐扩展**：`mbstring`、`pdo_mysql`、`openssl`、`json`、`curl`；可选 `redis`、`gd`

## 获取代码

```bash
git clone <仓库地址> candy
cd candy/backend
```

或使用发布包解压，Web 根目录指向 **`backend/`**（含 `index.php`）。

## 依赖

Composer 依赖位于 `Candy/Vendor/`，按项目说明安装扩展：

```bash
php Candy composer install <扩展名>
```

## 数据库配置

编辑 **`Source/Inc/Config.inc.php`** 中 `DB.default`：

```php
'default' => [
    'HOST'      => 'localhost',
    'USER'      => 'your_user',
    'PASS'      => 'your_password',
    'DBNAME'    => 'your_database',
    'TABPREFIX' => 'sa_',
],
```

调试模式下也可通过首页 **开发脚手架** 填写并写入该文件（见 [raw/doc/sql/README.md](../../raw/doc/sql/README.md)）。

## 初始化配置

1. **`Source/Inc/Init.inc.php`**：`DEBUG`（1 开发 / 0 生产）
2. **`Source/Inc/System.inc.php`**：模板路径等（如 `$tplpath = 'Home@./Template'`）
3. **`Source/Inc/Route.inc.php`**：伪静态后缀（Admin 常用 `.shtml`）

## Nginx 伪静态（示例）

```nginx
location / {
    try_files $uri $uri/ /index.php$is_args$args;
}
# 禁止直接访问框架与源码目录
location ~ ^/(Candy|Source|Runtime|Application)/ {
    return 404;
}
```

## 启动

| 环境 | 方式 |
|------|------|
| 生产 Web | 配置站点根目录为 `backend/`，访问域名 |
| 开发 Web | 同上，`DEBUG=1` |
| CLI | `php candy list` · `php candy server`（见 Server.inc.php） |

## 验证

- 开发模式访问 `/` 或 `/Doc/Candy/` 可见文档
- 脚手架初始化后访问 `/Admin/Login/index.shtml`
- CLI：`php candy scaffold:init --status`
