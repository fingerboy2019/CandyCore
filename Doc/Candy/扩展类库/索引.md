# Candy Extend 扩展类库

## 简介

Candy Extend 扩展类库是 Candy 框架的核心扩展组件，提供了一系列实用工具类，用于简化开发过程中的常见操作。这些类库采用静态方法设计，方便直接调用，无需实例化。

## 类库列表

### 安全认证类
- [JwtToken 类](JwtToken使用文档.md) - JWT 登录态（Bearer Cookie/Header）
- [Totp 类](Totp使用文档.md) - RFC 6238 TOTP / 恢复码工具（Admin 双因素底层）
- [Signer](Signer使用文档.md) - HTTP API 硬签与下载签名
- [PayloadCrypto](PayloadCrypto使用文档.md) - HTTP/Rpc 载荷 AES-256-GCM（强密备选）

### 数组操作类
- [Arr 类](Arr使用文档.md) - 功能丰富的数组操作工具类，提供数组访问判断、多维数组处理、数组过滤、数组排序等一系列常用操作。

### 文件系统操作类
- [Dir 类](Dir使用文档.md) - 文件夹操作类，提供目录创建、删除、复制、移动等功能，支持文件列表获取和过滤。

### 字符串操作类
- [Str 类](Str使用文档.md) - 字符串操作工具类，提供字符串处理、格式化、转换等功能。

### 文件操作类
- [File 类](File使用文档.md) - 文件操作工具类，提供文件读写、复制、移动、删除等功能。

### 加密解密类
- [Mcrypt 类](Mcrypt使用文档.md) - 加密解密工具类，提供数据加密解密、哈希生成等功能。
- [PayloadCrypto](PayloadCrypto使用文档.md) - AES-256-GCM 业务载荷加解密；`php candy payload-crypto:init` 后启用。

### 环境变量类
- [Env 类](Env使用文档.md) - 环境变量管理类，用于加载和获取环境变量。

### 会话管理类
- [Session 类](Session使用文档.md) - 会话管理类，提供会话创建、销毁、数据存储等功能。

### 哈希 ID 类
- [Hashids 类](Hashids使用文档.md) - Hashids 实现类，用于将数字转换为唯一的字符串表示。

### 集合类
- [Collection 类](Collection使用文档.md) - 集合操作类，提供集合数据的各种操作方法。

### XML 操作类
- [Xml 类](Xml使用文档.md) - XML 操作工具类，提供 XML 解析和生成功能。

## 命名空间

所有扩展类库都位于 `Candy\Extend` 命名空间下：

```php
namespace Candy\Extend;
```

## 使用方法

1. **直接使用静态方法**：大部分类库采用静态方法设计，可以直接通过类名调用。

```php
// 使用 Arr 类的方法
$array = ['name' => 'John', 'age' => 30];
$name = Arr::get($array, 'name');

// 使用 Dir 类的方法
Dir::create('./new/directory');
```

2. **实例化使用**：部分类库需要实例化后使用。

```php
// 使用 Dir 类的实例方法
$dir = new Dir('./path/to/directory');
$files = $dir->getIterator();
```

## 注意事项

1. **命名空间导入**：在使用类库前，需要导入相应的命名空间或使用完全限定类名。

```php
// 导入命名空间
use Candy\Extend\Arr;

// 或使用完全限定类名
Candy\Extend\Arr::get($array, 'name');
```

2. **文件权限**：使用文件系统相关类库时，确保 PHP 脚本有相应的文件系统操作权限。

3. **性能考虑**：对于大型数据处理，注意选择合适的方法，避免不必要的性能消耗。

4. **安全注意**：使用加密解密相关功能时，确保密钥的安全存储和管理。

5. **核心补充类库**：上述补充类位于 `Candy\Vendor\Extend` 命名空间；API 查阅以本目录「使用文档」为准（已移除类库文档下的重复副本）。
