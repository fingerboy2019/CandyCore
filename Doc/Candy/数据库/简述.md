# Candy框架数据库模块文档

## 概述

Candy框架的数据库模块提供了强大而灵活的数据库操作功能，支持多种数据库类型（MySQL、PostgreSQL、SQLite等），采用面向对象的方式设计，提供了丰富的API接口，简化了数据库操作的复杂性。

## 主要特性

- **多数据库支持**：MySQL、PostgreSQL、SQLite；多连接别名用于**库隔离**（非自动主从）
- **面向对象设计**：采用ORM模式，支持连贯操作
- **强大的查询构建器**：支持各种复杂查询
- **事务支持**：完整的事务管理
- **连接池管理**：高效的连接复用机制
- **数据缓存**：内置数据缓存功能
- **软删除支持**：保护误删除数据
- **数据验证**：内置数据验证机制
- **自动时间戳**：自动填充创建和更新时间
- **数据库备份与还原**：完整的备份还原功能

多库说明见 [多数据库切换功能说明](../框架使用/多数据库切换功能说明.md)。  
驱动演进、连接治理、异步只读与 ClickHouse 见 [驱动与连接规划](驱动与连接规划.md)。  
**完整实操手册**见 [详细使用指南](详细使用指南.md)。

## 快速开始

### 1. 安装与配置

环境要求见 [安装与配置](安装与配置.md)（**配置实操以 [详细使用指南](详细使用指南.md) 为准**）。

### 2. 建立连接

```php
// 使用全局函数 db()
$db = db('user');

// 使用D函数获取数据库连接（支持跨项目调用）
$db = D('user');

// 跨项目调用
$db = D('other_project://user');

// 使用M函数获取模型实例（自动实例化模型类）
$userModel = M('user');

// 跨项目调用模型
$userModel = M('other_project://user');

// 框架推荐使用D函数创建数据库连接
// 如果需要使用特定配置，可以在D函数中传入配置参数
$db = D('user', ['type' => 'mysqli', 'host' => 'localhost', 'user' => 'root', 'pass' => 'password', 'dbname' => 'candy']);
```

### 3. 基本查询

```php
// 查询所有用户
$users = $db->select();

// 查询单个用户
$user = $db->find(1);

// 条件查询
$users = $db->where(['status' => 1])->order('id DESC')->select();
```

### 4. 插入数据

```php
// 插入单个用户
$userId = $db->insert(['name' => '张三', 'email' => 'zhangsan@example.com']);

// 批量插入
$users = [
    ['name' => '李四', 'email' => 'lisi@example.com'],
    ['name' => '王五', 'email' => 'wangwu@example.com']
];
$db->insertAll($users);
```

### 5. 更新数据

```php
// 更新用户信息
$db->where(['id' => 1])->update(['name' => '张三']);

// 字段自增
$db->where(['id' => 1])->setInc('points', 10);
```

### 6. 删除数据

```php
// 删除用户
$db->where(['id' => 1])->delete();

// 软删除
$db->where(['id' => 1])->delete(true);
```

## API参考

### 核心类

- **DBServer**：数据库操作基类，提供增删改查等基本功能
- **DBService**：数据库服务类，提供备份与还原功能
- **驱动类**：
  - **PdoMysql** / **Mysqli**：MySQL
  - **PdoPgsql** / **PdoSqlite**：PostgreSQL / SQLite
  - **ClickHouse**：HTTP 分析查询（只读）
  - 历史别名 **Pgsql** / **Sqlite** / **Pdo** 仍可用

### 全局函数

- **db($table = null, $config = null)**：获取数据库操作实例
- **dbService()**：获取数据库服务实例
- **dbCache()**：获取数据库缓存实例
- **D($tableName = '_dbDriver', $config = [])**：数据库操作入口函数，用于获取或创建数据库连接对象，支持跨项目调用
- **M($className, $config = [])**：模型实例化函数，用于获取模型类的实例，支持跨项目调用
