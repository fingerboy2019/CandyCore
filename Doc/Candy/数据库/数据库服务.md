# 数据库服务

## 概述

数据库服务模块（`Candy\Extend\DB\DBService`）提供了数据库备份与还原的功能，支持多种备份策略和还原方式。

## 主要功能

- 数据库表结构和数据备份
- 支持分卷备份
- 支持压缩备份
- 数据库还原
- 表优化和修复
- 表结构查看
- 表清空和删除

## 安装与配置

### 依赖扩展

- **zip 扩展**：用于压缩备份
- **pdo 扩展**：数据库连接
- **相应的数据库扩展**：根据使用的数据库类型

### 配置文件

```php
// 备份配置
'CANDY_DB_BACKUP' => [
    'path' => C('CANDYROOT') . 'Date/backup/', // 备份路径
    'size' => 52428800, // 分卷大小（默认50MB）
    'compress' => 1, // 压缩级别（0-9，0不压缩）
    'level' => 9, // 压缩级别
],
```

## 使用方法

### 初始化

```php
// 初始化数据库服务
use Candy\Extend\DB\DBService;

$dbService = new DBService();

// 或者使用全局函数
$dbService = dbService();
```

## 数据库备份

### 备份所有表

```php
// 备份所有表
$backup = $dbService->backup();

if ($backup) {
    echo "备份成功，文件路径：{$dbService->fileName}";
} else {
    echo "备份失败：{$dbService->error}";
}
```

### 备份指定表

```php
// 备份指定表
$tables = ['user', 'article', 'comment'];
$backup = $dbService->backup($tables);

if ($backup) {
    echo "备份成功，文件路径：{$dbService->fileName}";
} else {
    echo "备份失败：{$dbService->error}";
}
```

### 分卷备份

```php
// 分卷备份（默认分卷大小50MB）
$backup = $dbService->backup(null, 0, 52428800); // 50MB

if ($backup) {
    echo "分卷备份成功，文件路径：{$dbService->fileName}";
} else {
    echo "备份失败：{$dbService->error}";
}
```

### 压缩备份

```php
// 压缩备份
$backup = $dbService->backup(null, 1); // 启用压缩

if ($backup) {
    echo "压缩备份成功，文件路径：{$dbService->fileName}";
} else {
    echo "备份失败：{$dbService->error}";
}
```

### 分批备份大数据表

```php
// 分批备份大数据表（每1000条记录一批）
$tables = ['big_table'];
$backup = $dbService->backup($tables, 0, 0, 1000);

if ($backup) {
    echo "分批备份成功，文件路径：{$dbService->fileName}";
} else {
    echo "备份失败：{$dbService->error}";
}
```

## 数据库还原

### 还原备份文件

```php
// 还原备份文件
$file = 'backup_20231001.sql';
$restore = $dbService->import($file);

if ($restore) {
    echo "还原成功";
} else {
    echo "还原失败：{$dbService->error}";
}
```

### 还原分卷备份

```php
// 还原分卷备份（只需要指定第一个文件）
$file = 'backup_20231001_1.sql';
$restore = $dbService->import($file);

if ($restore) {
    echo "还原成功";
} else {
    echo "还原失败：{$dbService->error}";
}
```

## 常见问题

### 备份失败

**症状**：备份过程中报错

**解决方案**：
- 检查备份路径是否存在且可写
- 检查磁盘空间是否足够
- 检查权限设置
- 查看错误信息：`$dbService->error`

### 还原失败

**症状**：还原过程中报错

**解决方案**：
- 检查备份文件是否完整
- 检查数据库版本是否兼容
- 检查权限设置
- 查看错误信息：`$dbService->error`

### 分卷备份问题

**症状**：分卷备份无法还原

**解决方案**：
- 确保所有分卷文件存在
- 确保分卷顺序正确
- 使用第一个分卷文件进行还原

### 压缩备份问题

**症状**：压缩备份失败

**解决方案**：
- 确保安装了 zip 扩展
- 检查压缩级别设置是否合理
- 检查磁盘空间是否足够

## 最佳实践

1. **定期备份**：设置定时任务定期备份数据库
2. **多重备份**：本地备份和远程备份结合
3. **分卷备份**：大数据量使用分卷备份
4. **压缩备份**：减少备份文件大小
5. **备份验证**：定期验证备份文件的完整性
6. **权限控制**：限制备份文件的访问权限
7. **恢复测试**：定期测试还原流程

## 代码示例

### 完整备份脚本

```php
<?php
use Candy\Extend\DB\DBService;

// 初始化
$dbService = new DBService();

// 设置备份路径
$dbService->setPath(__DIR__ . '/backup/');

// 设置分卷大小（50MB）
$dbService->setSize(52428800);

// 设置压缩级别
$dbService->setLevel(9);

// 备份进度回调
$dbService->onProgress(function($total, $current, $file) {
    echo "\r备份进度：" . round($current / $total * 100, 2) . "%，当前文件：{$file}";
});

// 备份所有表
echo "开始备份数据库...\n";
$backup = $dbService->backup(null, 1);

if ($backup) {
    echo "\n备份成功！\n";
    echo "备份文件：{$dbService->fileName}\n";
    echo "备份大小：{$dbService->fileSize}\n";
} else {
    echo "\n备份失败：{$dbService->error}\n";
}
```

### 完整还原脚本

```php
<?php
use Candy\Extend\DB\DBService;

// 初始化
$dbService = new DBService();

// 还原进度回调
$dbService->onProgress(function($total, $current, $sql) {
    echo "\r还原进度：" . round($current / $total * 100, 2) . "%";
});

// 还原备份
echo "开始还原数据库...\n";
$restore = $dbService->import('backup_20231001.sql');

if ($restore) {
    echo "\n还原成功！\n";
} else {
    echo "\n还原失败：{$dbService->error}\n";
}
```
