## 环境要求

在使用 Candy 框架的数据库功能前，确保您的环境满足以下要求：

### PHP 扩展要求
- **PDO 扩展**：必须安装，所有数据库驱动都依赖 PDO
- **具体数据库扩展**：
  - MySQL/MariaDB：安装 `pdo_mysql` 扩展
  - PostgreSQL：安装 `pdo_pgsql` 扩展
  - SQLite：安装 `pdo_sqlite` 扩展

### 环境检查

在项目根目录执行以下命令检查扩展是否安装：

```bash
php -m | grep -E 'pdo|mysql|pgsql|sqlite'
```

## 配置文件

数据库配置信息位于项目的配置文件中，默认路径为 `Config/config.php`。

### 配置示例

```php
// 数据库配置
'CANDY_DB' => [
    'type'     => 'mysqli', // 数据库类型：mysqli, pdo, pgsql, sqlite
    'host'     => 'localhost', // 服务器地址
    'user'     => 'root', // 用户名
    'pass'     => 'password', // 密码
    'dbname'   => 'candy', // 数据库名
    'port'     => '3306', // 端口
    'TABPREFIX'=> 'cd_', // 表前缀
    'charset'  => 'utf8mb4', // 数据库编码
    'timeout'  => 30, // 数据库连接超时时间
],

// Redis 缓存配置（可选，用于数据库缓存）
'CANDY_REDIS' => [
    'host'     => '127.0.0.1',
    'port'     => '6379',
    'pass'     => '',
    'select'   => 0,
    'timeout'  => 0,
    'expire'   => 3600,
    'persistent'=> false,
    'prefix'   => 'candy_',
],
```

## 配置说明

| 配置项 | 说明 | 可选值 | 默认值 |
|--------|------|--------|--------|
| type | 数据库驱动类型 | mysqli, pdo, pgsql, sqlite | mysqli |
| host | 数据库服务器地址 | 域名或IP | localhost |
| user | 数据库用户名 | - | root |
| pass | 数据库密码 | - | - |
| dbname | 数据库名称 | - | candy |
| port | 数据库端口 | - | 3306 |
| TABPREFIX | 表前缀 | - | cd_ |
| charset | 数据库字符集 | - | utf8mb4 |
| timeout | 连接超时时间（秒） | - | 30 |

## 初始化数据库连接

在框架启动时，数据库连接会自动初始化。您也可以手动创建数据库连接：

```php
// 方法一：使用全局函数
$db = db(); // 默认配置
$db = db('other_db'); // 使用其他配置

// 方法二：使用D函数创建数据库连接（框架推荐）
$db = D('user', [
    'type'     => 'mysqli',
    'host'     => 'localhost',
    'user'     => 'root',
    'pass'     => 'password',
    'dbname'   => 'candy',
    'TABPREFIX'=> 'cd_',
]);

// 方法三：使用M函数创建模型连接
$userModel = M('user', [
    'type'     => 'mysqli',
    'host'     => 'localhost',
    'user'     => 'root',
    'pass'     => 'password',
    'dbname'   => 'candy',
    'TABPREFIX'=> 'cd_',
]);

// 注意：框架要求所有数据库连接必须通过D函数或M函数创建，不支持直接实例化驱动类
```

## 配置多数据库

框架支持配置和使用多个数据库：

```php
// 配置文件中定义多个数据库
'CANDY_DB' => [
    'default' => [
        // 默认数据库配置
    ],
    'other' => [
        // 第二个数据库配置
    ],
],

// 使用指定数据库
$db = db('default'); // 使用默认数据库
$db = db('other'); // 使用第二个数据库
```

## 常见问题

### 1. 连接失败

**症状**：无法连接到数据库服务器

**解决方案**：
- 检查数据库服务是否运行
- 验证用户名和密码是否正确
- 检查服务器地址和端口是否正确
- 确保防火墙允许数据库连接

### 2. 扩展缺失

**症状**：提示 "请开启PDO扩展" 或特定数据库扩展缺失

**解决方案**：
- 安装缺失的PHP扩展
- 修改php.ini文件启用扩展
- 重启Web服务器或PHP-FPM

### 3. 字符集问题

**症状**：中文显示乱码

**解决方案**：
- 确保数据库字符集配置为 utf8mb4
- 检查数据表和字段的字符集设置
- 确保应用程序输出使用正确的字符编码
