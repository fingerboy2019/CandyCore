# where条件说明

## 一、一维关联数组（AND 模式）

**适用场景**：多个字段等值查询，条件之间用 `AND` 连接

```php
// 传参
['name' => 'anna', 'age' => 18, 'status' => 1]

// 生成SQL
`name` = ? AND `age` = ? AND `status` = ?
// 绑定数据: ['anna', 18, 1]
```

**代码位置**：1537-1546 行

---

## 二、一维单元素数组（主键模式）

**适用场景**：通过主键直接查询

```php
// 传参
[5]

// 生成SQL
`pri_key` = ?
// 绑定数据: [5]
```

**特殊情况**：
- `['']`, `[false]`, `[0]` → 返回空条件（跳过）
- `['\0']` → 转换为 `[0]`

**代码位置**：1550-1554 行

## 三、一维双元素数组

### 3.1 带操作符的键名

```php

// 生成SQL

// 绑定数据: ['anna']
```

支持的操作符位置：键名中包含空格即可，如 `'name <>'`, `'age >='`

**代码位置**：1557-1563 行

### 3.2 简单等值查询

```php

['name', 'anna']

// 生成SQL

// 绑定数据: ['anna']
```

**代码位置**：1564-1570 行

## 四、一维三元素数组（完整条件）

**格式**：`[字段名, 操作符, 值]`

| 操作符 | 示例 | 生成SQL | 绑定数据 |
|--------|------|---------|----------|
| `=` | `['age', '=', 18]` | `` `age` = ? `` | `[18]` |
| `<>` | `['age', '<>', 18]` | `` `age` <> ? `` | `[18]` |
| `>` | `['age', '>', 18]` | `` `age` > ? `` | `[18]` |
| `>=` | `['age', '>=', 18]` | `` `age` >= ? `` | `[18]` |
| `<` | `['age', '<', 18]` | `` `age` < ? `` | `[18]` |
| `<=` | `['age', '<=', 18]` | `` `age` <= ? `` | `[18]` |
| `LIKE` | `['name', 'LIKE', '%anna%']` | `` `name` LIKE ? `` | `['%anna%']` |
| `NOT LIKE` | `['name', 'NOT LIKE', '%anna%']` | `` `name` NOT LIKE ? `` | `['%anna%']` |
| `BETWEEN` | `['age', 'BETWEEN', '18,30']` | `` `age` BETWEEN ? AND ? `` | `['18', '30']` |
| `NOT BETWEEN` | `['age', 'NOT BETWEEN', '18,30']` | `` `age` NOT BETWEEN ? AND ? `` | `['18', '30']` |
| `IN` | `['id', 'IN', '1,2,3']` | `` `id` IN (?, ?, ?) `` | `['1', '2', '3']` |
| `NOT IN` | `['id', 'NOT IN', '1,2,3']` | `` `id` NOT IN (?, ?, ?) `` | `['1', '2', '3']` |
| `EXP` | `['score', 'EXP', '> 100']` | `` `score` > 100 `` | `[]` |

### ThinkPHP 操作符别名（兼容）

以下别名在关联数组 / 三元素 / 键名后缀三种写法下均可用，内部会归一化为上表标准操作符：

| 别名 | 等价 |
|------|------|
| `eq` | `=` |
| `neq` | `<>` |
| `gt` | `>` |
| `egt` | `>=` |
| `lt` | `<` |
| `elt` | `<=` |
| `notlike` | `NOT LIKE` |
| `notin` | `NOT IN` |
| `notbetween` | `NOT BETWEEN` |

```php
->where(['status' => ['eq', 1]])
->where(['age' => ['egt', 18]])
->where(['age', 'lt', 60])
->where(['score egt' => 100])
```

**注意**：
- `BETWEEN`/`IN` 的值支持字符串逗号分隔，会自动 `explode`
- `LIKE` 会自动 `addslashes`
- `EXP` 模式的值会直接拼接到 SQL 中（无参数绑定）

**代码位置**：`Candy/Class/DB/Trait/WhereParser.class.php`

## 五、多维数组 - 数字索引（OR 模式）

### 5.1 嵌套条件组

```php
// 传参
[
    ['name', '=', 'anna'],
    ['age', '>', 18]
]

// 生成SQL
(`name` = ?) OR (`age` > ?)
// 绑定数据: ['anna', 18]
```

**代码位置**：1599-1605 行

### 5.2 主键列表

```php
// 传参
[1, 2, 3]

// 生成SQL
`pri_key` = ? OR `pri_key` = ? OR `pri_key` = ?
// 绑定数据: [1, 2, 3]
```

**代码位置**：1612-1617 行

### 5.3 主键 IN 字符串

```php
// 传参
['1,2,3']

// 生成SQL
`pri_key` IN (?, ?, ?)
// 绑定数据: ['1', '2', '3']
```

**代码位置**：1618-1622 行

### 5.4 直接 SQL 语句

```php
// 传参
['status = 1 AND deleted_at IS NULL']

// 生成SQL
status = 1 AND deleted_at IS NULL
// 绑定数据: []
```

**代码位置**：1624-1626 行

## 八、特殊值处理

| 特殊值 | 处理方式 |
|--------|----------|
| `'\0'` | 转换为 `0` |
| `''`, `false`, `0`（单元素） | 返回空条件 |
| 值包含 `,` | 自动 `explode` 为数组（用于 IN/BETWEEN） |

## 九、行为与业务对齐（注意）

### 9.1 勿混用关联键与数字下标（推荐写法）

下列混写在主线已支持 AND 合并，但**仍推荐**用关联键或链式三参数，避免与旧文档/旧项目习惯混淆：

```php
// 不推荐（历史上易出错，现已兼容）
$where = ['status' => 1];
$where[] = ['id', '<>', 1];

// 推荐
['status' => 1, 'id' => ['<>', 1]]
// 或
->where('id', '<>', 1)
```

解析实现：`Candy\Extend\DB\Trait\WhereParser::parseWhereArrayCondition()`。

### 9.2 软删除与 `is_deleted`

框架仅识别 `$deleteTime`（默认 `delete_time`）且用 `` = null `` 判断未删；**`is_deleted` 0/1 需业务手写条件**，见 [详细使用指南 §10.2](详细使用指南.md#102-软删除)。

---

## 优先级总结

1. **一维关联数组** → AND 模式
2. **一维单元素** → 主键模式
3. **一维双元素** → 等值/NULL/操作符模式
4. **一维三元素** → 完整条件模式
5. **多维数字索引** → OR 模式
6. **多维关联数组** → AND 模式 + IN/等值/LIKE
