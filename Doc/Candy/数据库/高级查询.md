## 连接查询

### 内连接 (INNER JOIN)

```php
// 基本内连接
$users = D('user')
    ->join('article', 'user.id = article.user_id')
    ->select(['user.*', 'article.title']);

// 带条件的内连接
$users = D('user')
    ->join('article', 'user.id = article.user_id')
    ->where(['user.status' => 1])
    ->select(['user.*', 'article.title']);

// 别名连接
$users = D('user')
    ->join('article as a', 'user.id = a.user_id')
    ->select(['user.*', 'a.title']);
```

### 左连接 (LEFT JOIN)

```php
// 基本左连接
$users = D('user')
    ->leftJoin('article', 'user.id = article.user_id')
    ->select(['user.*', 'article.title']);

// 带条件的左连接
$users = D('user')
    ->leftJoin('article', 'user.id = article.user_id')
    ->where(['user.status' => 1])
    ->select(['user.*', 'article.title']);
```

### 右连接 (RIGHT JOIN)

```php
// 基本右连接
$articles = D('article')
    ->rightJoin('user', 'article.user_id = user.id')
    ->select(['article.*', 'user.name']);

// 带条件的右连接
$articles = D('article')
    ->rightJoin('user', 'article.user_id = user.id')
    ->where(['article.status' => 1])
    ->select(['article.*', 'user.name']);
```

### 多表连接

```php
// 三表连接
$orders = D('order')
    ->join('user', 'order.user_id = user.id')
    ->join('product', 'order.product_id = product.id')
    ->select(['order.*', 'user.name', 'product.title']);

// 混合连接
$orders = D('order')
    ->join('user', 'order.user_id = user.id')
    ->leftJoin('product', 'order.product_id = product.id')
    ->select(['order.*', 'user.name', 'product.title']);
```

## 子查询

### 子查询作为条件

```php
// 查询有文章的用户
$users = D('user')
    ->where(['id' => ['in', function($query) {
        $query->select('user_id')->from('article');
    }]])
    ->select();

// 查询文章数大于5的用户
$users = D('user')
    ->where(['id' => ['in', function($query) {
        $query->select('user_id')->from('article')->group(['user_id'])->having(['count(*) > 5']);
    }]])
    ->select();
```

### 子查询作为表

```php
// 子查询作为表
$users = D()->query(
    'SELECT * FROM (SELECT id, name FROM cd_user WHERE status = 1) as u WHERE u.id > 10'
);

// 使用连贯操作实现子查询
$users = D('user')
    ->field(['id', 'name'])
    ->where(['status' => 1])
    ->buildSubQuery()
    ->where(['id > 10'])
    ->select();
```

### 关联查询

```php
// 查询用户及其所有文章
$user = D('user')->r_select(['article'], 1);

// 查询用户及其所有文章和评论
$user = D('user')->r_select(['article', 'comment'], 1);

// 带条件的关联查询
$user = D('user')->r_select(['article' => ['where' => ['status' => 1]]], 1);
```

## 事务处理

### 基本事务

```php
// 开始事务
$db->beginTransaction();

try {
    // 执行操作
    d('user')->insert(['name' => '张三']);
    $db->article->insert(['title' => '文章标题', 'user_id' => $db->lastInsertId()]);
    
    // 提交事务
    $db->commit();
    
    echo "事务执行成功";
} catch (Exception $e) {
    // 回滚事务
    $db->rollBack();
    
    echo "事务执行失败：" . $e->getMessage();
}
```

### 自动事务

```php
// 使用闭包自动处理事务
$success = $db->transaction(function() use ($db) {
    d('user')->insert(['name' => '张三']);
    $db->article->insert(['title' => '文章标题', 'user_id' => $db->lastInsertId()]);
    
    // 如果需要回滚，抛出异常
    // throw new Exception('需要回滚');
    
    return true;
});

if ($success) {
    echo "事务执行成功";
} else {
    echo "事务执行失败";
}
```

### 事务嵌套

```php
// 开始外层事务
$db->beginTransaction();

try {
    d('user')->insert(['name' => '张三']);
    
    // 开始内层事务
    $db->beginTransaction();
    
    try {
        $db->article->insert(['title' => '文章标题', 'user_id' => $db->lastInsertId()]);
        $db->commit(); // 提交内层事务
    } catch (Exception $e) {
        $db->rollBack(); // 回滚内层事务
        throw $e; // 继续抛出异常
    }
    
    $db->commit(); // 提交外层事务
    
    echo "事务执行成功";
} catch (Exception $e) {
    $db->rollBack(); // 回滚外层事务
    
    echo "事务执行失败：" . $e->getMessage();
}
```

## 数据缓存

### 查询缓存

```php
// 缓存查询结果
$users = D('user')
    ->where(['status' => 1])
    ->cache(3600) // 缓存1小时
    ->select();

// 带缓存键的查询
$users = D('user')
    ->where(['status' => 1])
    ->cache(3600, 'user_list_cache') // 指定缓存键
    ->select();

// 删除缓存
$db->delDataCache('user_list_cache');
```

### 缓存配置

```php
// 设置缓存过期时间
$db->cacheTime(3600); // 默认1小时

// 设置缓存驱动
$db->cacheDriver('redis'); // redis 或 file

// 关闭缓存
$db->cache(false);
```

## 高级条件构造

### 区间条件

```php
// BETWEEN 条件
$users = D('user')->where(['age' => ['between', [18, 30]]])->select();

// NOT BETWEEN 条件
$users = D('user')->where(['age' => ['not between', [18, 30]]])->select();
```

### IN 条件

```php
// IN 条件
$users = D('user')->where(['id' => ['in', [1, 2, 3]]])->select();

// NOT IN 条件
$users = D('user')->where(['id' => ['not in', [1, 2, 3]]])->select();
```

### LIKE 条件

```php
// LIKE 条件
$users = D('user')->where(['name' => ['like', '%张%']])->select();

// NOT LIKE 条件
$users = D('user')->where(['name' => ['not like', '%张%']])->select();

// 多个 LIKE 条件
$users = D('user')->where([
    'name' => ['like', '%张%'],
    'email' => ['like', '%@example.com']
])->select();
```

### NULL 条件

```php
// IS NULL 条件
$users = D('user')->where(['email' => ['is null']])->select();

// IS NOT NULL 条件
$users = D('user')->where(['email' => ['is not null']])->select();
```

### 组合条件

```php
// AND 条件
$users = D('user')->where([
    'status' => 1,
    'age' => ['>', 18]
])->select();

// OR 条件
$users = D('user')->where([
    'status' => 1,
    'OR' => [
        'age' => ['>', 18],
        'name' => ['like', '%张%']
    ]
])->select();

// 复杂条件
$users = D('user')->where([
    'status' => 1,
    'AND' => [
        'age' => ['>', 18],
        'OR' => [
            'name' => ['like', '%张%'],
            'email' => ['like', '%@example.com']
        ]
    ]
])->select();
```

## 高级统计

### 分组统计

```php
// 分组统计
$stats = D('order')
    ->group(['user_id'])
    ->select([
        'user_id',
        'count(*) as order_count',
        'sum(amount) as total_amount',
        'avg(amount) as avg_amount'
    ]);
```

### 交叉表查询

```php
// 交叉表查询
$stats = D()->query(
    'SELECT 
        user_id,
        SUM(CASE WHEN status = 1 THEN 1 ELSE 0 END) as completed,
        SUM(CASE WHEN status = 0 THEN 1 ELSE 0 END) as pending,
        SUM(CASE WHEN status = -1 THEN 1 ELSE 0 END) as canceled
    FROM cd_order 
    GROUP BY user_id'
);
```

## 最佳实践

1. **避免笛卡尔积**：确保连接条件正确，避免产生大量冗余数据
2. **索引优化**：连接字段和查询条件字段添加索引
3. **合理使用连接类型**：根据业务需求选择合适的连接类型
4. **事务粒度**：事务尽量小，避免长时间占用数据库资源
5. **缓存策略**：频繁查询的数据使用缓存
6. **子查询优化**：复杂子查询考虑使用连接查询替代
7. **批量操作**：大量数据操作使用批量处理
8. **避免全表扫描**：查询条件尽量使用索引字段
