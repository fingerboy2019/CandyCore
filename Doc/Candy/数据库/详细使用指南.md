## 1. 架构与分层

Candy 数据库能力位于 `Candy/Class/DB/`，应用通过全局函数访问，**禁止在 Control / View 中直接写 SQL**。

```
HTTP 请求
  → Control（C）  接收参数、鉴权
  → Service（S）  跨表编排（可选）
  → Model（M）    单表 CRUD、列表查询
  → DBServer      链式 SQL 构建 + 驱动
  → Driver        PdoMysql / Mysqli / PdoPgsql / …
```

| 场景 | 推荐入口 | 说明 |
|------|----------|------|
| 后台列表、单表 CRUD | `M('Article')` | Model 编译后继承 `BaseModel`，业务方法写在 `Models/` |
| 临时查表、无 Model 类 | `D('User')` | 直接操作表，表名自动 snake_case |
| 仅要连接/执行 SQL | `D('_dbDriver')` | 不绑定表名 |
| 跨 Model 业务编排 | `S('Order')` 内调 `M()` | Service **无对应表**，不写 SQL |
| 备份、优化表结构 | `DBService` | 见 [数据库服务](数据库服务.md) |

**核心类：**

| 类 | 路径 | 作用 |
|----|------|------|
| `DBServer` | `Candy/Class/DB/DBServer.class.php` | 查询构建、ORM 链式 API 抽象基类 |
| `BaseModel` | `Candy/Class/DB/BaseModel.class.php` | Model 组合连接，代理链式方法 |
| `DriverInterface` | `Candy/Class/DB/DriverInterface.class.php` | 驱动契约 |
| `DbMetrics` | `Candy/Class/DB/DbMetrics.class.php` | 查询/连接指标 |
| `DbAsync` | `Candy/Class/DB/DbAsync.class.php` | 异步只读队列 |

## 2. 环境与配置

### 2.1 PHP 扩展

| 驱动 | 扩展 |
|------|------|
| `pdomysql`（推荐） | `pdo_mysql` |
| `mysqli` | `mysqli` |
| `pdopgsql` | `pdo_pgsql` |
| `pdosqlite` | `pdo_sqlite` |

检查命令：

```bash
php -m | grep -E 'pdo|mysql|pgsql|sqlite'
```

### 2.2 主配置 `Source/Inc/Config.inc.php`

```php
return [
    'CHARSET' => 'utf8mb4',

    // 默认驱动（全局 G('DRIVER')）
    'DRIVER'  => 'pdomysql',

    // 多库 = 库隔离；别名下可再配 write/read
    'DB' => [
        'default' => [
            'HOST'      => 'localhost',
            'USER'      => 'app',
            'PASS'      => 'secret',
            'DBNAME'    => 'app_main',
            'TABPREFIX' => 'sa_',
            'PORT'      => 3306,       // 可选
            'TIMEOUT'   => 30,         // 可选，秒
        ],
        // 其他隔离库示例
        'tenant_a' => [
            'HOST'      => 'localhost',
            'USER'      => 'tenant_a',
            'PASS'      => '...',
            'DBNAME'    => 'app_tenant_a',
            'TABPREFIX' => 'ta_',
        ],
    ],
];
```

**配置项说明：**

| 键 | 必填 | 说明 |
|----|------|------|
| `HOST` | 是* | 主机；SQLite 可用 `PATH` 或 `DSN` 代替 |
| `USER` / `PASS` | 是* | 账号密码 |
| `DBNAME` | 是* | 库名 |
| `TABPREFIX` | 否 | 表前缀，如 `sa_` |
| `CHARSET` | 否 | 默认继承全局 `CHARSET` |
| `PORT` | 否 | 默认 3306（MySQL） |
| `TIMEOUT` | 否 | 连接超时（秒） |

\* SQLite：`PATH` 指向 `.db` 文件，或完整 `DSN`。

### 2.3 扩展配置 `Source/Inc/Db.inc.php`

通过 `loadConfig('Db')` 加载，与连接治理、异步读相关：

```php
return [
    'DB_SLOW_MS'         => 500,   // 慢查询阈值（毫秒）
    'DB_MAX_CONNECTIONS' => 32,    // 每 Worker 最大连接数
    'async_read'         => false, // 是否启用 useAsyncRead 异步入队
];
```

## 3. 入口函数 D / M

定义于 `Candy/Func/di.func.php`。

### 3.1 `D()` — 表级数据库对象

```php
// 默认库 + 自动表名 user
$db = D('User');

// 库隔离别名
$db = D('User', 'tenant_a');

// 强制读库（第三参数或紧凑写法）
$db = D('User', 'default', 'read');
$db = D('User', 'default@write');

// 临时配置数组（CRC32 池键，不污染全局 C()）
$db = D('User', [
    'HOST' => '10.0.0.9',
    'USER' => 'ro',
    'PASS' => '...',
    'DBNAME' => 'report',
    'TABPREFIX' => 'rpt_',
]);

// 跨应用
$db = D('Admin://Log', 'default');

// 仅驱动，不绑表
$driver = D('_dbDriver');
echo $driver->dbVersion();
```

**参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| `$tableName` | string | 表名；`_dbDriver` 表示只要驱动 |
| `$config` | string\|array | 隔离别名或完整连接数组 |
| `$role` | `write`\|`read`\|null | 强制角色；null 为自动路由 |

### 3.2 `M()` — Model 实例

```php
$user = M('User');
$list = M('Article', 'tenant_a', 'read')->where(['status' => 1])->select();

// 跨应用
$log = M('Admin://Log');
```

Model 类位于 `Application/{App}/Models/{Name}.class.php`，运行时编译为 `{Name}Model extends BaseModel`。

### 3.3 容器与连接复用

相同 **表名 + 应用 + 配置键 + 角色** 复用同一实例；不同隔离库或角色会创建独立实例。配置数组用 **CRC32** 生成池键，避免与全局配置冲突。

## 4. 链式查询 API

### 4.1 链式方法（可连续调用）

| 方法 | 说明 | 示例 |
|------|------|------|
| `field()` | 查询字段 | `->field(['id', 'title'])` |
| `where()` | AND 条件 | `->where(['status' => 1])` |
| `orWhere()` | OR 条件 | `->orWhere(['id' => 5])` |
| `order()` | 排序 | `->order(['id' => 'DESC'])` |
| `limit()` | 条数限制 | `->limit(10)` 或 `->limit(0, 20)` |
| `group()` | 分组 | `->group(['category'])` |
| `having()` | 分组条件 | `->having(['cnt > 1'])` |
| `join()` | 左连接 | 见下文 |
| `data()` | 待写入数据 | `->data([...])->insert()` |
| `cache()` | 查询缓存开关 | `->cache(false)` 关闭 |

**角色控制（BaseModel / DBServer）：**

```php
M('User')->useRead()->select();      // 强制读库
M('User')->useWrite()->find(1);      // 强制写库（读后写场景）
M('User')->useAuto();                // 恢复自动路由
M('User')->useAsyncRead()->select(); // 异步入队只读（需 Db.async_read）
```

### 4.2 终结方法（执行 SQL）

| 方法 | 返回 | 说明 |
|------|------|------|
| `select()` | `array` | 多条记录 |
| `find($id?)` | `?array` | 单条；可传主键或仅靠 where |
| `total()` | `int` | 计数 |
| `total($offset, $limit)` | `['total'=>int,'list'=>array]` | **分页列表推荐** |
| `insert()` / `add()` | `int\|false` | 插入，返回自增 ID |
| `update()` | `int\|false` | 更新行数 |
| `save()` | `int\|false` | 有主键则更新，否则插入 |
| `delete()` | `int` | 删除 |
| `setInc()` / `setDec()` | mixed | 字段自增/自减 |

查询结束后框架**自动重置** where / order / limit 等状态（`total` 带分页参数时内部会保留条件再查 list）。

### 4.3 关联查询 `join()`

```php
// 格式：join([表名, 字段列表, 外键字段])
// 主表 user，关联 profile：user.id = profile.user_id
$rows = D('User')
    ->join(['profile', ['nickname', 'avatar'], 'user_id'])
    ->field(['id', 'name'])
    ->where(['status' => 1])
    ->select();

// 表别名：[[表名, 别名], 字段, 外键]
$rows = D('Order')
    ->join([['user', 'u'], ['name'], 'user_id'])
    ->select();
```

复杂多表关联可使用 `r_select()`（见 [高级查询](高级查询.md)）。

### 4.4 后台分页标准写法

与 Admin Layui 列表对齐（详见 `raw/doc/ListPaginationConvention.md`）：

```php
// Model 内
public function getList(array $params = []): array
{
    $page  = max(1, (int)($params['page'] ?? 1));
    $limit = max(1, (int)($params['limit'] ?? list_page_size()));
    $offset = ($page - 1) * $limit;

    $this->resetQueryState();
    $this->applyListFilters($params);

    $result = $this->cache(false)
        ->order($this->buildListOrder($params))
        ->total($offset, $limit);

    return [
        'code'    => 0,
        'message' => '',
        'count'   => (int)($result['total'] ?? 0),
        'data'    => $result['list'] ?? [],
    ];
}
```

## 5. 增删改查

### 5.1 查询

```php
// 全表（慎用）
$all = D('User')->select();

// 条件 + 排序 + 限制
$users = D('User')
    ->where(['status' => 1])
    ->order(['id' => 'DESC'])
    ->limit(20)
    ->select();

// 按主键
$user = D('User')->find(5);
$user = D('User')->where(['email' => 'a@b.com'])->find();

// 计数
$count = D('User')->where(['status' => 1])->total();
```

### 5.2 插入

```php
$id = D('User')->insert([
    'name'       => '张三',
    'email'      => 'zhang@example.com',
    'createtime' => time(),
]);

// 链式 data
$id = D('User')->data(['name' => '李四'])->add();
```

`insert` / `add` 等价；`$filter=1` 时会过滤非法字段，`$validate=1` 时走 `Validate` 规则。

### 5.3 更新

```php
// 按条件更新
$n = D('User')->where(['id' => 1])->update(['name' => '新名']);

// save：有主键更新，无主键插入
D('User')->save(['id' => 1, 'name' => '新名']);

// 自增 / 自减
D('Article')->where(['id' => 10])->setInc('views');
D('Product')->where(['id' => 3])->setDec('stock', 2);
```

### 5.4 删除

```php
$n = D('User')->where(['id' => 99])->delete();
```

若表含 `deleteTime` 字段且未 `withTrashed()`，框架按软删除规则处理（见 §10）。

## 6. Where 条件

`where()` 支持多种数组形态，完整规则见 [Where条件说明](Where条件说明.md)。

### 6.1 常用写法

```php
// 关联数组（AND 等值）
->where(['status' => 1, 'type' => 'admin'])

// 主键简写
->find(5)          // 等价 where 主键 = 5
->where([10])      // 同上

// 运算符（值用二元数组）
->where(['age' => ['>', 18]])
->where(['name' => ['like', '%张%']])
->where(['id' => ['in', [1, 2, 3]]])
->where(['email' => ['is null']])

// 键名带运算符
->where(['status <>' => 0])

// 多段 AND / OR
->where(['a' => 1])->orWhere(['b' => 2])
```

### 6.2 复杂条件

```php
->where([
    ['logic' => 'AND', 'args' => [['status', 1], ['type', 'vip']]],
    ['logic' => 'OR',  'args' => [['level', ['>=', 5]], ['score', ['>', 1000]]]],
])
```

### 6.3 行为与业务对齐

**软删除字段**

- 框架默认软删字段为 **`delete_time`**（可在模型/驱动上改 `$deleteTime`），且表结构探测到该字段存在时，查询自动附加 `` `delete_time` = null ``（`onlyTrashed` 为 `` <> null ``）。
- 业务表若使用 **`is_deleted`（0/1）** 等布尔标记，框架**不会**自动处理；需手写 `where(['is_deleted' => 0])`，`delete()` 也不会自动写 `is_deleted = 1`。

**Where 数组混写**

- `WhereParser` 对「关联数组 + `$where[] = …` 数字下标混入」历史上易解析错误；**推荐**使用 `'id' => ['<>', n]` 或链式三参数 `->where('id', '<>', n)`。
- 自主线起，混写形态 `['status' => 1, ['id', '<>', 1]]` 已按 AND 合并解析；仍建议新代码用推荐写法，可读性更好。

```php
// 推荐
->where(['status' => 1, 'id' => ['<>', 1]])
->where('id', '<>', 1)

// 可用（混写，AND 合并）
$where = ['status' => 1];
$where[] = ['id', '<>', 1];
->where($where)
```

## 7. 多库隔离与读写分库

**两个正交维度：**

1. **库隔离**：`DB` 下不同别名 = 不同数据空间（租户、业务域）。
2. **读写分库**：同一别名内 `write` / `read`（主从），自动或手动选节点。

### 7.1 库隔离

```php
$main   = D('User')->select();              // default
$tenant = D('User', 'tenant_a')->select(); // 租户库
$shop   = D('Order', 'shop')->select();    // 商城库
```

### 7.2 读写分库配置

```php
'DB' => [
    'default' => [
        'write' => [
            'HOST' => '10.0.0.1',
            'USER' => 'app',
            'PASS' => '...',
            'DBNAME' => 'app_main',
            'TABPREFIX' => 'sa_',
        ],
        'read' => [
            [
                'HOST' => '10.0.0.2',
                'USER' => 'app_ro',
                'PASS' => '...',
                'DBNAME' => 'app_main',
                'TABPREFIX' => 'sa_',
            ],
        ],
    ],
],
```

| 配置形态 | 行为 |
|----------|------|
| 含 `HOST` 的扁平配置 | 读写同一连接 |
| 含 `write` / `read`（或 `master` / `slave`） | 按角色拆连接 |
| 仅 `write` 无 `read` | 读操作回退到 write |

### 7.3 自动路由规则

| 操作 | 默认节点 |
|------|----------|
| `select` / `find` / `total` | `read` |
| `insert` / `update` / `delete` / 其他写 | `write` |
| 事务进行中 | 全程 `write` |

### 7.4 强制角色

```php
D('User', 'default', 'read');
D('User', 'default@write');
M('User')->useRead()->select();
M('User')->useWrite()->find(1);
```

> 完整说明：[多数据库切换功能说明](../框架使用/多数据库切换功能说明.md)

**注意：** 各库事务独立，**不能跨库同一事务**。

## 8. MVCS 中的 Model 用法

### 8.1 目录与编译

```
Application/Admin/Models/Article.class.php   # 源码
Runtime/Models/Admin/ArticleModel.php        # 编译后 extends BaseModel
```

`M('Article')` → `APP\Model\Admin\ArticleModel`。

### 8.2 Model 模板

```php
<?php
/***
 * 用户数据层
 *
 * 对应表：sa_user
 * 业务逻辑见：APP\Service\Admin\User
 *
 * $Author: ...
 * $Date: 2026-07-17 10:40:00 $
 *
 * @package APP\Model\Admin
 */
namespace APP\Model\Admin;

defined('CANDY') OR die('You Are A Bad Guy. o_O???');

class User {

    protected $table = 'sa_user';
    protected $pk = 'id';

    public function getById(int $id): ?array
    {
        $this->resetQueryState();
        return $this->find($id) ?: null;
    }
}
```

### 8.3 常驻进程注意 `resetQueryState()`

Workerman / 计划任务中 Model 实例会跨请求复用，**写操作前**应重置链式状态，防止 where 残留：

```php
$this->resetQueryState();
$this->where(['id' => $id])->update($data);
```

参照：`Application/Admin/Models/Article.class.php`。

### 8.4 Control 调用示例

```php
// Controls/User.class.php
function list() {
    $result = M('User')->getList(I('get.'));
    $this->assign([
        'code'    => $result['code'],
        'count'   => $result['count'],
        'message' => $result['message'] ?? '',
        'data'    => $result['data'],
    ]);
    $this->display();
}
```

## 9. 事务

```php
$db = D('Order');

try {
    $db->beginTransaction();

    D('Order')->insert(['user_id' => 1, 'amount' => 100]);
    D('Account')->where(['user_id' => 1])->setDec('balance', 100);

    $db->commit();
} catch (\Throwable $e) {
    $db->rollBack();
    throw $e;
}
```

- 方法：`beginTransaction()`、`commit()`、`rollBack()`
- 事务期间自动锁定 **write** 节点
- 多库场景对每个库分别开启事务

## 10. 查询缓存与软删除

### 10.1 查询缓存

```php
// 默认可能缓存 select/find/total 结果（取决于表配置）
$rows = D('Config')->cache(true)->where(['key' => 'site_name'])->find();

// 列表建议关闭，避免脏读
$rows = M('Article')->cache(false)->total($offset, $limit);
```

写操作（insert/update/delete）会清理对应表缓存。

**隔离库键规则**（`DB` Trait\Cache）：

| 项 | 说明 |
|----|------|
| 键格式 | `dbqc:{alias}:{dbname}_{tab}:v{ver}:{md5}` |
| `alias` | 库隔离别名（`getDbAlias()`），**不含** write/read，主从共享 |
| 失效 | 写库后递增 `:ver`，旧版本键自然失效（Redis/Memcached 均可用，无需前缀扫描） |
| 进程内回退 | `File` 驱动时按 `alias → dbname → tab` 分组存放 |

不同隔离别名即使 `DBNAME` 相同也不会互相命中。

### 10.2 软删除

默认软删字段名为 **`delete_time`**（属性 `$deleteTime`），且字段须在表结构 `fieldList` 中；条件使用 `` = null `` / `` <> null ``（非 `IS NULL` 写法）。

表含该字段时：

```php
D('User')->where(['id' => 1])->delete();           // 软删（写 delete_time）
D('User')->withTrashed()->select();                 // 含已删
D('User')->onlyTrashed()->select();                 // 仅已删
```

**`is_deleted`（0/1）等业务标记不在默认软删范围内**：不会自动附加 where，也不会在 `delete()` 时自动置 1，需业务自行 `where` + `update`。

## 11. 原生 SQL 与调试

### 11.1 执行原生 SQL

```php
$driver = D('_dbDriver');
$rows = $driver->query('SELECT * FROM sa_user WHERE status = ?', 'select', [1]);

// 绑定表后
D('User')->query('SELECT COUNT(*) AS c FROM `sa_user`', 'other', []);
```

`$method` 影响读写路由：`select` / `find` / `total` 走读库，其余走写库。

### 11.2 调试信息

调试模式（`DEBUG = 1`）下，SQL 与耗时写入 `Debug` 消息栈。慢查询超过 `DB_SLOW_MS` 写入 `Runtime/Logs/sql-slow.log`。

```php
$state = M('User')->getSqlState();  // 查看当前链式状态
$msg   = M('User')->getMsg();       // 最近一次错误信息
```

## 12. 驱动与扩展配置

### 12.1 驱动一览

| `DRIVER` | 实现类 | 场景 |
|----------|--------|------|
| `pdomysql` | `PdoMysql` | MySQL / MariaDB（**推荐**） |
| `mysqli` / `mysql` | `Mysqli` | 原生 mysqli |
| `pdopgsql` / `pgsql` | `PdoPgsql` | PostgreSQL |
| `pdosqlite` / `sqlite` | `PdoSqlite` | SQLite |
| `pdosqlsrv` / `sqlsrv` | `PdoSqlsrv` | SQL Server（pdo_sqlsrv） |
| `clickhouse` | `ClickHouse` | HTTP 分析查询（只读） |

别名 `pdo` → `PdoMysql`；旧类 `Pgsql` / `Sqlite` 为兼容薄包装。

解析入口：`DBServer::resolveDriverClass($name)`。

### 12.2 SQLite 配置示例

```php
    'PATH' => '/data/app/storage/local.db',
    // 或 'DSN' => 'sqlite:/data/app/storage/local.db',
],
```

## 14. 异步只读与 ClickHouse

### 14.1 异步只读

适用：可接受最终一致性的统计类 `select` / `find` / `total`。

```php
// Source/Inc/Db.inc.php
'async_read' => true,
```

```php
D('Log')->useAsyncRead()->where(['type' => 'login'])->select();
// 入队后立即返回空结果/0/null，由 Worker 异步执行
```

消费 Job：`flush_db_read`（`FlushDbReadJob`），需在计划任务中**自行挂载**（建议每分钟执行一次）。

### 14.2 行为与业务对齐

| 要点 | 说明 |
|------|------|
| **立即空返回** | `DbAsync` 入队后**立即**返回 `[]` / `0` / `null`，**无结果回写**到请求上下文；只适合可丢结果的统计、预热类查询 |
| **flush driver 透传** | 入队写入 `driver`；`flush()` 使用 `D(..., $driver)`；别名配置可设 `DRIVER` => `clickhouse` |
| **默认关闭** | `Source/Inc/Db.inc.php` 中 `async_read` 默认为 `false`；开启后必须配置计划任务 **`flush_db_read`**，否则 SQL 只入队不执行 |

```php
// 计划任务示例：Handler = flush_db_read，cron 建议 * * * * *
```

### 14.3 ClickHouse

```php
'DB' => [
    'analytics' => [
        'DRIVER' => 'clickhouse',
        'HOST'   => '127.0.0.1',
        'PORT'   => 8123,
        'USER'   => 'default',
        'PASS'   => '',
        'DBNAME' => 'default',
    ],
```

## 16. 最佳实践与常见错误

### 16.1 推荐做法

| 做法 | 原因 |
|------|------|
| 单表逻辑放 `Model`，Control 只协调 | MVCS 分层 |
| 列表用 `total($offset, $limit)` | 一次条件、标准分页 |
| 常驻进程写前 `resetQueryState()` | 防止 where 污染 |
| 生产用 `pdomysql` + 配置别名 | 连接池与方言统一 |
| 主从场景读用 `useRead()`，写后立即读用 `useWrite()` | 避免主从延迟脏读 |
| 改驱动/注解后清 Runtime + Node 缓存 | 见 `AGENTS.md` |

### 16.2 常见错误

| 现象 | 原因 | 处理 |
|------|------|------|
| 改了 Model 不生效 | 编译缓存 | 清 `Runtime/`（保留 `init.lock`） |
| 隔离别名无效 | 未注册到 `DB` / `DBLIST` | 检查 `Config.inc.php` |
| 主从写入后读不到 | 读库延迟 | `useWrite()->find($id)` |
| 误把从库做成顶层 `DB` 键 | 混淆隔离与主从 | 从库应放在 `read` 数组内 |
| `M()` 报类不存在 | 无 Model 文件 | 用 `D('Table')` 或生成 Model |
| 异步读无结果 | 设计如此：入队即空返回；或 flush 未跑 | 仅用于可丢结果场景；配置 `flush_db_read` |
| 异步 flush 走错驱动 | 队列已带 driver；别名配 `DRIVER` | `S('Analytics')` 或 `D(..., 'clickhouse')` |

### 16.3 清理运行缓存

```bash
find backend/Runtime -mindepth 1 ! -name 'init.lock' -exec rm -rf {} +
chown -R www:www backend/Runtime && chmod -R 775 backend/Runtime
```

### 16.4 测试单元说明

```bash
php candy test:run db_driver   # 驱动冒烟（7 项）
php candy test:run db_unit     # ORM 单元：Where 编译、读写路由、事务锁 write
php candy test:run all
```

| HANDLER_ID | 范围 | 说明 |
|------------|------|------|
| `db_driver` | 冒烟 | 驱动解析、配置形态探测、指标、`dbVersion` 连库 |
| `db_unit` | 单元 | **无连库**：`WhereParser`（`<>`/`IN`/主键/边界）、`roleForQueryMethod`、事务内强制 write |

旧专题文档（`安装与配置.md`、`基本查询.md` 等）可能含 `mysqli`/`db()`/`CANDY_DB` 等历史写法，**一律以本文为准**。
