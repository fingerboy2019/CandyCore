## 查询数据

### 查询所有记录

```php
// 查询所有用户
$users = D('user')->select();

// 查询指定字段
$users = D('user')->select(['id', 'name', 'email']);

// 带条件查询
$users = D('user')->where(['status' => 1])->select();

// 带排序
$users = D('user')->order(['create_time' => 'desc'])->select();

// 限制查询数量
$users = D('user')->limit(10)->select();

// 分页查询
$users = D('user')->page(1, 10)->select();
```

### 查询单条记录

```php
// 根据ID查询
$user = D('user')->find();

// 条件查询单条记录
$user = D('user')->where(['name' => '张三'])->find();

// 查询指定字段
$user = D('user')->field(['id', 'name'])->find();
```

### 查询记录总数

```php
// 查询用户总数
$total = D('user')->total();

// 带条件查询总数
$total = D('user')->where(['status' => 1])->total();
```

### 查询指定字段

```php
// 查询指定字段
$users = D('user')->field(['id', 'name', 'email'])->select();

// 字段别名
$users = D('user')->field(['id as user_id', 'name as user_name'])->select();
```

## 条件查询

### where 条件

```php
// 基本条件
$users = D('user')->where(['status' => 1])->select();

// 多条件查询
$users = D('user')->where(['status' => 1, 'gender' => 'male'])->select();

// 使用运算符
$users = D('user')->where(['age' => ['>', 18]])->select();
$users = D('user')->where(['age' => ['>=', 18]])->select();
$users = D('user')->where(['age' => ['<', 30]])->select();
$users = D('user')->where(['age' => ['<=', 30]])->select();
$users = D('user')->where(['name' => ['like', '%张%']])->select();
$users = D('user')->where(['id' => ['in', [1, 2, 3]]])->select();
$users = D('user')->where(['id' => ['not in', [4, 5]]])->select();
$users = D('user')->where(['email' => ['is null']])->select();
$users = D('user')->where(['email' => ['is not null']])->select();
```

### 高级条件

```php
// AND 条件
$users = D('user')->where(['status' => 1])->where(['age' => ['>', 18]])->select();

// OR 条件
$users = D('user')->where(['status' => 1])->orWhere(['age' => ['<', 18]])->select();

// 复杂条件
$users = D('user')->where(function($query) {
    $query->where(['status' => 1])->orWhere(['age' => ['>', 18]]);
})->where(['gender' => 'male'])->select();
```

### 区间查询

```php
// 年龄在18-30之间
$users = D('user')->where(['age' => ['between', [18, 30]]])->select();

// 年龄不在18-30之间
$users = D('user')->where(['age' => ['not between', [18, 30]]])->select();
```

## 插入数据

### 插入单条数据

```php
// 插入用户
$id = D('user')->insert([
    'name' => '张三',
    'email' => 'zhangsan@example.com',
    'password' => password_hash('123456', PASSWORD_DEFAULT),
    'create_time' => time(),
    'update_time' => time(),
]);

// 返回自增ID
echo "新用户ID：" . $id;
```

### 批量插入

```php
// 批量插入用户
$users = [
    [
        'name' => '张三',
        'email' => 'zhangsan@example.com',
        'create_time' => time(),
    ],
    [
        'name' => '李四',
        'email' => 'lisi@example.com',
        'create_time' => time(),
    ],
];

$ids = D('user')->addAll($users);

// 返回插入的ID数组
print_r($ids);
```

## 更新数据

### 更新单条数据

```php
// 根据ID更新
$affected = D('user')->update(['name' => '张三'], 1);

// 条件更新
$affected = D('user')->where(['email' => 'zhangsan@example.com'])->update(['name' => '张三']);

// 返回影响的行数
echo "更新了 {$affected} 行";
```

### 批量更新

```php
// 批量更新用户状态
$users = [
    ['id' => 1, 'status' => 0],
    ['id' => 2, 'status' => 0],
];

$affected = D('user')->saveAll($users);

// 返回影响的行数
echo "更新了 {$affected} 行";
```

### 字段递增/递减

```php
// 浏览量 +1
$affected = D('article')->where(['id' => 1])->setInc('view_count');

// 库存 -1
$affected = D('product')->where(['id' => 1])->setDec('stock');

// 增加指定值
$affected = D('article')->where(['id' => 1])->setInc('view_count', 5);

// 减少指定值
$affected = D('product')->where(['id' => 1])->setDec('stock', 3);
```

## 删除数据

### 删除单条数据

```php
// 根据ID删除
$affected = D('user')->delete(1);

// 条件删除
$affected = D('user')->where(['email' => 'zhangsan@example.com'])->delete();

// 返回影响的行数
echo "删除了 {$affected} 行";
```

### 批量删除

```php
// 批量删除
$affected = D('user')->where(['id' => ['in', [1, 2, 3]]])->delete();

// 删除所有记录
$affected = D('user')->where(['status' => 0])->delete();
```

### 软删除

```php
// 开启软删除
$db->softDelete(true);

// 软删除记录
$affected = D('user')->delete(1); // 实际执行 update set deleted_at = now()

// 查询未删除的记录
$users = D('user')->where(['status' => 1])->select(); // 自动添加 where deleted_at is null

// 查询所有记录（包括已删除）
$users = D('user')->withTrashed()->select();
```

## 排序与分页

### 排序

```php
// 单字段排序
$users = D('user')->order(['create_time' => 'desc'])->select();

// 多字段排序
$users = D('user')->order(['create_time' => 'desc', 'id' => 'asc'])->select();
```

### 分页

```php
// 分页查询
$users = D('user')->page(1, 10)->select();

// limit 限制
$users = D('user')->limit(10)->select(); // 查询前10条
$users = D('user')->limit(10, 20)->select(); // 从第10条开始查询20条

// offset 偏移
$users = D('user')->limit(20)->offset(10)->select(); // 等同于 limit(10, 20)
```

## 分组与聚合

### 分组查询

```php
// 按性别分组统计用户数
$users = D('user')->group(['gender'])->select(['gender', 'count(*) as total']);

// 多字段分组
$users = D('user')->group(['gender', 'status'])->select(['gender', 'status', 'count(*) as total']);
```

### 聚合函数

```php
// 计算平均值
$avgAge = D('user')->field(['avg(age) as avg_age'])->find();

// 计算总和
$totalAmount = D('order')->field(['sum(amount) as total_amount'])->where(['status' => 1])->find();

// 最大值
$maxAge = D('user')->field(['max(age) as max_age'])->find();

// 最小值
$minAge = D('user')->field(['min(age) as min_age'])->find();
```

## 执行原生 SQL

### 查询原生 SQL

```php
// 执行原生查询
$users = D()->query('SELECT * FROM cd_user WHERE status = ?', ['1']);

// 执行多条 SQL
$results = D()->query('SELECT * FROM cd_user; SELECT * FROM cd_article;');
```

## 连贯操作

框架支持连贯操作，使代码更简洁易读：

```php
// 连贯操作示例
$users = D('user')
    ->where(['status' => 1])
    ->where(['age' => ['>', 18]])
    ->order(['create_time' => 'desc'])
    ->field(['id', 'name', 'email'])
    ->limit(10)
    ->select();
```

## 常用连贯操作方法

| 方法 | 描述 | 示例 |
|------|------|------|
| where | 设置查询条件 | where(['status' => 1]) |
| orWhere | 设置 OR 条件 | orWhere(['gender' => 'male']) |
| field | 设置查询字段 | field(['id', 'name']) |
| order | 设置排序 | order(['create_time' => 'desc']) |
| limit | 设置查询数量 | limit(10) |
| page | 设置分页 | page(1, 10) |
| group | 设置分组 | group(['gender']) |
| having | 设置 having 条件 | having(['total' => ['>', 10]]) |
| join | 设置连接查询 | join('article', 'user.id = article.user_id') |
| leftJoin | 设置左连接 | leftJoin('article', 'user.id = article.user_id') |
| rightJoin | 设置右连接 | rightJoin('article', 'user.id = article.user_id') |

## 最佳实践

1. **使用参数绑定**：避免 SQL 注入
2. **限制查询字段**：只查询需要的字段
3. **使用索引字段**：条件查询使用索引字段
4. **分页查询**：大数据表使用分页查询
5. **事务处理**：复杂操作使用事务保证数据一致性
6. **软删除**：优先使用软删除保护数据
7. **连贯操作**：使用连贯操作提高代码可读性
