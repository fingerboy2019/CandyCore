# 数据库驱动与连接规划（P2 / P3）

> 最后修订：**2026-07-17**  
> 日常开发请先阅读 [详细使用指南](详细使用指南.md)。

## 驱动一览

| DRIVER | 类 | 说明 |
|--------|-----|------|
| `pdomysql` | `PdoMysql` | MySQL/MariaDB（推荐） |
| `mysqli` / `mysql` | `Mysqli` | 原生 mysqli 备选（`ConnectionManager` 池治理与 Pdo 一致） |
| `pdopgsql` / `pgsql` | `PdoPgsql` | PostgreSQL |
| `pdosqlite` / `sqlite` | `PdoSqlite` | SQLite（PATH/DSN） |
| `pdosqlsrv` / `sqlsrv` | `PdoSqlsrv` | SQL Server（需 pdo_sqlsrv + ODBC 17/18） |
| `clickhouse` | `ClickHouse` | HTTP 分析查询 |

历史别名 `pdo` → `PdoMysql`；`Pgsql` / `Sqlite` 类保留为薄包装。

## SQL Server（P4）

```php
'DB' => [
    'mssql' => [
        'DRIVER' => 'pdosqlsrv',
        'HOST'   => '127.0.0.1',
        'PORT'   => 1433,
        'USER'   => 'sa',
        'PASS'   => '...',
        'DBNAME' => 'AppDb',
        'TABPREFIX' => 'sa_',
    ],
],
```

```php
D('User', 'mssql')->where(['status' => 1])->limit(10)->select();
// Where 使用 [col]；limit 编译为 OFFSET/FETCH
```

依赖：PECL `pdo_sqlsrv`（PHP 8.3+）与 Microsoft ODBC Driver 17/18。

## DuckDB（旁路，对照 Analytics）

不进入 `DBServer` ORM。客户端 `Candy\Extend\DB\DuckDb` + Service `S('Duckdb')`，经 **duckdb CLI** 执行 JSON 结果。

```php
'DB' => [
    'duckdb' => [
        'PATH' => '/data/analytics.duckdb', // 或 :memory:
        'BIN'  => 'duckdb',                 // 可选绝对路径
    ],
],
```

```php
S('Duckdb')->select('SELECT count(*) AS c FROM read_csv_auto(\'logs.csv\')');
S('Duckdb')->ping();
```

适合本地 OLAP / 文件分析；无 CLI 时 `ping` 返回不可用。

## pgvector（旁路，PostgreSQL 向量）

不新增 DRIVER。在现有 `pdopgsql` 连接上启用扩展，封装文档向量表与相似度检索。

依赖：PostgreSQL 安装 `pgvector`（如 `postgresql-14-pgvector` 或源码编译），并 `CREATE EXTENSION vector`。

```php
// 探测
S('Pgvector')->ping();

// 启用扩展 + 建表示例表 sa_doc_embedding（维度可配）
S('Pgvector')->ensureExtension();
S('Pgvector')->ensureDocTable('doc_embedding', 1536, true);

// 写入 / 检索（cosine）
S('Pgvector')->upsert('doc-1', $embedding, '摘要…');
S('Pgvector')->search($queryEmbedding, 10, 'cosine');
```

底层客户端：`Candy\Extend\DB\Pgvector`。禁止当作 Admin 默认 DRIVER；文档元数据仍在关系表，向量列用 pgvector。

## Vector（框架门面，旁路）

**推荐入口（任意应用，无需写 Service）：**

```php
V()->upsert('doc-1', $embedding, '摘要');
V()->search($queryEmbedding, 10);
V(null, ['force' => 'php'])->search($q);          // 强制嵌入式
V()->usePgvector()->upsert('doc-1', $emb, '…');   // 强制 pgvector
VectorServer::query($q, 10);                      // 静态快捷
```

路由：`VectorServer` → `VectorRouter`（默认 **pgvector 优先**，失败回退 PHP `Data/vector`；`DEBUG=1` 时 `Debug::addMsg` 提醒）。

可选：运维直连 `S('Pgvector')`（ensureExtension / ensureDocTable）。**不要**在各应用再实现 `Services/Vector`。

配置：`Source/Inc/Vector.inc.php`（`prefer_pgvector` 等）。

## MongoDB（旁路，文档存储）

不进入 `DBServer` ORM。客户端 `Candy\Extend\DB\Mongo` + Service `S('Mongo')`，依赖 PECL `mongodb`。

```php
'DB' => [
    'mongo' => [
        'URI'    => 'mongodb://127.0.0.1:27017',
        'DBNAME' => 'candy_docs',
    ],
],
```

```php
S('Mongo')->ping();
S('Mongo')->ensureDocIndexes();
S('Mongo')->upsertDoc('page-1', ['title' => '…', 'body' => '…', 'tags' => ['a'], 'meta' => []]);
S('Mongo')->getDoc('page-1');
S('Mongo')->searchByTag('a', 20);
S('Mongo')->find('logs', ['user_id' => 1], ['limit' => 20]);

// 可选抄写（需 Mongo.write_enqueue=true + 非 File 缓存）
S('Mongo')->enqueue('docs', ['doc_id' => 'page-1', 'title' => '…']);
```

设计说明见 `raw/doc/MongoSidecarDesign.md`。禁止当作 Admin 默认 DRIVER。

## 库隔离 + 读写分库

见 [多数据库切换功能说明](../框架使用/多数据库切换功能说明.md)。

`DBServer::setLink` 已接线 `DbLinkRole`：别名/内联若含 `write`/`read`（无顶层 HOST）则启用自动路由；`alias@read` 与第三参 `role` 可强制节点。默认库若为分库形态，从 `DBLIST.default` 初始化（与 Bootstrap 注入一致）。

## 连接治理（P2）+ Workerman 长驻

- `ConnectionManager`：空闲超时、坏连接剔除、每 worker 连接上限（`DB_MAX_CONNECTIONS`，默认 32）
- `WorkerRuntime`：`onWorkerStart` / `onWorkerReload` 重置 **PDO/Mysqli 进程内池** + `Cache::flushInstance()`，避免 fork 继承坏套接字
- 接线：`Route::bindWorkerReload()`（WebServer 已调用）会同时包装 `onWorkerStart`
- PDO：`isWebServer()`（Workerman）下 **禁用** `ATTR_PERSISTENT`；FPM 可开持久连接
- Redis：长驻默认 **禁用 pconnect**（`WorkerRuntime::shouldAvoidPersistentIo()`）；可用 `CACHE.options.persistent` 强制覆盖
- 断线重试：MySQL 错误码 + PostgreSQL `08*` / `57P01` 等 SQLSTATE
- `DbMetrics`：查询次数、慢查询、连接创建、读写角色命中、异步队列
  - FPM：`metrics_persist=auto` 时写入 `Runtime/Cache/db_metrics.json` 跨请求累计（`flock`）
  - Workerman：默认仅当前 Worker 进程内累计；可用 `metrics_persist=true` 强制落盘
- 慢查询日志：`Runtime/Logs/sql-slow.log`（阈值 `DB_SLOW_MS`，默认 500ms）

配置：`Source/Inc/Db.inc.php`

冒烟：`php candy test:run worker_runtime_smoke`

## 异步只读（P3）

```php
// Source/Inc/Db.inc.php
'async_read' => true,

// 代码
D('User')->useAsyncRead()->select();
```

消费：计划任务 Job `flush_db_read`（`FlushDbReadJob`），**默认未挂载**，开启 `async_read` 后需自行配置（建议每分钟）。

**行为对齐：**

- 入队后**立即返回空结果**，无回写，适合可丢的统计类查询。
- `flush` 携带队列中的 `driver`（或按别名 `DB.*.DRIVER` 解析），消费时 `D('_dbDriver', alias, read, driver)`。
- 分析库推荐 `S('Analytics')` 或 `D('_dbDriver', 'analytics', 'read', 'clickhouse')`。
- `async_read` 在 `Db.inc.php` 中**默认 `false`**。

## ClickHouse（P3）

```php
'DB' => [
    'analytics' => [
        'DRIVER' => 'clickhouse',
        'HOST'   => '127.0.0.1',
        'PORT'   => 8123,
        'USER'   => 'default',
        'PASS'   => '',
        'DBNAME' => 'default',
    ],
],
```

```php
// Service 封装（推荐）
S('Analytics')->select('SELECT count() AS c FROM events');
S('Analytics')->ping();

// 主库写成功后旁路入队（无计划任务时积压达阈值会机会式刷库；不可用则静默丢弃）
S('Analytics')->enqueue('events', [
    'uid' => 1,
    'evt' => 'login',
    'created' => date('Y-m-d H:i:s'),
]);
// 消费：计划任务 Handler=flush_ch_write；或 Analytics.opportunistic_flush_at 机会式刷库

// 或直接 D() 第四参透传驱动
D('_dbDriver', 'analytics', 'read', 'clickhouse')->query('SELECT 1', 'find');
```

分析库适合日志/报表；不支持事务与完整 ORM。旁路写入见 `Source/Inc/Analytics.inc.php`、`APP\Extend\ChWriteQueue`。
