# Candy 博客

欢迎访问。在 `Doc/Blog/{content_dir}/分类名/` 下新建 Markdown 即可发布文章，首页 feed 将自动聚合。

## 快速开始

| 操作 | 说明 |
|------|------|
| 新建文章 | 在 `{content_dir}/分类名/文章名.md` 创建文件 |
| 访问首页 | `/Blog/` |
| 访问文章 | `/Blog/分类名/文章名`（URL 不含 `post`） |

示例分类见侧栏 **默认分类**。
